# STS2 Minimal Mod / 儒家原型

这是《杀戮尖塔 2》思想家 Mod 的最小开发项目。目前实现孔子路线的木铎与青玉佩、孟子路线的熊掌、荀子路线的绳墨，以及单人开局的“诸子观照”事件插入原型；不依赖 BaseLib 或 RitsuLib。

## 当前原型

测试遗物“木铎”直接施加“周礼”规则：

- 每回合可以自由决定先行礼或先攻击，不再禁止攻击牌。
- 技能牌或能力牌先出则视为先礼：第一张技能牌获得 2 点临时力量，后续技能牌各获得 1 点，每回合最多 5 点；能力牌只确定先礼。
- 攻击牌先出则视为失礼：该攻击结算前获得 1 点负向临时力量，本回合只触发一次，之后技能牌不再提供木铎力量。
- 正向和负向力量都只持续到本回合结束，不影响其他来源的力量。
- 木铎不进入普通奖励抓包，只能通过开发者控制台的 `kongzimuduo` 指令获得；它登记在事件遗物池中仅用于模型与详情页识别。
- 当前使用木铎临时占位图；PCK 包含中英文测试文本和 Godot 导入后的图标资源。

测试遗物“青玉佩”提供第二个原型：

- 只有所有存活敌人均为非攻击意图时才会检查仁行。
- 玩家本回合只要曾有一张经 `CardModel.CanPlay` 与原生目标判定确认可打出的攻击牌，最终未打出任何攻击牌即践行仁；先用技能耗尽能量不会抹去已经出现过的机会。
- 打出攻击牌会立即失仁并关闭本场机会；毒、充能球及其他非攻击牌伤害不计。
- 一旦仁行成立并锁定奖励，后续回合打出攻击牌也不会撤销本场结果。
- 仁行永久增加 1 点德，并在本场正常卡牌奖励末尾追加一张不同的罕见或稀有牌，但仍只能取得一张牌。
- 青玉佩与木铎一样不进入普通奖励抓包，只能用开发者控制台的 `kongziqingyupei` 指令授予；图标物件为无字、无绳的长方形青玉佩。

测试遗物“熊掌”读取青玉佩保存的同一份德：

- 每场战斗的前 N 个回合获得 1 点能量并额外抽 2 张牌，N 等于当前德。
- 只能用开发者控制台的 `mengzixiongzhang` 指令授予；当前明确复用青玉佩图片作为临时占位图，尚未设计最终熊掌图标。

测试遗物“绳墨”追踪持有者连续打出的牌：

- 每回合首次连续打出技能牌、攻击牌和技能牌时，获得 1 点力量和 1 点敏捷；每回合最多触发一次。
- 只有持有者实际打出的牌参与序列，其他玩家的出牌互不影响；能力牌及其他非技能、非攻击牌会打断序列。
- 可用开发者控制台的 `xunzishengmo` 指令授予；当前明确复用木铎图片作为临时占位图，尚未设计最终绳墨图标。
- 绳墨已登记到事件遗物池，但尚未接入“诸子观照”事件。

“诸子观照”提供事件插入 MVP：

- 单人局中，涅奥选择完成后的继续按钮先进入标准事件界面，再由事件的继续按钮打开原版地图。
- 初始页可以接受木铎、接受青玉佩或拒绝；一次事件最多授予其中一件，已通过控制台持有任一原型遗物时不会重复授予或形成双持。熊掌不在该事件的选项中。
- 事件不会加入普通问号池，也不修改地图节点、坐标、路线、楼层编号或第一排固定小怪。
- 插入点只补丁 `NEventRoom.Proceed()`；当前房间必须是涅奥事件，且当前地图点房间历史中尚无 `PHILOSOPHERS_GAZE`。
- 当前版本仅面向单人流程；多人邀请与选择规则尚未实现。

## 构建与部署

项目从 `local.props` 读取本机游戏目录。该文件不会提交；新机器可复制 `local.props.example` 后修改路径。

```powershell
dotnet build -c Release -p:DeployOnBuild=false
```

该命令只构建程序集，不构建 PCK，也不部署到游戏目录。

运行不依赖游戏进程的木铎、仁、绳墨序列与奖励稀有度策略检查：

```powershell
dotnet run --project .\tests\ModLogicChecks\ModLogicChecks.csproj -c Release
```

必须从 Steam 启动游戏；直接运行 `SlayTheSpire2.exe` 会因缺少 Steam 启动上下文而自动退出。启用 `STS2 Minimal Mod` 后，初始化日志应包含：

```text
[STS2MinimalMod] Initialized successfully.
```

Windows 日志位置：

```text
%APPDATA%\SlayTheSpire2\logs\godot.log
```

进入一局游戏后按反引号（\`）或单引号键打开开发者控制台，可使用 `kongzimuduo`、`kongziqingyupei`、`mengzixiongzhang` 或 `xunzishengmo` 将对应遗物加入当前玩家的遗物栏；规则从当前玩家的下一次适用时机开始生效。`mengzixiongzhang virtue [amount]` 可查看或设置该玩家由青玉佩保存的德。
