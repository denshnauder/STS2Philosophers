# 已解决问题归档

此目录只保存已经完成验证并闭环的问题。

## 归档条件

问题只有在验证条件满足后才能从 `../ACTIVE.md` 迁移到这里。

- 仅完成代码修改：不能归档。
- 自动测试或构建通过，但仍需要游戏内确认：状态保持 `待验证`。
- 验证失败：回到 `处理中`，继续修复。
- 因用户决策、人工操作、外部资源或环境限制无法继续：标记 `阻塞`。
- 验证条件全部满足：迁移到本目录，并从 `ACTIVE.md` 删除。

## 文件命名

`YYYYMMDD ISSUE编号 问题简称.md`

遵守仓库禁止自定义文件名使用连字符的规则。

## 每份归档必须记录

1. 问题现象
2. 期望目标
3. 根因
4. 最终修改
5. 验证方法
6. 最终结果
7. 涉及文件
8. 相关提交

归档的意义是形成可检索的技术记忆，而不是保留活动任务列表。
