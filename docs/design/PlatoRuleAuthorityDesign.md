## 先看游戏呈现和制作

节点仍是既定第二幕Fixed/Adopt，不改前置或单一主说。战斗只使用玩家实际手牌、正常能量、原生敌人和攻击。每回合抽牌完成、首次手动动作之前，用两种公开操作方式之一处理本回合一次费用减免；无需新角色、第二目标或场景。

拟复用原生两选一界面和实际牌面。玩家需看到将自动执行的那一张牌及其目标，再决定是否委托；不能伪装成不知道结果的随机风险。自行安排还需正常选牌和选目标。原生选择窗口、自动出牌队列、临时费用处理是否支持这一时点，尚未验证；频繁选择的节奏成本也要测试。不是已接入UI。

素材目标一枚静态遗物图标，两方式用同一图标/原生卡框与简短文字。牌面、动作、受击与状态全部来自实际原生牌。不自动生成AI图，不覆盖生产城邦印章；本页尚无图标资产或游戏验收。

拟名：统领筹 / PlatoRuleAuthority / PLATO_RULE_AUTHORITY，键PLATO_RULE_AUTHORITY.title、.description，资源plato_rule_authority。模式：依规执行 / PlatoRuleAuthorityDelegate / PLATO_RULE_AUTHORITY_DELEGATE；自行安排 / PlatoRuleAuthorityDirect / PLATO_RULE_AUTHORITY_DIRECT，各用.title、.description并共用图标。未注册，不更名公开ModelId。

## 问题面和操作规则

“我接受一种现成能力时，是否说明了它服务什么？力量较大、规则有条理，会不会遮住我真正要照顾的局面？”并不把自行选目标叫理性，把委托叫欲望；两种方式都可能服务经过考虑的目的。原生牌类型也不等于灵魂三部分。

每轮一次，处理同一真实手牌实例，选择后正常剩余回合继续：
- **依规执行**：按本轮抽牌时固定顺序，预告并选出第一张合法牌；自动对当前生命最高的合法敌人出牌，自身牌正常指向自身；该牌减免至多2点实际能量费。若同生命按固定位置，不随机换目标。
- **自行安排**：玩家选择一张合法手牌及合法目标；该牌减免至多1点实际能量费。
- **不用**：正常手动回合，无减免，权限结束。本轮没有合法牌时不强制弹窗，不奖励闲置权限。

不是增加两点/一点可任意花的能量，不复制牌、不多抽牌、不修改全局模型或下轮费用。低费牌实际减免可能小于上限；零费牌为0，不能称已付出差额。X费与需额外玩家选择的牌先排除在有限纸面范围之外；正式能力的适用面尚未定，不借范围标签伪称全牌支持。纸面只用未升级Bash和DefendIronclad，两者合法性、费用和效果明确。

流程：看到实际规则/自动牌目标 → 三选回应 → 实际支付并打出原实例 → 正常剩余行动 → 记录已花费用/目标/本段结果 → 下轮可重新选择方式。自动规则没有合法目标时不偷换牌或消耗事务；应回到正常手动，不制造额外卡。出牌前状态已变时须重新核对合法性。正式实现需要原子队列与读档继续验证。

主说退出前完成待处理操作；之后不残留减免。空句回应与不回答同权限；不因使用哪种方式判人格、扣善恶分或授予后继。后继关系保持既定图，当前只留方法、明确目的和实际材料接口。

## 两种处境的同规则实例

所有敌人/手牌为受控反例，不是原生遭遇或完整起手。玩家生命12、正常能量3。Bash为2费伤害8并随后施加易伤2；DefendIronclad为1费格挡5。此处只观察一轮且之后不再攻击易伤目标，不另行猜测易伤倍率、下轮牌或胜负。

**A：大者13生命/打4，小者6生命/打10；手牌Bash、Defend、Defend。**
- 委托Bash打大者：Bash实际0费，大者剩5；再打两Defend共2费，格挡10，两个存活敌人总攻14，实际失血4，玩家8。剩1能量却已无其他手牌，不能称这1点已产生有用行动。
- 自行Bash打小者：实际1费，小者击倒；再打两Defend共2费，格挡10，大者打4，实际失血0，玩家12。
- 无新能力的正常Bash打小者再打一Defend也能避免失血；此例不能夸称只有自行减免才实现保全。

**B：大者13生命/打17，小者6生命/打1；手牌Bash和三Defend。**
- 委托Bash打大者后可付3费打三Defend，格挡15；总攻18，实际失血3，玩家9，大者剩5、小者6。
- 自行Bash打小者后剩2费只能打两Defend，格挡10；大者打17，实际失血7，玩家5，大者13、小者击倒。
- 自行方式也可选择免费一Defend再打另外两Defend，失血3，但没有打Bash、双方敌人生命仍13/6。这说明上两行是具体方案，不是“所有自行选择都较差”的证明；委托额外费用容量在该方案里确实容纳了一张防护牌。

不以模式胜负评人。两处自动规则始终一样，因实际威胁改变而可能合用或不合用；更大的减免并不保证较好的行动安排，控制权也不能自动证明目的值得。

## 失败、恢复与设计缺口

失败可以是委托规则忽略了真正威胁，也可以是自行安排支付较多后错失行动；保留实际生命和资源，不回滚。下一回合可换方式，不锁死“不修订才理性”。有限模型死亡后无后续动作或伪造记录；击倒目标取消其攻击。修订不给补偿奖励，学习改变规则使用而不是安装一个品德分。

动作从“拿共享耐久抵伤”转成“决定现成能力由什么规则支配、何时自己安排”，不是换一组格挡数值。但仍不能把普通战术控制等同柏拉图正义：共同/整个个体的目的尚未正面建立；选择得更聪明依旧可能服务坏目标。正式主循环还需更完整的可用牌、合法性、节奏与持续停留设计。

**继续条件**：先做受控三张/四张手牌的一轮可操作纸面，允许正常原生费用的基线对照、三种回应、实际目标与费用记录。只判断控制取舍是否可感，程序不认证善、理性、幸福或乐趣。若试玩仍只觉得费用优惠，停止这项候选，不铺自动出牌或存档系统。暂不批准完整主能力；游戏安全与哲学审查独立。
