# 第欧根尼公开说明双前史

## D139候选性质

本页在D138角色架构内设计具体Question内容，候选核心是：**把已经发生、原本只由玩家或系统知道的行动事实，交给明确接收者；事实一旦公开不能撤回，理由可以保持、修订或撤回。** 它不新增战斗能力，也不以丢弃资源换奖励。

两种前史都来自既有设计记录，不伪造新经历：

- 苏格拉底德性前史：稳定回合是否出现、玩家继续或撤离、当时明确目的/标准/自评分别保存。来源为58/61/62/65纸面候选，尚未接游戏。
- 柏拉图前史：正常购买、匿名取用或离开、实际价格/支付/取得，以及玩家私下理由分开保存。来源为79/83与无名环纸面，原生商店保存仍阻塞。

这些是设计层可用材料，不冒充生产存档已经可靠。正式接入前必须分别通过各自的保存与知识边界验证。

## 正式节点、界面和素材

沿[[89第欧根尼问题事件角色定位]]：

1. 第二幕既定Question：标准事件页显示一种前史的准确事实卡，再显示第欧根尼问题与公开选项；一张第欧根尼静态图。
2. 中间不监控普通战术，不新增状态图标。路线历史只保存接收者已知内容、玩家公开说法和未公开私有材料的边界。
3. 第三幕既定Stay/Switch：标准事件页回看第欧根尼已知的内容；Stay复用第欧根尼图，Switch使用芝诺图并显示克拉特斯中介说明卡。

没有群众、商人到场、街市、桶屋、传令者、战斗浮层或动画。柏拉图交易的商人没有自动得到披露内容；“向第欧根尼公开”只表示第欧根尼这一接收者知道，不虚构全世界知晓。若以后要让商人回应，需独立节点、素材和知识流设计。

## 共享状态结构

| 字段 | 含义 | 禁止推断 |
| --- | --- | --- |
| FactKind | 苏格拉底行动/目的，或柏拉图交易 | 不从人物名推品德 |
| FactSnapshot | 事件发生时的不可变事实 | 不用后来结果改写过去 |
| PrivateReason | 玩家此前只对系统提交的理由，可为空 | NPC不自动知道 |
| DiogenesDisclosure | 未公开、事实公开、事实与理由公开 | 不是诚实分数 |
| PublicClaim | 玩家在第欧根尼处明确提交的当前说法，可为空 | 不从点击结果反推动机 |
| ZenoResponse | 保持、补充理由、修订、撤回、继续沉默 | 不删除已公开事实 |
| RouteOutcome | Stay或Switch | 不认证谁更犬儒/斯多亚 |

事实公开后不能改回“第欧根尼不知道”；理由撤回只表示玩家不再坚持该理由。未公开的PrivateReason不能出现在第欧根尼或芝诺台词中。第三幕芝诺只知道第欧根尼已公开传递的内容和玩家当场说出的新内容；中介说明不等于克拉特斯亲历本局。

## 苏格拉底德性前史

### 第二幕事实页

只显示程序真正保存的组合，例如：

- 有稳定撤离机会，玩家为“保全生命完成某目的”选择撤离；
- 有稳定继续机会，玩家按某一标准继续承担后果；
- 没有稳定机会、只看过页面或没有提交目的。

第欧根尼不宣布撤离是怯懦或坚持是勇敢。他问的是：**你是否需要别人把这次行动叫作勇敢，才能继续按同一目的生活？** 这是游戏创作的问题，不冒称原话。

### 玩家选项

1. 公开事实与当时目的：第欧根尼知道行动和玩家当时给出的理由。
2. 只公开事实，拒绝先给德性名称：第欧根尼知道发生什么，不知道PrivateReason。
3. 保持沉默：不公开事实或理由；记录明确拒答，不推断羞耻、欺骗或无知。
4. 无材料：仅在没有合格事实时出现，可离开；不制造一次撤离/坚持。

这些选项不改变生命、奖励、旧主说或候选权重。公开目的不是正确答案；它可能后来显得不充分。

## 柏拉图无名环前史

### 第二幕事实页

显示实际选中药水、原价、购买/匿名取用/离开、实付和是否取得；私下理由单列为“尚未告诉第欧根尼”。免费、满槽、失效报价和无交易机会沿83/84边界显示，不能把失败取得写成克制。

第欧根尼问：**匿名保护了行动不受赞美或责难；你现在愿意让一个具体的人知道什么？** 问题针对评价与公开说明，不把原价付款定义为正义，也不要求认罪。

### 玩家选项

1. 公开交易事实与当时理由；
2. 只公开交易事实，不提交人格/正义结论；
3. 保持沉默；
4. 无有效交易材料时说明“没有这次机会”并离开。

公开匿名取用不会自动通知商人、扣款或改库存；公开正常购买也不发声誉奖励。若只公开事实，第欧根尼不能在结果页引用PrivateReason。

## 第三幕共同回看

第三幕页面先按知识流显示：

- 已公开事实与理由：原样回看，可保持理由、补充限度、修订或撤回当前说法；
- 只公开事实：可首次说明理由、继续拒绝标签或保持沉默；
- 未公开：可当场首次告诉第欧根尼/芝诺相应事实，或继续沉默；
- 无材料：不能伪造前史，只讨论是否接受另一种训练。

完成回看后单独选择：

- Stay：本局哲学发展停在第欧根尼公开自足问题，保留此前唯一机械主说；
- Switch Zeno：显示犬儒传统经克拉特斯等进入早期斯多亚，确认后由芝诺替换此前主说。

说法选择和路线结果分两步，避免“选一句谦虚台词就自动得到芝诺”。所有披露状态都允许Stay或Switch；差异在后继问题与已知材料，不用公开程度做门票。

## 完整决策循环与玩家取舍

前史实际行动 → 第二幕决定公开范围并形成当前说法 → 第欧根尼只回应已知内容 → 第三幕在同一事实和新处境下保持/修订/撤回 → 独立选择Stay/Switch。玩家取舍是信息一旦给出无法收回，但理由可变；沉默保留隐私，却放弃针对自己具体事实的回应。没有隐藏善恶奖励。

这与苏格拉底循环不同：苏格拉底检查一个说法的根据或行动理由；第欧根尼候选检查玩家是否让公开评价支配生活，以及是否愿意承担让具体他人知道的关系后果。相同的“修订”状态结构可以复用，问题对象、知识流和路线后果不同，不能只换标题。

## 失败、恢复与反例

- 玩家公开事实只为看更多文本：程序不判动机；文本价值需体验验证，不能奖励“公开次数”。
- 玩家沉默因为没有兴趣：仍是合法选择，不写成依赖名声。
- 购买、撤离等原行为本来就是最优策略：公开问题不把结果认证为自足，重点在评价/理由的关系。
- 私下理由含任意安全文本：展示必须转义，NPC不可据此自动判断真假。
- 跨前史混合：单次只选一个完整事实材料，不把苏格拉底目的和柏拉图交易拼成更高分。
- 已公开后读档：必须保留接收者知识；不能通过重新进事件把公开变私密或换另一事实。
- Stay保留旧强力主说、Switch追求新能力：两者动机不可知，不写路线道德结论。

## D139判决与继续条件

本候选首次把D137关系外壳填入可操作内容：两种前史均有真实事实、三种公开范围、不可逆知识流、可修订理由和独立Stay/Switch，且不新增战斗数值或场景。它可以作为**完整核心候选**继续纸面审查。

仍未批准对白原型或生产。主要风险：

1. 公开与沉默若只改变文本长度，玩家可能看不到值得取舍的关系后果；
2. 两种前史目前都只在纸面模型中有细粒度记录，生产存档与安全文本未统一；
3. “让第欧根尼知道”仍弱于广义公共/政治直言，只能如实称具体关系中的公开说明。

下一用四条完整纸面路径检查知识边界和后继差异：苏格拉底公开目的后修订、苏格拉底沉默后首次开口、柏拉图只公开事实后补理由、柏拉图公开后撤回理由。每条都分别走Stay和Switch，若最终仅多几句文本且不改变问题，就降为辅助对白而非核心。
## D140四条纸面路径与八个后继问题

以下使用虚构但受状态规则约束的具体材料，只检验知识流与问题差异，不冒充正式对白、原生存档或完整剧情。苏格拉底材料中的“护送伤者”只是纸面目的输入；柏拉图材料中的药水/价格只作交易字段示例。

### 路径一：苏格拉底公开目的，第三幕修订

事实：玩家在稳定撤离机会中选择撤离；当时公开目的为“保住生命，护送伤者”。第二幕向第欧根尼公开事实与目的。第三幕玩家修订为“我保住了生命，但不能仅凭目的证明这次撤离值得称勇敢”。

- 知识边界：第欧根尼始终知道撤离和旧目的，也知道玩家后来不再用旧目的充分证明德性；修订不能抹掉旧说。
- Stay问题：能否让行动保持有理由但不急于取得“勇敢”称号，并继续承担未定判断？
- Switch问题：芝诺收到的是“行动事实 + 旧目的 + 修订”，可以问怎样把有限理由转成可反复训练的判断，而不能说玩家已证明德性。

Stay与Switch面对的不是同一句收尾：前者承担未定评价，后者把修订过的理由交给另一种训练。两者都不增加资源。

### 路径二：苏格拉底沉默，第三幕首次开口

事实同上，但第二幕玩家保持沉默，第欧根尼不知道撤离、目的或私有自评。第三幕玩家首次公开“我当时撤离是为了护送伤者，但我没有在那时说明”。

- 知识边界：第二幕结果页不能引用撤离或目的；第三幕才产生公开事实。不能写“你终于承认”，因为第欧根尼此前只知道玩家拒答。
- Stay问题：为什么选择现在向第欧根尼说明；时间变化是否改变了对评价的依赖？
- Switch问题：芝诺接收第一次公开说明和中介背景，可以问玩家为何此刻愿意把行动交给另一种训练；不能假装这是经第欧根尼长期检验的结论。

与路径一的差别不是文本长短，而是谁在何时有资格追问：路径一可追问理由修订，路径二只能先处理迟来的公开。

### 路径三：柏拉图只公开交易事实，第三幕补理由

事实：玩家匿名取用一瓶标价120、实付0的药水并实际取得；私下理由是“先保命，之后再决定是否补价”。第二幕只向第欧根尼公开交易事实，不公开理由。第三幕首次补充该理由。

- 知识边界：第二幕第欧根尼只能回应匿名、取得与未付款事实，不能说玩家为了保命；私有理由仍不影响商人库存或金币。
- Stay问题：补出的理由是否改变玩家对匿名评价的关系，还是只在事后争取理解；第欧根尼不裁决正义。
- Switch问题：芝诺可问如何在未来行动前形成判断，而不把补理由等同为已经自制；克拉特斯中介只说明传统关系。

差别在理由首次进入共同材料后，后继从“你愿公开什么”转到“理由何时对行动有约束”。这不是原价或付款判分。

### 路径四：柏拉图公开事实与理由，第三幕撤回理由

事实同路径三。第二幕公开交易与“先保命、以后再决定”理由；第三幕玩家撤回该理由，不撤回交易事实。

- 知识边界：第欧根尼仍知道旧理由曾被公开；撤回后不能把它当玩家当前主张，也不能删除交易。
- Stay问题：在失去原理由后，玩家是否愿让行动保持未辩护状态，而不是立即找一个更体面的解释？
- Switch问题：芝诺收到的是事实、旧理由及撤回历史，可以问训练如何避免事后理由支配下一次选择；不能称撤回为认罪或通过。

与路径三相比，一个是理由迟来，一个是理由失效；后继问题方向相反，不能合并成“已说明理由”布尔值。

## 八个终点的共同约束

四条路径各有Stay/Switch，共八种结尾。所有结尾都遵守：

- Stay保留此前唯一机械主说并关闭本局后续哲学切换；Switch才由芝诺替换；
- 公开范围不改变候选资格、奖励或数值；
- 芝诺只接收公开历史，不读取PrivateReason；
- 第欧根尼与芝诺的问题可以不同，事实快照不能不同；
- 沉默、迟说、修订和撤回分别保存，不压成“未通过/通过”；
- 玩家动机不可由路径反推。

## D140判决

四条路径能够产生不同的后继问题，而不只改变文本长度：

1. 已公开理由后的修订，问题是如何承担有限理由；
2. 沉默后的首次开口，问题是公开时点与接收关系；
3. 只公开事实后的补理由，问题是理由何时开始约束行动；
4. 公开理由后的撤回，问题是失去辩护后是否急于替换。

Stay与Switch又分别把同一知识历史导向“承担未定终点”或“接受另一种训练”，没有正确答案门票。由此，公开说明可继续作为**完整叙事决策核心候选**，不降为辅助对白。

它仍不是完整可玩路线：当前没有正式短文案、交互纸面或玩家体验；两前史的生产保存均未接通，静态人物素材也未解决。下一先把四条路径压成标准事件可读的事实卡/选项/结果信息架构，并检查控制器焦点、信息长度与两张静态图预算；不先写游戏代码，也不以纯文字原型替代正式美术可行性。

## D141公开说明事件信息架构

[事件信息架构](./DiogenesPublicAccountInterface.md)把D140四条路径压成两个计划出现时点：第二幕第欧根尼事实回看/披露/回应，第三幕已知内容回看/说法处理/独立Stay或Switch。所有不可逆披露前都先显示接收者将知道什么，首项为安全返回；提交后只能修订理由，不能把事实变回未知。理由使用上游选择生成的预写类别，不开放自由文本，避免手柄、转义、本地化和存档边界同时失控。

现有项目事件图实测为1600×900，当前代码只证明一个事件模型使用一张静态背景，未证明页面内安全换图。制作预算因此固定为第欧根尼、芝诺各一张1600×900静态PNG，无动画、群众、桶屋、克拉特斯肖像或额外街市场景；正式接入至少需要两个标准事件模型；若第三幕不能页内换图而要显示芝诺，最多需要三个连续实例，动态换图与串接都需API核实。素材必须原创、明确委托授权或许可兼容；不默认AI图能进入生产。

正文目标45—60字、纸面硬上限82字，标题4—8字/上限10字，选项说明12—32字/上限44字，单页2—4项；超出时拆页，不缩字。两前史、四类公开历史和八个Stay/Switch后继仍保持差异，不设公开门票或数值奖励。该阶段只批准信息架构继续纸面设计，未批准文案、代码、美术或完整路线。下一写四路径共用短文案矩阵和状态提交边界，再做鼠标/手柄线框与恢复表。

## D142公开说明短文案矩阵

[短文案矩阵](./DiogenesPublicAccountCopyMatrix.md)把四条代表路径写成A—F标准事件短文案，并标明每次确认前后的接收者知识。正文36—51字、标题4—9字、说明12—19字；所有页面低于91的纸面上限。苏格拉底公开后修订、沉默后首次开口，柏拉图只公开事实后补理由、公开理由后撤回仍有不同正文和状态，不读取PrivateReason或给公开程度发奖励。

走查发现“返回、保持、限缩、修订、撤回”会形成五项，超过既定手柄预算；现把限缩并入有预写结果的修订，只保留返回、保持、修订、撤回四项。选项说明目标已修正为12—32字，短而明确的说明不为凑字扩写。生产输入仍只允许枚举事实、预写理由和原生本地化对象/整数；D140药水和价格只是纸面材料。

各确认页分别提交披露、第三幕说法和路线结果，查看/返回不提交；Stay与Switch继续独立。该阶段只证明文案装得进信息架构，未证明换行、焦点、取消键、读档、两事件接续或玩家体验。下一画A—F鼠标/手柄焦点线框，并模拟取消、返回、退出读档、重复确认和第二事件接续。

## D143公开说明交互与恢复线框

[交互与恢复线框](./DiogenesPublicAccountInteraction.md)为A—F页固定初始焦点、显式返回、取消降级和提交边界：披露、第三幕说法、Stay与Switch各自确认，所有破坏性页第一项为返回；取消键若不能安全拦截就无动作，绝不映射成沉默、停留或切换。查看/返回不写状态，重复确认必须幂等，退出重入只从最后一个已提交边界恢复。

11个纸面模拟覆盖披露前退出、确认返回、FactsOnly双击、沉默后重入、说法返回、修订双击、补理由退出、沉默后首次公开、Stay返回、Switch返回改Stay和替换中途失败。知识不倒退，旧说历史不删除，半完成替换不能显示成功。
