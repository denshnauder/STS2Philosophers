# 第欧根尼的自足与操练

## D129资料层级

既定规划：18人物用途/流程与19判决59—62、终点修订；第欧根尼主问题是德性与幸福的公开自足实践，可停留。EDGE010第二幕Question/Switch不是柏拉图直接师承；EDGE011仅可选经犬儒传统/克拉特斯到季蒂昂芝诺的游戏压缩，不强制前进。研究不改固定六入口与89人用途，不替第欧根尼补现代制度理论。

## 原始证言（仍非本人现存著作）

来源：[第欧根尼·拉尔修《名哲言行录》第六卷，第欧根尼章](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Diogenes_Laertius/Lives_of_the_Eminent_Philosophers/6/Diogenes%2A.html)，R. D. Hicks英译，页面公开版本。拉尔修是后世汇集者，不把转述叫本人可核实的历史原话；同一页存在相互竞争归属和版本。

- VI.37传述见孩童以手饮水而弃杯的故事。其设计启发是重新识别用具的必要性，不能推导所有物品都应丢弃。
- VI.70—71把身心操练联系，并区别无益的劳苦与按自然选择的操练；不能推出任意损血受罚就有德性。
- VI.26传述踏毯反奢与另一种骄傲的反诘，且标明不同说法。可作自我反例：反炫耀也可能成为炫耀，不将故事认定为确定现场。
- VI.69传述公开行动与直言形象。公开有受众，不能用程序私人记录冒充公共实践。

以上为有限定位的释义，无逐字引文；历史可信度、叙述意图与游戏取舍分别记录，不把传闻细节变成强制规则。

## 游戏推论与下一用途

“较少依赖”不等于“资源条较少”，自足不等于拒绝帮助或完全脱离共同体。被迫缺物不等于主动简化；为了换更强增益而抛物也未必降低依赖。身体操练不是加生命/力量的自动翻译，直言不是无后果点一条挑衅台词。这些是设计反例，不声称原典已给游戏规则。

先比较可用正式载体的节点/界面/资产与真实对象、实际依赖、可修订过程；不能用轶事编出必须新增街市/桶屋/群众场景。未形成完整循环，人物未设计完成，未实现或验收。
## D134自足、操练与直言的关系

### 二手研究与证据边界

本轮补读[Internet Encyclopedia of Philosophy：Cynics](https://iep.utm.edu/cynics/)的伦理、自由/直言、操练部分，以及[Stanford Encyclopedia of Philosophy：Ancient Ethical Theory](https://plato.stanford.edu/entries/ethics-ancient/#Cyn)。两者都提醒：早期犬儒著作未传，关于第欧根尼主要依靠较晚且有争议的言行记录。因此下列关系是有来源支撑的解释和游戏设计要求，不冒充本人留下的一套固定阶段理论。

- askēsis是持续的自我训练/实践，不是知道一条教义，也不是挨一次罚。它使人能够在困难中按所认可的生活方式行动。
- autarkeia是较少受外在财富、权势与惯例控制的生活能力，不是库存越少分数越高。能否用得上替代方式，比丢掉多少东西更重要。
- parrhēsia包含直率言说，也包含向具体对象说话时承担的风险。它与自足有关：若生活依赖权势者的供给和认可，直言会受牵制；但自足不会自动保证每句话真实、明智或正当。
- IEP把自由、自足与直言列为相互关联的形式，并把操练写成摆脱有害惯例、促进自足的途径；SEP则更谨慎地把简朴生活、充分操练、超脱惯常外在善联系起来。二者都不足以证明“先操练、再自足、最后直言”是唯一历史次序。

用于游戏的暂定因果链只能写成设计假说：**反复练成一个不靠特定外在许可或供给也能实行的方式，才可能在相关对象面前承担说与做的风险。** 玩家必须能用实际行动反驳这条假说；仅拒绝奖励、仅受苦或仅点挑衅台词都不算验证。

### 三者不能压成一个计量条

| 层次 | 必须看见的事实 | 不足以成立的替代 |
| --- | --- | --- |
| 操练 | 同一方式至少在两个真实时点可再次选择；玩家可中止、恢复或修订 | 苦难次数、少用一次药水、系统自动坚持 |
| 自足 | 原先依赖的对象、可用替代和替代失效的边界都具体存在 | 物品数、贫穷值、跳过次数、额外强牌 |
| 直言 | 有明确接收者、可理解的说/做内容和因关系产生的风险或后果 | 私人日志、无受众台词、程序判定“勇敢” |
| 三者关系 | 后来的表达引用先前真实行动，并允许承认替代失败 | 三枚分数同时上涨或一句旁白宣布已经自由 |

这里的“公开”不要求凭空新增群众，但必须有一个在正式界面中真实出现、能接收表达的对象。第欧根尼本人可以听取玩家的陈述，却不能仅凭教师见证把私人战术变成公共风险；若对象没有供给、评价或规则上的关系，直言层仍未完成。

### 现有低制作成本载体的能力边界

| 既有载体 | 能承载什么 | 当前缺口 |
| --- | --- | --- |
| 第二幕Question邀请 | 说明一个具体依赖、接受/拒绝、登记可修订说法 | 单页对话没有持续操练，也没有天然的权势/供给风险 |
| 正常战斗与卡牌界面 | 产生重复、可中止的真实行动和失败材料 | 敌人不是理解陈述的受众；额外牌或禁用资源容易退回一般战术增益/限制 |
| 奖励、休息点、路线选择 | 有真实机会成本且复用成熟界面 | 多数是私人优化；跳过本身没有练成替代能力 |
| 商店 | 有供给者、支付与依赖关系 | 已是柏拉图核心候选，复用会模糊人物；原生保存和自定义交易成本也仍未解决 |
| 第三幕Question/Switch或停留结点 | 可让玩家陈述并承担后继选择 | 必须引用局内已发生的事实，不能由结尾补写不存在的公众检验 |

没有一个低成本原生界面能单独诚实承载三者。允许的方向是同一条因果链的两层呈现：正常游戏时点承担操练/自足，既定Question或后继选择承担有接收者的表达；两层必须共享同一具体对象与事实记录。若需要额外街市、统治者、群众或专属场景才能让表达成立，先登记制作成本并重新选载体，不用文字声称已经发生。

### 对下一设计的硬条件

下一步只选择一个可在所有正常局面出现的训练材料，并同时回答：

1. 玩家原先具体依赖什么，为什么不是作者替玩家虚构的依赖；
2. 不禁止资源、不送数值补偿时，玩家练成的替代动作是什么；
3. 该动作在何种局面失效，玩家如何合法恢复或修订；
4. 后继哪个既有角色/关系能理解这段行动，表达会失去什么或改变什么；
5. 只做最优战术、被迫贫穷、为了表演而简朴时，系统怎样不误判为犬儒实践。

在这五项有共同材料前，不命名主能力、不画图标、不做原型。D134完成的是关系研究和载体边界，不是完整人物设计。
