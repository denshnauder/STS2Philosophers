# 第欧根尼人物设计

## D129当前问题与归属

当前为独立研究/载体审查，未形成批准能力。按既定18/19及EDGE010：第二幕问号转入德性与幸福的实践；可拒绝、停留并成为合法终点。第三幕若选芝诺，公开犬儒传统/克拉特斯中介，不伪造直接师承、不把停留算失败。六入口、89人用途、现有图边与東哲/公开ID不改。

**我能否修订对外物的需要，并在实际处境中保持这种生活，而不是借简朴换另一种奖赏或名声？** 这是游戏问题候选，不冒称本人原句。依据与争议见[[03研究与资料/西方哲学史/24第欧根尼自足与操练]]。

## 制作前置

优先既定Question邀请/标准事件或现有战斗、奖励界面，先选择具体载体再谈能力。新增街市、桶屋、群众、行走/挑衅动画均不默认获准。原生事件界面可承载选项，但正文声称有受众不等于已经有真实资源关系与可读呈现；新增事件图与角色静态素材也有成本，需要明确来源与数量，不假设AI可解决。

正式节点、操作、界面、素材/动画预算目前未定，不接生产。研究页不注册ModelId或资源，未选能力时不先生成命名/图标/脚手架。

## 必须区别的三件事

1. 自足：实际识别一种依赖及可用替代，承担简化后的机会成本，并允许事实推翻最初判断。减少库存计数不充分。
2. 操练：跨时点检验可持续方式和恢复，受苦本身不发认证或奖赏。不能把普通保留/跳过奖励贴成已经完整的哲学实践。
3. 公开：谁观察什么、为何有影响必须明确，程序记录与观众认知分开；为演简朴赢赞赏可能重新依赖评价，不评分真实动机。

与柏拉图无名环区分：前者考察真实需要与实践，后者材料是归责解除后的所有权/付款。不是把购买换成丢弃再重复同一资源对比；后继能质询明确说法，不要求承认游戏的付款标准才能见第欧根尼。

## 当前否决与未定

- 丢药水/金币自动获得力量、格挡或抽牌：资源交换或贫穷计分，未表达依赖修订，不推进。
- 普通删牌直接称自足：可能是为最强牌组优化，无明确依赖和后续检验，不直接采纳。
- 只选择直言台词：无实际受众/可见关系/代价，不能充完整循环。
- 用新增NPC任务或桶屋探索补表达：制作预算未定，不自动扩场景。
以上否决的是现有简化接法，不等于哲学概念不能游戏化。须先找到可成立的载体。

## 准确下一步

比较两个少素材既有载体：战斗中的实际用具依赖与替代操练，标准问号事件的可持续需要修订；逐项写节点/操作/界面/素材/动画、实际代价与恢复、是否要求新增群众或伪造观察、是否只是资源换增益。先选一个完整决策循环，或明确两者都不成立；不先编码。柏拉图商店保存/真实界面人工样本独立等待，不用其高风险接口限制本人物设计。
