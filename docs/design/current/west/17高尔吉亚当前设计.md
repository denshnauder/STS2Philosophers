# 高尔吉亚当前设计

## 三分钟摘要

- **当前结论：** ENC-111 的主要用途是第一幕语言与意义路线的一次问号“封箱与说辞”。取得亚里士多德范畴石板、实际完成战斗且本幕问号未用的玩家，可检验一段话如何促成行动，却不能因此证明被谈论的事物已被查明。此处是后世同题对照，不宣称高尔吉亚直接回应亚里士多德；运行图没有高尔吉亚边，事件只占问号而不改节点。
- **玩家流程：** 有封条的箱子标着“粮食”，无人打开验看。玩家决定向等待分配的人群说“粮食已经到了，可立刻分配”，或只说“箱上写着粮食，内容未核”。看到人群的相应反应后，选择把赞同或延迟当作内容证据，或只承认言辞改变了信念；最后记录有限追问或保留原有范畴判断。
- **核心取舍：** 强断言便于迅速协调，却背负未核实的事实承诺；谨慎表述保留证据边界，却无法立即推动分配。人群赞同与箱中真实内容是两个事实，反应不会被系统判成哲学正确答案。
- **界面与素材成本：** 一个原生标准事件、短页和既有静态背景别名；封箱与人群仅由文字呈现，不新增NPC、箱子模型、动画、资源奖励或地图节点。
- **已完成：** 第一幕范畴石板是既有合法入口；本路线没有已启用的第一幕语言问号，既有032边保持禁用。事件、双语、严格保存恢复和十条路径已通过逻辑检查；Release 零警告零错误，原生地图房间、RitsuLib 0.6.2／本机0.6.7与PCK检查通过。已与阿那克萨戈拉合批安全部署0.5.8，安装三文件哈希与构建输入一致，回退点见[开发说明](../../../../DEVELOPMENT.md)。
- **未完成：** 未进行渲染UI或完整实机局试玩；玩家反馈另按实际情况处理。
- **准确下一步：** GitHub 批量收尾后关闭 ENC-111，按 Linear 真实顺序继续，不恢复禁用的032边。

## 来源和解释边界

[高尔吉亚《海伦颂》原文入口](https://atlas.perseus.tufts.edu/library/urn:cts:greekLit:tlg0593.1st1K001/)讨论言辞改变听者信念的力量；[SEP《Sophists》](https://plato.stanford.edu/entries/sophists/)同时介绍其演说与《论非存在》的后世报告。后者的“存在、认识、传达”三层论证有残缺文本和解释争议；本事件只取“言辞使人赞同不等于观察对象被证实”的有限问题，不断言高尔吉亚本人相信世界不存在，也不把他写成普罗泰戈拉或塞克斯都的同一个怀疑主义者。[SEP《Plato on Rhetoric and Poetry》](https://plato.stanford.edu/entries/plato-rhetoric/)可帮助区分柏拉图后来对说服与知识关系的批评；游戏不把该批评冒充高尔吉亚自己的承认。

亚里士多德的范畴石板在玩家这一局先出现，只提供识别物品标签和分类的游戏起点。历史上高尔吉亚早于亚里士多德，事件是玩家跨人物比较，不是确定师承、会面或高尔吉亚批评石板的史实。现有语言032通向索绪尔已禁用，不能为本人物恢复或改写；独立问号不创建高尔吉亚节点、图边或后继资格。

## 完整决策循环

1. **机会：** 单人第一幕，当前 `ARISTOTLE__LANGUAGE_AND_MEANING__CORE`、持范畴石板、完成至少一场本幕战斗、第一幕问号未处理且原生地图安全返图时邀请。先预约并保存本幕问号；拒绝也消费机会。已有保存仅在同一事件房间严格恢复，不能让旧按钮改选。
2. **一次说辞：** 唯一已知事实是箱上标签与完好封条，内容无人查看。玩家选“粮食已到，立刻分配”或“标签写粮食，尚未开验”。前者得到迅速赞同但承担未经核实的事实与行动风险；后者保留核验空间但无法用这句话立即促成分配。两条叙事反应保存在事件状态，不给资源、数值或隐藏正确奖励。
3. **解释人群反应：** 强断言后可把赞同当作箱中确有粮食的证明；谨慎说辞后可把等待验看当作箱中无粮的证明。两条路径都可只承认言辞改变了人群的信念。事件分别指出证据跳跃或留下内容未核的缺口；人群要求先开验也不能被当成箱中为空。此处是玩家选择的一种推论，不宣称高尔吉亚提出了每个选项。
4. **承担结论：** 玩家可记录“言辞的效力与对象的知识须分开”，或只保留范畴石板的原有实践；可提前中止。所有结果保持当前人物节点、遗物与战斗规则，只消费一次问号，不改变六入口或89人用途。
5. **失败与恢复：** 先保存待提交动作，再提交同一状态并保存确认；原生 `EventRoom` 与RitsuLib共享槽两者精确读回。旧档缺字段、未知枚举／版本、错误路线或已占机会保持冻结，不清空重邀。关闭后继续同一地图；不自动打开游戏或触碰玩家存档。

反例：封条完好不证明箱中有粮；人群被说服不证明陈述为真；谨慎说法不保证粮食不存在；一次高尔吉亚问号不能证明“无物存在”、让语言必定欺骗，或削弱现有石板战斗实践。
