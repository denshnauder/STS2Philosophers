# 边沁当前设计（ENC-149）

## 承接位置

- 主用途：固定。路线「后果与自由」：苏格拉底／德性开局 → 第一幕边沁 → 第二幕密尔 → 第三幕罗尔斯。
- 图：新增节点 `BENTHAM__FREEDOM_AND_INSTITUTIONS__CORE`；新增边 065（苏格拉底→边沁，第一幕固定）、066（边沁→密尔，第二幕固定）、067（密尔→罗尔斯，第三幕问号 Switch）。
- 第三幕沿用问号收束，不新增固定边；密尔与罗尔斯节点原已存在。

## 玩家流程

第一幕在苏格拉底节点完成至少一场普通战斗后，地图边界插入本事件：

治安官带来苦乐账本，一次重伤可被许多小便利抵消。三个选择：

1. **把总额加起来**：采纳 065，进入边沁节点。
2. **保留个体边界**：同样采纳 065，记录边界标准。
3. **留在苏格拉底**：放弃本幕固定承接，停留在苏格拉底节点。

结算页各有一句后果说明，随后「离开办公室」关闭事件。

## 状态与保存

- `BenthamUtilityState`：阶段、待确认动作、已确认动作、标准（总额／边界／苏格拉底）、是否采纳边、是否放弃固定幕、是否关闭；严格版本与重放校验。
- 随 `PhilosophyRunState.BenthamUtility` 保存；旧档缺属性时为 null，不补发。
