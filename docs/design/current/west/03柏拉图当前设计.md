# 柏拉图当前设计

## 三分钟摘要

- **当前结论：** 当前可玩柏拉图用途是第二幕“两项职责”；守灯、旅人、课程、匿名交易和其他历史载体继续作为实验或反例，不是第二套当前入口。
- **玩家流程：** 完成普罗泰戈拉共同商议后，玩家面对一项可独立完成和一项依赖前者交付的职责；可以先取得独立成果，也可以先承诺依赖项，并在同伴回应后履行、撤回或交还选择权。
- **核心取舍：** 独立成果与共同安排不能同时由玩家单方控制；事件记录安排如何发生，不把任何结果认证为正义或灵魂有序。
- **界面与素材成本：** 一个标准事件、复用背景和短选项；不新增商店事务、场景、动画或新的战斗遗物。
- **已完成：** 触发、状态、四条完成路径、两种未完成结果、保存恢复、双语文案、验证、构建和部署均已完成。
- **未完成：** 守灯与旅人没有正式节点和可承担素材方案，禁止接入生产。
- **准确下一步：** 柏拉图人物任务先核对当前职责事件与历史实验的边界，不从旧“下一步”复活被否决载体。

## 研究读取边界

- 匿名取用、声誉与补价只曾服务“德性／正义后继”的反例：它们可以同时暴露私人所得与他人损失，但不能靠一次付款宣布正义问题已经解决。
- “自由／制度入口”是另一用途，必须在玩家受益前公开共同规则、显示例外与排除，并让规则也约束玩家；不得复用匿名交易、德性资格或私人灵魂判断。
- 灵魂秩序不能由资源结算、胜负或程序诊断。两种用途只共享已发生行动、受影响者、公开理由和不可读心这些事实，不共享主机制、资格或完成语义。
- 项目的跨时代“自由／制度”标签不等于把《理想国》对民主的批评当作现代制度结论，也不推出“约束越多越正义”。
