# 休谟「先行修理」代价修复（ENC-134 / Sol P2）

## 缺陷

选项「先行修理」与结果页承诺「失去一次即时商店折扣」，但 `HumeInductionState`、`HumeInduction`、补丁与遗物链都没有读取该结局、改价或保存折扣债务。本 Mod 只有 `WesternPracticeRelic` 的卡牌练习费用折扣，与商店价格无关；游戏侧折扣是 `MembershipCard`＋`_discountKey` 的「遗物＋价格键」形式，没有现成的一次性折扣开关。

## 裁决与实现

设计方 2026-10-30 决定改用既有金币代价协议兑现（与贝克莱第二观察者同款）：

- `HumeInductionState` 实现 `IEventGoldCostState`，`RepairFirstGoldCost = 75m`，仅 `ResultRepair` 结局 `Cost = 75`，其余结局为 0；新增 `CostAttempted/CostPaid/CostGoldBefore/CostGoldAfter` 快照字段。
- 事件在提交 027 与持久化之后调用 `EventGoldCostProtocol.ApplyAsync`（`PlayerCmd.LoseGold(75, Spent)`），进入房间时对已保存的 `ResultRepair` 重试未结算扣款；金币不足 75 时「先行修理」选项不显示，`Choose` 二次校验。
- 中英文案同步为「花费 75 金币」，不再承诺商店折扣。

## 语义

- 幂等：`CostPaid` 为真后协议直接返回，重进房间不重复扣。
- 旧档：无快照的旧记录按协议既有规则失败开放（settle 为已付），不二次扣款。
- 其它结局（保留预测、收回必然性、保留洛克）不扣金币。
