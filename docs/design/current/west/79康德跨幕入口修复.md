# 康德两个第三幕入口修复（ENC-141）

## 缺陷（Sol P1）

`KantApperceptionPatch`（查休谟）与 `KantUniversalizationPatch`（查卢梭同意）都用 `HasCompletedCombatAfter`，只读 `MapPointHistory[CurrentActIndex]`。前驱在第二幕、入口在第三幕，正常历史里找不到前驱，两个承诺入口都被拒。

原生夹具把休谟／卢梭同意放进第三幕历史，违反各自幕数限制，掩盖了缺陷。

## 修复

- 两处改用既有 `HasCompletedCombatAfterAcrossActs`（黑格尔、休谟等房间同款）：跨幕找前驱，仍保留本幕战斗、真实前驱身份、已完成边、原生问号、visited、预算与保存门。
- 两个原生夹具改为真实三幕历史：前驱在第二幕，第三幕为本幕战斗。
- 未搬动前驱幕数、未补造历史、未改图。

## 证据

- 修前：修正夹具 + 旧 helper → `Real native PullNextEvent selects KantApperception, got AbyssalBaths.`，原生套件 exit 1。
- 修后：同一夹具 → 原生套件 exit 0（含真实 PullNextEvent 选中两个康德事件）。
- ModLogicChecks 全绿；主工程 build 0 error；内容 PCK 构建通过。
