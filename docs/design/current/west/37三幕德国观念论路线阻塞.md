# 三幕德国观念论路线阻塞说明

## 现状

当前可执行路线为：

`AUGUSTINE` → 021（第二幕 Question／Switch，卢梭自由）→ 022（第三幕 Fixed／Adopt，康德自由）→ 037（第三幕 Question／Revise，费希特内批）。

图上的后续边是：

- `WESTERN_EDGE_038`：康德自由 → 黑格尔历史，第三幕 Fixed／Adopt，要求 037。
- `WESTERN_EDGE_039`：黑格尔历史 → 马克思早期，第三幕 Question／Switch，要求无额外边。

问题在于 022 已经消耗第三幕固定槽位；037 作为第三幕问号只完成修订，不会释放固定槽位，因此 038 的 `LastFixedAct < 3` 条件永远不成立，039 也随之不可达。当前费希特实现因此是“第三幕问号修订”，不是完整进入费希特节点，也没有把 038/039 计入交付。

## 设计资料中的原始序列

`config/western_research.json` 的 `original_sequence` 写的是：

`第一幕固定卢梭（历史与权力）→ 第二幕固定康德 → 问号费希特 → 第三幕固定黑格尔 → 问号马克思早期`

这与当前 022 的第三幕不一致，说明 022 的幕数或进入路径在既有实现中被压缩过。

## 可选方案

### A. 把 022 移到第二幕（推荐，但需产品确认）

- 021 在第二幕 Question 后，022 作为第二幕 Fixed 进入康德自由；037 第二幕 Question；038 第三幕 Fixed；039 第三幕 Question。
- 需要同步修改：`config/western_graph.json` 的 022 `act`、`KantUniversalization` 的触发/实例/本地化“act-three”文案、纯逻辑与原生测试、费希特事件从第三幕改回第二幕。
- 影响：已完成的旧存档若已在第三幕完成 022，新版本需要迁移或允许旧状态；属于既有已部署事件的时序变更，不能由实现方单方面决定。
- 验证：图样本、Kant/Fichte/Hegel History/Marx 四段事件、原生边界、PCK。

### B. 保持 022 第三幕，把 038/039 压成 022/037 的连续结果

- 不新增固定/问号槽位，把黑格尔历史与马克思早期写成同一事件房内的连续页。
- 需要重做 038/039 的图语义与事件边界，玩家看不到独立地图节点；与“固定/问号”既定用途冲突较大。
- 不推荐在未确认产品语义前实现。

### C. 扩展幕数或新增入口

- 超出当前三幕结构与冻结版本范围，不能作为本批补丁。

## 当前结论

- 未改 022 幕数、未启用已撤下的 036、未把 038/039 伪造成可达。
- 费希特 037 按第三幕内批修订交付；038/039 记录为阻塞。
- 需要人工选择 A/B/C，尤其是 A 对既有存档和已部署事件的影响；确认后才可继续 038/039。
