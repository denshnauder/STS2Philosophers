# 赫拉克利特当前设计

## 三分钟摘要

- **当前结论：** ENC-105 将既有琴弓收口为“同一尺度下的攻守对张”：每回合只标记起手抽牌中首张非消耗攻击或技能牌；它可保留一回合。本回合先手动打过相反类型，再打标记牌，才消耗它并抽1张；直接打出则正常结算。
- **玩家流程：** 涅奥后九人池抽到赫拉克利特时，可以看过效果后接受琴弓、返回三位邀请者或拒绝。战斗中从敌方意图、费用与手牌判断：直接使用、先打相反类型再释放，或把标记牌留到下回合。
- **核心取舍：** 直接使用保住牌组循环，放弃本回合换牌；对张后释放得到当下效果与抽牌，但本场战斗失去该牌；保留保存确定手牌，却放弃当前效果和换牌。没有额外伤害、格挡或永久收益奖励“更懂哲学”。
- **界面与素材成本：** 复用琴弓图标、原生卡牌保留提示与遗物悬浮信息；计数1表示已标记、2表示已具备相反类型，悬浮展示对应卡牌。无新场景、事件、动画、人物画或新框架。
- **已完成：** 新规则、中英文与原生提示、每回合一次门控、同名实例区分及旧载荷兼容检查均完成；2026年10月16日通过逻辑、Release、PCK 与安全部署，已可从原有第一幕邀请进入。
- **未完成：** 本轮未进行人工实机体验；自动检查不证明乐趣、平衡或全部兼容性。后续问号、回响和其他人物只有获得合法载体与独立授权后才接入。
- **准确下一步：** 本票开发交付结束，回到 Linear 查询已授权队列。后续实机体验问题独立登记反馈，不把普通试玩作为开发闸门。

## 研究边界与思想转译

既定用途仍为“存在与变化”的固定入口，兼任问号与回响；不改变六入口、七问题、89人用途或九人池。问号／回响不等于额外生成一次赫拉克利特事件；既有关系没有接入的后继，不在本票补造师承或节点。

[斯坦福课程的残篇译文](https://web.stanford.edu/~jsabol/sophia/heraclitus.html)可定位 B1／B2 的共同 logos、B12 的同一河流与不同水、B51 的弓琴对张。这些是后世引述的残篇，不是完整著作，也不能直接推出卡牌规则。[SEP 的讨论](https://plato.stanford.edu/entries/heraclitus/)提示变化、对立与统一的解释有争议。以下是游戏创作：变化依赖一条对攻、守同样适用的公开尺度，保持与释放都成立，不把 logos 当成奖励点数，也不宣称攻击和技能穷尽哲学中的对立。

旧规则只要求消耗标记牌换抽牌；单纯多消耗牌不足以表达对张。新规则把先后顺序引入同一决策，同时保留不换牌的正常出牌出口。与苏格拉底德性分支的“一场战斗自行选牌并累积等待减费”不同，琴弓绑定每回合抽牌中的具体实例，不累积等待收益。

## 完整决策循环

1. 每个自己的回合，起手抽牌中第一张进入手牌、当前不带消耗的攻击或技能牌成为标记牌；能力、状态、诅咒、牌效抽牌、生成、直接移入手牌以及已有保留牌不占机会。原生 `fromHandDraw` 只表示回合开始抽牌，本票沿用这个既有资格。
2. 遗物悬浮显示该实例；牌上可见原生保留。攻击与技能是相反类型；本回合已结算的手动相反类型即可构成对张，能力和自动打出不计。相反类型可以在标记出现前打出，尺度不因抽牌时点改变。
3. 标记牌直接手动打出：若未形成对张，按原牌效果与原去向结算；若已形成对张，结算后进入消耗堆，并额外请求抽1张。换来的牌不能再次获得本回合机会。
4. 标记牌未打出且仍在手中：回合结束保留。下回合它成为普通旧手牌，不继续保留或享有消耗换牌资格；新回合仍从起手抽牌选一次。
5. 标记牌被弃掉、移出或自动打出：机会结束，不返还，也不转给同名副本。没有相反类型、费用不足或不愿消耗时，直接使用与保留都仍合法。
6. 战斗结束清空临时记录，不改牌组永久卡牌、当前主说、路线历史和后继资格。当前未登记合法后继时正常继续地图，不补占位人物。

## 具体取舍与反例

- 首张为攻击，敌人重击而手牌只有一张1费防御、共1能量：可以防御并保留攻击；不能因为2亮起就获得免费能量或暗中打出标记牌。
- 首张为攻击，敌人已能一击击杀：直接攻击即可结束战斗，不必先打无用防御追求换牌。省下的牌保留在原生弃牌循环，事件不评判选择优劣。
- 首张为防御，敌人重击但你必须先攻击才能满足对张：直接防御可保住牌组循环；先攻再防御会多耗能量和一张本场防御资源。不能用常驻增益抹平代价。
- 没有攻击或技能可相反配合、满手、禁抽或抽牌不足：原生限制照常，抽1只是一次请求，不补发、不欠账，不为保障奖励生成牌。
- 零费相反牌仍须是玩家真实打出；允许现有牌组协同，但至多标记一次，不能串成无限“首张”。重复结算、复制效果与自动打出不增加机会或换牌次数。
- 同名副本不是同一张牌；丢弃后再抽同一实例也不重建机会。载入时无法唯一辨认标记实例就停用本回合标记，不猜测绑定另一张同名牌。

## 实现与恢复约束

保留公开 `HERACLITUS_LYRE`／`HeraclitusLyre`／`heraclitus_lyre`，新增提示沿用 `HERACLITUS_LYRE.*` 本地化键。复用原生 `SavedProperty`、现有 `PracticePayload` 和原生保留、出牌去向、悬浮钩子；RitsuLib 仍是唯一主框架，不新增通用保存层。

先核对锁定的 RitsuLib 0.6.2 和当前游戏公开接口：原生在 `BeforeCardPlayed` 之前确定结果牌堆，所以不得在该回调才设置消耗；使用原生出牌结果去向钩子，并在打出前决定一次。状态确认抽牌机会已消费后再请求抽牌，防重入与复制补发。

旧版本1载荷继续可读，新增字段仅保存赫拉克利特本场临时规则。缺少新规则记录的旧活动回合暂停旧标记效果，到下一个真实回合再按新规则开始；不删除牌、不改公开遗物身份，不直接改写玩家存档文件。损坏状态不发新奖励，其他六问题的语义和保存格式版本不变。原生退出读档不提供任意战斗现场快照，不把独立 Codec 往返当成整场战斗恢复已验收。
