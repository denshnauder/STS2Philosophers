# 贝克莱第二观察者代价修复（ENC-133）

## 缺陷

Sol 复核指出：第二观察者分支只显示「花一次商店采购机会」，没有采购资格检查、扣减或可兑现债务。

## 修复

- 仓库没有「商店采购次数」接口，改用既有 `EventGoldCostProtocol`（六个既有房间同款）兑现代价：第二观察者固定 75 金币，即一次商店采购的等值花费。
- `BerkeleyPerceivedMarkState` 实现 `IEventGoldCostState`：`Cost` 只在结论为第二观察者时为 75，其余分支为 0；保存扣费快照，重复回调与读档重入不重复扣费。
- 金币不足时该选项不显示；事件入口若发现已结论为第二观察者但扣费未结算，会补结算一次（协议内的三种状态：已扣、未扣、旧记录歧义）。
- 中英文案同步写明 75 金币。

## 验证

ModLogicChecks（含新增：观察通道零成本、第二观察者 75、只扣一次、重放不重复扣）、主工程 build 0 error、RunNativeRuntimeChecks exit 0、内容 PCK 构建通过。

## 未验证

未实机进商店核对扣费后的购买行为；未部署；版本 0.5.24。
