# 芝诺当前设计

## 三分钟摘要

- **当前结论：** 芝诺是第欧根尼 Switch 后保证出现的第三幕终点，处理眼前印象、同意范围、实际行动和后来结果之间的关系；成功不反推判断正确。
- **玩家流程：** Switch 后至少完成一个非路线房间，系统在安全地图边界、Boss 前或离幕前兑现事件。玩家回看冻结的真实材料，然后保留、缩小、撤回理由，或在缺少合法材料时拒绝补写同意。
- **核心取舍：** 转向芝诺已经放弃第欧根尼完整结局；芝诺允许修订但保留公开历史，不发数值奖励，也不改变当前战斗能力。
- **界面与素材成本：** 一个标准事件和一张1600×900静态图；无新地图、敌人、动画、主说遗物或常驻面板。
- **已完成：** 状态、事务、严格编解码、旧档与损坏隔离、事件页面、触发、关闭续行、正式入口、素材、验证、构建和安全部署均已完成。
- **未完成：** 裁切、文字节奏、选择价值和平衡感属于之后的玩家反馈，不阻塞当前交付。
- **准确下一步：** 芝诺的新修改只由 Linear 的 Bug、Improvement 或 Design `Todo` 触发。

详细状态与设计证据见 [芝诺德性设计](../../ZenoVirtueDesign.md)，玩家流程见 `README.md`，实现事实见 `DEVELOPMENT.md`。
