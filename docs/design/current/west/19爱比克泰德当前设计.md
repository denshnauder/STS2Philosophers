# 爱比克泰德当前设计

## 用途与史料边界

既定主要用途为「实践」，兼任问号和回响。先前[研究](../../../research/west/00希腊化与罗马哲学.md)否决了“第四幕节点”、只读总结页和在结果后点击“接受”的替代品；原版仍没有第四幕。本次在已验证的第三幕原生安全返图边界设计一个多步行动事件，不添加地图节点、斯多亚升级遗物或第二次芝诺同意结局。它只在芝诺结局和塞涅卡回看都已保存关闭后出现，仍需有合法安全返图点。

[《手册》1—2](https://classics.mit.edu/Epictetus/epicench.html)区分自身判断／行动与不由自己保证的外在结果，同时仍要求谨慎地行动；[《手册》30](https://classics.mit.edu/Epictetus/epicench.html)把适当职责放在具体关系中。[《谈话录》3.2](https://classics.mit.edu/Epictetus/discourses.3.three.html)把行动冲动、关系中的适当行为与同意练习并列。本事件只借这三重问题构造尖塔中的一位同行者，不声称原典记载了游戏情节，也不把生命值、获胜、少拿奖励或“接受”按钮当作德性的判据。

## 同行者与两次行动

一位同行者请玩家带他经过一道不稳的窄门。玩家先在职责范围内作一个可见行动：**先告知已观察到的风险并给出有条件的引导**，或**径直承诺带他通过**。两者都实际向同行者说出并开始履行；后者把不能保证的结果说成保证，不因此被扣血或自动评为恶。门在途中关闭，同伴没有跟随；这是明确呈现的外部回应，不根据玩家此前的血量或随机奖励推算。

事件随后回显玩家自己说过和做过的事、门与同伴的独立回应，再要求第二次具体行动：**回去向同行者说明改道并陪他寻找已知安全的出口**，或**先给后来者留下风险标记，再返回履行引导**。两个动作的先后与对象不同，均继续承担引导责任；都不能让门重新开启，也不能保证同行者一定接受帮助。最后回显具体行动和关系的未完结性，不给“完全自由／完全正确”结论。玩家也可在承担前谢绝引导；事件仍仅出现一次。

这与柏拉图的轮流执印不同：没有公共决定权或署名分配；与塞涅卡不同：不是回顾过去的检查习惯；与芝诺不同：不重判一份旧说法。它让行动先于外部结果、结果之后仍有后续行动，补足此前单页回响方案缺失的三段因果。

## 接入、恢复与成本

- 第三幕、单人、芝诺 `ZenoClosed`、塞涅卡事件确已关闭且同一局身份，原生地图安全返图；一次局内一个标准事件，复用现有静态背景，不占原始图节点。
- 冻结芝诺结果及塞涅卡关闭的身份作资格证据，不篡改两者记录。玩家在事件内做的两次行动按顺序写入有限、可回放的存档状态；每次选择先保存待提交动作，再确认保存并开放下一页。旧档无本事件即未出现，未知或矛盾存档停用，重复回调不能改写前一动作。
- 页面最多三项原生按钮；无战斗数值、额外抽牌、金钱、生命、路线边或地图旅行干预。两次行动及外部回应是本事件的可玩实践，而不是保证外部结果的机制。
