# 库恩：异常与范式（第三幕收束）

## 位置

知识与怀疑线：苏格拉底第一幕（塞克斯都问题）→ 牛顿第三幕固定（有条件的两处试验）→ 库恩第三幕问题（本房间）。第三幕沿用「一个固定、一个收束问题」的既有形状（与培根→孔德同构），不新增第四幕，也不占第二幕。

新增图数据：节点 `THOMAS_KUHN__KNOWLEDGE_AND_DOUBT__CORE`（库恩：异常与范式），边 `WESTERN_EDGE_090` 牛顿→库恩，第三幕 Question / Switch / 高置信，`required_edge_ids: ["WESTERN_EDGE_049"]`。

## 房间

两页，先取证再决定，避免把单次异常直接当作换掉整套方法的理由：

1. 测量页：`CHECK_INSTRUMENTS`（按旧范式校准仪器，记一处异常、无不相容维度）或 `STUDY_NEW_CLASSIFICATION`（记两处无法与旧规则同测的维度）。两者都只记录，不改变路线。
2. 决定页：
   - `KEEP_OLD_METHOD`：保留旧法并公开异常档案，拒答本幕问题，零金币。
   - `TRAIN_TEAM`：花 75 金币训练队伍使用新量表，采纳 090 进入库恩节点，消耗本幕问题位。
   - `OBSERVE_IN_PARALLEL`：并行观察一轮后拒绝宣布胜负，拒答本幕问题，零金币。

## 代价

75 金币沿用本 Mod 现有标准代价单位（贝克莱第二观察者、休谟先行修理）。这是**设计替换**：原设计稿只写「失去先前短期收益」，没有给出可结算的商店价格接口；本 Mod 唯一的即时代价通道是金币，故以 75 金币结算，等待设计与独立验收确认。金币在已提交选择持久化之后才扣，`EventGoldCostProtocol` 负责一次扣费、重入重试与「已付不再扣」。

## 边界

- 异常本身不构成范式转换的理由；`TRAIN_TEAM` 必须先记录异常与不相容维度。
- 并行观察不得宣布任一方已胜，也不得进入库恩节点。
- 不新增遗物、不改动牛顿／孔德既有交付内容。
- 库恩节点不给通用奖励，路线收益由房间自身选择结算。
