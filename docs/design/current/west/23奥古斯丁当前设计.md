# 奥古斯丁当前设计｜ENC-119 候选规格（待入口与玩法验证）

> **阶段：** 人物玩法候选，尚未获准接入生产；未实现、未构建、未部署。严格保留第24位「固定」，兼「转线、内批」及既有图边，不因本设计关闭 ENC-119。现行主线资料以仓库 docs、config 与 Linear 任务为准。

## 三分钟摘要

- **本轮问题：** 在「自由与制度」路线，玩家先公开说出愿意维护的公共义务，后来遇到自己队伍的迫切需要，必须在资源限制下实际做出决定。意愿、行动和结果分别记录；不把一次履约等同神圣品格，也不以反悔证明意志完全不自由。
- **暂定事件：** 《诺言与迟疑》。一次原生标准事件中的「公开承诺 → 新事实 → 资源分配与确认」，最多三页关键操作。共用施工队只有一班工时；玩家可以花自己的金币另请帮手完成未选的一项工作，但金币不足也必须能正常结束。
- **与其他事件的区别：** 「第一阶段说要做什么」不产生效果；「第二阶段实做什么」受真实资源和新事实制约。不能在最后一页回写一条从未履行的承诺。必须有实际游戏效果，至少私人补给的 HP 恢复与可选的金币消耗；公开维护对玩家的价值仍需可玩性审查。
- **生产边界：** 不新增地图节点、战斗能力、卡、遗物或场景动画；允许复用标准 EventRoom、一个静态背景和现有金币/生命机制。最多一个持久化事件状态对象。

## 一、原典边界与历史中介

1. 《忏悔录》VIII.9–10 描述同一人的意愿发生冲突及习惯的拘束，不能写成肉体灵魂两套互相独立的操作者；「我赞成」与「我做到了」也不能自动视为一回事。
2. 《上帝之城》XIX.17 认为地上公共和平与日常生活秩序有真实用途，不应借「更高目的」将公共事务写成毫无价值。XIX.24 重视一个共同体以何种共同的所爱聚合；**制度能维持秩序**并不自动说明其终极目的正确。
3. 两城不能简化成「国家=恶／教会=善」，玩家也不由事件界面获得灵魂、救赎或恩典判定。奥古斯丁所说的恩典不能译成「玩家支付20金币即赚得恩典」。
4. 奥古斯丁接受并改写新柏拉图主义；现行图边020的中介应写「新柏拉图文本传统」，不假装柏拉图与他历史上面对面，也不从本轮普罗提诺候选自动推断他读过某一特定拉丁译本。该接受关系不等于直接继承普罗提诺的流溢学说。

**研究校验：** [《忏悔录》卷八（英译）](https://www.newadvent.org/fathers/110108.htm)、[《上帝之城》卷十九（英译）](https://www.newadvent.org/fathers/120119.htm)、[SEP：Augustine of Hippo](https://plato.stanford.edu/entries/augustine/)。上述文献只支撑哲学问题和历史边界；工队、货车、金币以及选项全部是游戏创作。意志、习惯、自由与恩典的关系在研究中有争议，本候选不作单一体系的最终裁断。

## 二、原生事件《诺言与迟疑》

**现场（虚构）：** 旅途中的公共水道闸门损坏，过路人都需要通行；玩家同行的货车也有急需修复之处。当地帮工今日仅剩一班工时，能完成一项。公告牌要求先登记优先事项，随后玩家才得知同行者的车轮已出现更严重的裂缝。两项事务都有实际价值，公共修理不代表永恒和平；照顾同行者也不自动是自私。

### 1．公告：先表态，未执行

完整展示共用帮工仅有一次机会、可做的两项工作及可能的私人花费；暂不展示后来的车轮严重程度。玩家可选择：
- **「先保公共闸门」**：登记公开优先修理水道。
- **「先保同行者的车」**：登记公开优先修理自己的队伍。
- **「我暂时不作承诺」**：公开承认信息不足，但并不终止公共任务；仍需在下一页决定帮工实际做什么。
以上只是公开表态，**不扣钱、不恢复 HP、不写入完成事实**。界面保留一句「刚才登记的优先事项」作为可见对照。

### 2．补充事实：再行动，开始真正付代价

告知玩家车轮裂缝恶化、若不先修队伍将错过一次实际补给；公共闸门若不修，其他旅人要自行解决通行。只展示确定可见的事实，不把队伍伤情描写成对玩家的惩罚。

使用**同一班帮工**只能选择一次：
- **「让帮工修公共水道」**：记为公共修复已完成；本事件不获得私人恢复。若玩家曾承诺先修货车，结果必须明确显示改变主意。
- **「让帮工修同行货车」**：当场恢复玩家至多 8 点生命值（上限为缺失生命值）；记为私人修复已完成。若先前承诺公共闸门，明确显示公开承诺尚未完成，不能替玩家编造已履约。
- **「两项都先不处理」**：不使用帮工，保留双方未完成事实；本次邀请结束，不提供之后反复刷奖励的入口。这个选项须让玩家看清弃置一次工时的后果。

确认本次帮工去向以后，**任何退回或读档都不可再挪动已提交的工时**；确认前可以返回上一页调整，但不得因返回产生效果。

### 3．补救：可选付费，不以意图替代实际工作

若实际完成了其中一项，可以追加花 **25金币（暂定平衡值）** 雇人完成另一项：
- 金币足够时显示「支付25金币，完成另一项」，金币扣除一次并写入该项完成事实。
- 不足25金币时显示「没有足够的钱另请帮工」，可选择「如实说明并离开」，不能自动扣成负金币、假称完成第二项，也不能变相奖励贫穷。
- 无论支付与否，始终可以「结束」，明确展示最终做成的公共/私人事项、花费和最初承诺是否兑现。

私人修复在满血时数值收益为零，必须原样展示而不可虚报疗效；审查若发现玩家普遍无法感到「公私两者均值得做」或某选项恒优，则在 ENC-119 内重新审查奖励结构，**不得因为流程能跑就直接实施**。不提供「道德分」「虔诚信仰」「恩典值」等隐藏变量。

### 4．结尾与玩家价值

- 公开表态和实际使用帮工是两段**不同的历史事实**，可以一致也可以背离；两项都完成的玩家也已经支付了现实成本。
- 「不作承诺」仍允许具体作为；「作出承诺」也不保证会履行。不得由系统判定「没有承诺的人更诚实」或「公共优先的人必定更善」。
- 结尾只展示已经发生的安排、旁人的处境与未解决的义务；不发宗教救赎宣告。若没能提供有分量的公共/私人取舍，这个候选应被否决，而非以更多哲学台词粉饰。

## 三、与既有人物的实质区分

- **柏拉图《两项职责》：** 核心是分配独立/依赖职责和他人的决策权。本事件聚焦**一个人公开意愿和实际执行的裂缝**，不转移整个共同体的治理权。
- **普罗提诺《同源而非同形》（候选）：** 讨论共同解释依据及多种表现，本事件不追求共同元结构，也不把一者等同公共法则。
- **第欧根尼／芝诺：** 不重演德性去留/同意边界，不用公共承诺表明「认知控制已达成」。
- **塞涅卡：** 不做先前选择的无成本事后自省，本次表态与具体行为直接发生在同一个资源限制现场。
- **卢梭（后继021）：** 将来若合法读取本次已发生的承诺/行动，只能据此重开「谁能共同制定规则」，不能把二人设置成从奥古斯丁到现代政治的一条直接师承线。

## 设计通过/否决标准

**必须满足：** 无免费最优选项；第一次声明与实际行动可不一致；资源约束能改变可做的事；玩家看得见各方实际利害和付出；游戏不替人裁判内心与救赎；路线019/020真实成立。

**否决信号：** 只有几段哲学台词、所有玩家都选即时回血、公共维修恒为纯负收益、金币与HP只是换皮道德条、或为一次事件破坏原生胜利与存档。出现任一项先改机制，不追求赶人数。

**阶段状态：** 可审查的哲学边界及最小玩法与测试候选完成；**合法入口尚缺，经济与体验尚未验证，人物交付仍为 Todo**。
