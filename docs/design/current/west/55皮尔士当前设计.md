# 皮尔士当前设计（ENC-152）

## 承接位置

- 主用途：固定。路线「可错探究」：苏格拉底／知识开局 → 第一幕休谟 → 第二幕皮尔士（詹姆斯内批） → 第三幕杜威。
- 图：新增节点 `CHARLES_SANDERS_PEIRCE__KNOWLEDGE_AND_DOUBT__CORE`、`JOHN_DEWEY__KNOWLEDGE_AND_DOUBT__CORE`；新增边 069（苏格拉底→休谟，第一幕固定）、070（休谟→皮尔士，第二幕固定）、071（皮尔士→杜威，第三幕问号 Switch）。

## 玩家流程

第二幕在休谟节点完成至少一场普通战斗后，地图边界插入本事件：

测量员报告了与既定表格矛盾的读数。三个选择：

1. **按后果检验**：采纳 070，进入皮尔士节点。
2. **交给共同体**：同样采纳 070，记录共同体标准。
3. **保留休谟**：放弃本幕固定承接，停留在休谟节点。

## 状态与保存

- `PeirceInquiryState`：阶段、待确认动作、已确认动作、标准（后果／共同体／休谟）、是否采纳边、是否放弃固定幕、是否关闭；严格版本与重放校验。
- 随 `PhilosophyRunState.PeirceInquiry` 保存；旧档缺属性时为 null，不补发。
