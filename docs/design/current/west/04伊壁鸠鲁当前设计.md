# 伊壁鸠鲁当前设计

## 三分钟摘要

- **当前结论：** 当前可玩用途是第三幕标准事件“共同余地”，它与柏拉图的安排观竞争，但不伪造柏拉图到伊壁鸠鲁的历史继承。
- **玩家流程：** 完成柏拉图德性009、仍持审思砝码且第三幕至少完成一战后，进入实际问号并由原生抽为 Event 才可能遇到“共同余地”；玩家在知道同伴具体请求前先选择彼此担保或各留余地；得知变化后可以履行、拒绝、自愿调整或维持原约。
- **核心取舍：** 彼此担保会开放具体请求也带来承担压力；各留余地保留独立安排，也不能把没有请求当作禁止主动照顾对方。
- **界面与素材成本：** 一个标准事件、复用背景和预写选项；无生命、金币、卡牌、遗物或路线奖励。
- **已完成：** 四条完成路径、未完成退出、状态保存、触发、双语文案、验证、构建和部署均已完成。
- **未完成：** 原子论语境、更多人物关系和长期平衡仍是研究内容，不在当前事件中展开。
- **准确下一步：** 后续人物任务先读取 [希腊化与罗马哲学研究](../../../research/west/00希腊化与罗马哲学.md)，再收敛为独立可交付循环。
