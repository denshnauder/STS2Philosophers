# 笛卡尔当前设计

## 三分钟摘要

- **当前结论：** 当前可玩笛卡尔用途是第二幕“重建起点”，只处理为重建而检验共同基础；它不同于塞克斯都对窄命题的悬置，也不同于入口人物“主体与他者”的沉思镜实践。
- **玩家流程：** 知识路线完成塞克斯都事件、第二幕至少完成一战且仍持问杯时，在具备自然分叉的实际问号被原生抽为 Event 后才可能面对三项共用旧底稿的路线判断；玩家可暂用旧底稿，或撤下共同基础，只选地标或独立足迹核验，再决定恢复有限判断还是继续保留未证主张。
- **核心取舍：** 局部核验只能恢复它真正覆盖的内容；撤下主张不发奖励，地图结果也不能倒证方法正确。
- **界面与素材成本：** 一个标准事件、复用背景和原生地图分叉；无新节点、自由输入或额外战斗能力。
- **已完成：** Fixed 占位、四条核心路径、未完成状态、保存恢复、触发、双语文案、验证、构建和部署均已完成。
- **未完成：** 主体／他者用途仍只由入口沉思镜承担；更完整的方法路线必须另行设计。
- **准确下一步：** 笛卡尔人物任务先读取 [大陆理性主义与英国经验主义研究](../../../research/west/01大陆理性主义与英国经验主义.md)，不得把两种用途合并成同一个空泛怀疑机制。

实现事实见 `DEVELOPMENT.md` 的“笛卡尔重建起点事件”。

## ENC-191 沉思镜费用接入修复

既定规则不改：首次手动单体攻击绑定实际存活敌人，下一真实回合开始读取其意图；攻击意图优惠首张正费用技能，否则优惠首张正费用、明确针对该敌人的单体攻击。奥斯提是己方召唤物，不进入敌方候选。自动出牌不领取手动机会；死亡或消失不改绑其他同名敌人，读档不能重开已用机会。

原生运行时证实`PlayCardAction`先调用`SpendResources`，随后`OnPlayWrapper`才写入`CurrentTarget`。旧适配器只查该字段，因此非攻击分支在付款前得不到目标。ENC-191将费用目标改为原生当前出牌行动的目标，并在同步牌面预览内使用原生预览目标；尚未选目标且只有一个存活合法敌人时可直接显示确定优惠，多敌人未选目标则保持常规费用并提示需指定目标。显示和付款均调用同一费用钩子，不预先消费机会。

该修复只恢复既定收益，没有新人物、新资源或存档迁移。原生卡牌对象、费用钩子、真实能量扣除与遗物回调的集成复现必须覆盖修复前失败与修复后通过；不等同完整游戏画面、网络调度或实际存档文件的验收。

同一原生复现还发现公共入口把同名不同实例的`PlayIndex/PlayCount`误当唯一出牌标识，造成后续结算未消费优惠。改用原生`CardPlay`引用拒绝重复回调、已保存序号区分真实出牌；不改保存字段及版本。该公共修复需由ENC-192另行验证两张打击的惯例统计，不能由本票通过替代。

修复前两项失败用例已保留，修复后原生托管集成、相关纯逻辑、Release和PCK检查通过，已安全部署并核对三文件哈希，保留可回退旧部署。尚无修复后人工实机画面验证；测试覆盖范围见DEVELOPMENT，实际反馈仍独立处理。
