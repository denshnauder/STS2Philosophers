# 苏格拉底当前设计

## 三分钟摘要

- **当前结论：** 苏格拉底只有一个入口人物位，玩家进入后在“知识与怀疑”和“德性与幸福”中选择一种问题，本局不双领。
- **玩家流程：** 知识使用诘问杯，在战斗第一回合把至多两张手牌放到底部并接受等量未知牌；德性使用审思砝码，选一张攻击或技能跨回合保留并逐回合降费，手动打出时消耗。
- **核心取舍：** 前者用当前已知手牌交换未知替代，后者用手牌占用和最终消耗换取延后实践；无合格牌时保持中立。
- **界面与素材成本：** 复用开局手牌选择、卡牌高亮和遗物状态，不新增人物场景。
- **已完成：** 两种入口实践、保存恢复和后继资格判断已部署；ENC-112砝码消耗时点与Play堆实例追踪修复已通过逻辑检查、Release和PCK校验，用户恢复工作后确认游戏未运行，安全部署同批产物并核对三文件哈希。资格判断不等于后继生产入口可达。
- **未完成：** 普罗泰戈拉、塞克斯都及其后继事件的普通返图入口有已确认缺口，共享修复尚待验证和部署；不能把整条后继体验称为交付完成。尚无砝码修复的人工实机体验。历史稿中的试授反悔权与主动撤离不是当前入口玩法，不得据旧稿自动实现。
- **准确下一步：** 返回Linear，按89人既定顺序、真实依赖及必要公共阻断例外领取；同一人物内才按优先级、创建时间选择。入口功能缺口在原票补齐，后续体验反馈独立登记。

## 当前完整决策循环与解释边界

开局三人邀请中苏格拉底只出现一次；进入后选择一个问题，或返回原候选／拒绝。候选先保存，返回不重抽；领取并验证遗物身份后才记录主说与路线，重复回应不能双领。

| 环节 | 知识与怀疑：诘问杯 | 德性与幸福：审思砝码 |
| --- | --- | --- |
| 出现时点 | 每场战斗首回合抽牌后，一次原生手牌选择 | 同一时点，最多选一张攻击或技能，也可不选 |
| 玩家选择 | 保持已知手牌，或把0至2张置底换等量未知抽牌 | 立即使用当前牌，或占用手牌位置跨回合等待；每次仍在手中则保留并降费1，最低0 |
| 收益与代价 | 换掉当前不想用的牌，但替代牌不保证更好，置底牌暂时远离 | 推迟行动换取以后更低费用；手动使用后消耗，同一战斗不能再抽回重复使用 |
| 失败与恢复 | 禁抽、满手等遵循原生限制，不补抽、不重选；选择异常关闭本场机会 | 只追踪选中实例；离手不换绑同名副本，自动出牌不获得手动承诺效果；身份恢复不唯一时停用追踪 |
| 后继变化 | 已实现塞克斯都理由并置、第二幕笛卡尔有限重建；普通返图触发待修复交付 | 已实现普罗泰戈拉共同授权、柏拉图职责、第三幕幸福实践或去留终点；战后后继触发待修复交付 |

这些战斗工具只提供可承受的有限取舍，不认证“换未知牌就是知道自己无知”或“等得越久越有德性”。没有合格牌、选择0张、抽牌被阻止都保持中立，不惩罚为思想失败；胜利、失败、降费次数也不能证明知识或幸福。手动打出应兑现消耗成本，不能因程序接入过晚让承诺变成免费优势。抽牌选择与保留均复用既有选择器、牌面及遗物图标，无新场景、配音、动画或额外素材。

历史苏格拉底的材料主要经他人转述；《美诺》《拉凯斯》作为柏拉图对话材料，不等同历史苏格拉底的无争议定论。当前工具没有实现历史稿中完整的命题提出与诘问，也不以已有休眠协议冒充可玩对话。问号中的新问题由各人物自身事件承担；柏拉图的共同职责是另一人物用途，守灯与旅人仍受实验约束。这里已交付的是既定入口与战斗实践，后继资格与各事件的实际可达性分别核对，不声称完成苏格拉底全部思想。

## 后继边界

以下描述现有事件的设计职责；普通战后入口缺口解决并完成相关验证、部署前，不作为整条路线当前可玩的保证。

- 知识路线：塞克斯都提出理由并置；笛卡尔处理有限重建。两者都不表示苏格拉底直接影响后世人物。
- 德性路线：普罗泰戈拉处理共同商议，柏拉图处理共同职责，之后可进入伊壁鸠鲁，或进入第欧根尼与芝诺终点。
- 问号完成、人物接受和当前战斗工具是不同事实；后继事件不能伪造新的机械教义。
