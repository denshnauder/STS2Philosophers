# 阿那克萨戈拉当前设计

## 三分钟摘要

- **当前结论：** ENC-108 的主要用途是第二幕问号“混合中的秩序”。第一幕已接受巴门尼德、第二幕明确保留他而结束德谟克利特固定邀请的玩家，尚有本幕未用问号；在这条空余分支上比较“不生不灭的混合”与心灵启动运动的解释负担。现有图没有阿那克萨戈拉边，本事件沿用塞克斯都式的独立问号记录，不擅增节点或转线。
- **玩家流程：** 接受邀请后，玩家面对一种颜色占优势的混合，选择按占比解释显现，或要求找到完全纯净的一份；随后选择只把心灵用于启动分离，或要求它解释每个具体结果。最后明确记录有限追问，或保留巴门尼德边界。
- **核心取舍：** 按占比解释保留了显现，却不能从可见样本证明“一切在一切之中”；要求绝对纯净则让这个模型承担无法以少量可见材料完成的证明。只记录心灵的启动作用留下局部秩序的解释缺口；要求心灵说明每个结果则承担古代批评指出的未兑现解释。两种追问均不认证谁正确。
- **界面与素材成本：** 原生事件按钮、短页及既有诸子观照背景别名；色彩只是文字思想模型，不新画混合动画、物件、NPC或战斗UI。
- **已完成：** 巴门尼德与德谟克利特的合法前驱已存在；第二幕固定拒绝后的问号分支不与赫拉克利特留线的阿那克西曼德、德谟克利特采纳线的恩培多克勒重合。事件、双语、严格保存恢复、十条结局路径、原生地图房间、Release 与 PCK 检查通过；已与高尔吉亚合批安全部署0.5.8，三文件哈希与构建输入一致，回退点见[开发说明](../../../../DEVELOPMENT.md)。
- **未完成：** 未进行渲染UI或完整实机局试玩；玩家反馈另按实际情况处理。
- **准确下一步：** GitHub 批量收尾后关闭 ENC-108，按 Linear 真实顺序继续，不把本事件伪装为图节点或转线。

## 研究来源与争议边界

[阿那克萨戈拉残篇英译](https://history.hanover.edu/texts/presoc/anaxagor.html)的 B11—B12 区分各种混合成分与不混入其中的心灵，并将心灵与运动、辨识联系起来。[SEP《Anaxagoras》](https://plato.stanford.edu/entries/anaxagoras/)讨论“处处有份”、无绝对纯净部分、显现的优势成分，以及心灵是否足以解释局部秩序的争论。[柏拉图《斐多》97c—99a](https://chs.harvard.edu/primary-source/plato-phaedo-sb/)中的苏格拉底批评心灵未被持续用作“何者最好”的解释；这是后来的批评，不把它假装成阿那克萨戈拉的自我否定。游戏不将心灵绘作人格化神祇，也不把“宇宙有序”自动解释成“每件事都为玩家最优”。

## 完整决策循环

1. **邀请与机会：** 单人第二幕、当前巴门尼德存在／变化节点、已完成001、德谟克利特固定事件已拒绝并关闭、第二幕Fixed已明确拒绝且Question未用时，在实际问号被原生抽为 Event 后才可能邀请。先预约并保存第二幕问号；拒绝也消费机会，不强改遗物、六入口、89人顺序或图依赖。
2. **检验混合：** 文本模型给出一份多成分混合、其中一种颜色占优势。玩家选择以相对占比解释显色，或要求从中分出完全纯净的一份。前者在模型内有解释力，却不证明所有可能成分都存在；后者明确暴露“处处有份”对纯净样本要求的抵触，不把看不见的份额画成有限颗粒。
3. **检验心灵：** 两条路径都须继续选择：只将心灵用于启动旋转、承认之后的局部排序还需物质过程说明；或要求心灵解释每一具体结果为什么这样最好。后一项是玩家提出的强解释要求，事件说明现有材料尚未兑现，不把它写成阿那克萨戈拉本人宣称的完整目的论。
4. **承担结论：** 玩家可记录这次有限追问，或保留巴门尼德对生成的严格边界；也可提前中止。所有结果都保留当前巴门尼德节点、既有琴弓与本幕Fixed结果，无金币、战斗增益或遗物。记录只写本人物独立事件状态，不创设未审定图边或下一幕前置。
5. **失败与恢复：** 同一原生事件房间按准备→提交→再保存。旧档无记录时保持缺席；字段缺失、未知版本、矛盾前驱或已占用问号保持冻结，不能清空后重邀。已确认的页面和待提交动作可精确恢复；陈旧按钮不能换选。
6. **退出：** 回原生地图继续当前局。玩家之后若有实际体验意见另记反馈；本事件不抢占其他第二幕问号，因为三种路线节点与固定结果互斥。

反例：可见的两色混合不是对“一切在一切之中”的实验确证；只看到某成分优势不等于其他成分消失；要求找到纯净样本不是该理论已经保证可做到；心灵启动运动不自动说明全部具体目的；柏拉图的批评不得冒充两人的历史对谈。
