# 胡塞尔当前设计（ENC-155）

## 承接位置

- 主用途：固定。路线「现象与解释／具身知觉」：笛卡尔／主体开局 → 第一幕胡塞尔 → 第二幕海德格尔或梅洛庞蒂；前者第三幕伽达默尔，后者第三幕波伏瓦。
- 图：新增节点 `EDMUND_HUSSERL__SELF_AND_OTHER__CORE`、`MARTIN_HEIDEGGER__SELF_AND_OTHER__CORE`、`MAURICE_MERLEAU_PONTY__SELF_AND_OTHER__CORE`；新增边 072（笛卡尔→胡塞尔，第一幕固定）、073（胡塞尔→海德格尔，第二幕固定）、074（胡塞尔→梅洛庞蒂，第二幕固定）。
- 073 与 074 是第二幕的跨周目替代展开，一局只会承接其中一条；两条都不新增问号。

## 玩家流程

第一幕在笛卡尔节点完成至少一场普通战斗后，地图边界插入本事件：

学生报告她看见的东西，随后发现自己把预期也加了进去。三个选择：

1. **描述显现**：采纳 072，进入胡塞尔节点。
2. **悬置存在设定**：同样采纳 072，记录悬置标准。
3. **保留笛卡尔**：放弃本幕固定承接，停留在笛卡尔节点。

## 状态与保存

- `HusserlEpocheState`：阶段、待确认动作、已确认动作、标准（显现／悬置／笛卡尔）、是否采纳边、是否放弃固定幕、是否关闭；严格版本与重放校验。
- 随 `PhilosophyRunState.HusserlEpoche` 保存；旧档缺属性时为 null，不补发。
