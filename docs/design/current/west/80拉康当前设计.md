# 拉康当前设计（ENC-178，第84位）

## 路线位置

无意识与规范：笛卡尔主体开局 → 第一幕弗洛伊德（087）→ 第二幕拉康（088）→ 第三幕巴特勒（待实现）。不要求同局另跑语言线；索绪尔、黑格尔等中介保留说明，不写成直接师承。

## 现场与操作

《你所指的那一个》。旅站有人请玩家取回「属于你的」标记；看守、信使、记录员三人各自把「你的」指向不同承诺与场景。

1. **第一次选择（把词连到使用者）**：把「你的」连到看守／信使／记录员之一，并记下他当时的使用场景。
2. **打断**：另一位说话者当众改口，把「你的」指向另一个承诺。玩家在三种终局中选一：
   - **澄清**：追踪改口、公开澄清自己的请求，失去一次领取物品的优先权（采用 088）。
   - **立即领取**：保留既有解释立刻领取，记录显示一位请求者始终未获回应（采用 088）。
   - **拒绝对象化**：拒绝把无法确证的缺失物说成具体对象，保留未解之处（保留弗洛伊德节点，放弃本幕固定位）。

## 保存内容

能指的使用者（`Speaker`）、公开要求与结局标准（`Standard`）、未被回答的请求（`UnansweredRequests`）、已确认动作序列；`IsUsable` 按动作序列重放校验。与索绪尔的系统分类不合并、不换皮：本房间记录的是「谁在什么场景用这个词」，不是符号系统的内部差异。

## 容量与互斥

第二幕固定位一次；采用 088 后 `LastFixedAct` 由 2 变 3；拒绝则 `DeclinedFixedActs` 记 3 并留在弗洛伊德节点。旧档若已有开放实例按原事件恢复，不补发、不重算。

## 反例与边界

- 不写成读心、三界奖励或「治疗成功」分数；不能从一次改口推断他人内心。
- 不把「拒绝对象化」写成更高真理或隐藏奖励。
- 不声称拉康直接继承弗洛伊德：图边 `ProblemShift`，说明中介（结构语言学、黑格尔接受）。
