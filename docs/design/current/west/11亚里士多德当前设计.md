# 亚里士多德当前设计

## 三分钟摘要

- **当前结论：** ENC-113保留语言入口“范畴石板”，新增第二幕制度路线标准事件“轮到谁执印”，兑现既定内部批判与转向用途。存在／德性的其他用途保留研究边界，不复活撤边，不制造额外入口。
- **玩家流程：** 第一幕选择柏拉图“自由与制度”、持有城邦印章，第二幕完成战斗返回地图时，可接受或拒绝。先安排独自执印或轮流，再回应知情者拒绝代言、或未入名册工匠的参与请求；承担后果后，另行选择转向亚里士多德或保留柏拉图。
- **核心取舍：** 独控能保留裁决权，但对方不交出自己的判断；共享决策就失去单方定案。扩大参与要交出原来属于自己的下一轮，保持名册则保住轮次并明确排除工匠。任何结果不认证善政，也不发资源奖励。
- **界面与素材成本：** 单个原生事件、少量短页与按钮，复用诸子观照背景和城邦印章。不新增地图节点、工坊场景、角色立绘、动画或战斗能力。
- **已完成：** 语言入口与范畴石板此前已部署；制度事件已实现、双语及12条完整路径和保存边界检查通过，Release零警告零错误、PCK加载／纹理通过，游戏未运行时安全部署且三文件哈希一致，已有回退点。现在可在游戏中遇到。
- **未完成：** 尚无人工实机体验。其他人物的后继按其授权交付，不把配置关系当作已有事件。
- **准确下一步：** 返回Linear领取下一个依赖满足的授权任务；实际体验反馈另票处理。

## 研究、既定用途与候选的边界

[《政治学》第二卷](https://classics.mit.edu/Aristotle/politics.2.two.html)批评把城邦过度统一为一个人的方案，保留不同角色及公民轮流执政的问题；[第三卷](https://classics.mit.edu/Aristotle/politics.3.three.html)对公民资格因政体而异及工匠排除的讨论不能改写成现代普遍平等。[《范畴篇》第一部分](https://classics.mit.edu/Aristotle/categories.1.1.html)区分同名与定义，不支持“同费用就是同一本质”。本事件是游戏创作的有限比较，不模拟整座城邦，也不把柏拉图本人写成独裁角色。转向后继续审查谁有资格参与，不宣称亚里士多德解决了排除。

六入口、七问题和89人用途保持不变。`WESTERN_EDGE_016`是既有第二幕制度固定转向，本票只在具体回应后让玩家明确接受它。`WESTERN_EDGE_002`（巴门尼德后连续固定承接）与`WESTERN_EDGE_032`（语言入口普通邻接索绪尔）保持禁用。潜能现实、四因、德性养成保留为其他问题面的研究用途；当前没有合法入口时不强塞入语言路线。阿奎那、霍布斯等未交付后继不在本票提前实现。

## 玩家循环、后果与反例

[阿奎那角色定义](../shared/01西哲人物用途基线.md)登记本票三个问题面与旧语言029投影的差异。当前制度016、语言范畴石板与阿奎那未来入口分别保留；不把语言031退休扩写成029退休，也不将制度转向当作语言前驱完成。

1. 实际来源为`PLATO__FREEDOM_AND_INSTITUTIONS__CORE`、第一幕固定状态、第二幕单人地图、已有战斗且持城邦印章时，仅创建一次事件实例并先保存。拒绝结束本次第二幕固定邀请，不能重进刷选择。
2. 明示这只是一次小型公共事务：两位入册者轮次原为你今天、同伴明天，未入册工匠只能供给维修。玩家先选集中执印或保留轮替。对方后续回应改变可以完成的共同安排。
3. 集中后，同伴拒绝把自己的判断当作你的命令：可以交还共同决策权，失去单方定案；也可保留独控，对方不署名、不提供共同裁决。轮替后，工匠要求参与：让出自己下一轮能将其纳入，或保留名册而明确排除。没有“两个都要”的隐含选择。
4. 只有看完上述具体后果，才能另行接受亚里士多德的研究方向；保持柏拉图不抹掉刚才发生的让权或排除。接受完成既有016边；保留／中止／拒绝只消耗第二幕固定机会，不伪造转向。当前城邦印章继续作为已有战斗工具，不叠新主能力，也不把路线身份与旧工具混为一谈。
5. 每个结果只退出同一原生地图叠层。中止标为未完成，不补全玩家未选的安排。保存前准备行动、同步提交、保存后换页；重入只续同一行动，未知／矛盾状态不清空重邀。旧档缺新字段保持缺席。

反例：轮流不等于所有居民都有资格；扩名册不消除有限轮次；独控不等于自动高效；多人同意不证明正义；选择亚里士多德不是给排除洗白；数值收益不作为任何立场的答案。自动检查只证明状态与路线一致，不证明玩家已感到公共权力的取舍。

## 既有语言入口

范畴石板每回合首张手动非X费攻击／技能／能力，以该遗物调整前费用分0、1、2以上；随后两张同类正费用牌降1，最低0。0费先手意味着本轮没有正费用折扣，玩家要在当前行动和后续构筑顺序之间取舍。自动出牌、X费及同名不能替代类别条件；回合结束重置。它是有限的游戏分类工具，不是完整范畴学或本质论；保存载荷与原生接入沿用既有实现，不因本票改名或改数值。
