# 阿那克西曼德当前设计

## 三分钟摘要

- **当前结论：** ENC-103 保留原定主要用途“问号”、兼任研究与回响。阿那克西曼德作为第二幕对“单一可见性质能否充当万物本原”的一次有界追问，不成为新的固定入口或战斗遗物。
- **玩家流程：** 第一幕从赫拉克利特琴弓路线完成巴门尼德问号、但未转向巴门尼德；第二幕仍持琴弓，具备该支路资格且进入实际问号，由原生抽为 Event 后才可能受邀。玩家可拒绝、检验一种可见性质的优先地位，或暂缓指定可见本原；最后明确记录有限的“无定者”追问、保留原判断或中止。
- **核心取舍：** 指定某一可见性质，须承担其对立面为何还能出现的解释负担；不指定可免于偏袒一方，却仍欠缺对生成机制的证明。记录追问只留下对路线的修订事实，保持赫拉克利特当前战斗实践；没有答对奖励。
- **界面与素材成本：** 复用原生标准事件和既有诸子观照背景别名，不新增地图节点、人物画、动画或框架。只使用既有琴弓资格与第二幕一次问号机会。
- **已完成：** 89 人中的第 2 位与问号主要用途已核对；旧第二幕返图入口事件、双语选择、有限路线记录和旧档隔离已实现。八条完整路径、原生事件边界、Release、PCK 及本机 RitsuLib 0.6.7 检查通过；0.5.5 三文件已在游戏未运行时部署到 Mac，哈希相符，原目标此前不存在并有回退记录。
- **未完成：** 尚无渲染界面或整局实机试玩；玩家反馈按独立票处理。
- **准确下一步：** 此人物已交付；后续按 Linear 与 89 人顺序推进，不把自动检查写成玩家已试玩。

## 来源与论证边界

[SEP 的前苏格拉底哲学条目](https://plato.stanford.edu/entries/presocratics/)将阿那克西曼德的“无定者”、对立者的产生与依时间安排的秩序归于不完整的古代证言；唯一相对可靠的残篇范围仍有争议。[亚里士多德《物理学》](https://classics.mit.edu/Aristotle/physics.1.i.html)提供后世对于“一”与对立者分离的解释，不等同阿那克西曼德自己的完整论证。因此游戏中的湿与干、热与冷只是检验单一可见本原的假设场景，不把“某一方胜出”为宇宙正义、不把无定者写成空白万能材料，也不声称他与赫拉克利特面对面对话或有已证实的直接影响。

## 机会、选择与恢复

第一幕巴门尼德问号无论拒绝还是保留都已消费第一幕 Question；若明确转向巴门尼德，则本事件不触发。第二幕赫拉克利特节点没有已启用的固定后继边，故在本次事件预约时确认“本幕无固定候选、保留现有主说”，以现有图的 `TryDecline(Fixed, 2)` 推进幕位，再预约第二幕 Question。必须同时满足第一幕事件已关闭、第二幕单人、琴弓仍在、原节点无合法 Fixed 候选且两个业务机会都未被使用；实际问号还须被原生抽为 Event。保存或资格确认失败时锁定输入，不跳过前置、不重邀、不用另一个人物补位。

接受后先在一处热与冷、湿与干并见的假设现场选如何说明：暂以一项可见性质为首，或拒绝让任何一项独占首位。前者随即面对相反性质回归的解释负担；后者面对“不偏袒任一方并未说明具体分离方式”的限制。两条路径都可选择记录有界追问，或只保留观察而不采纳解释，也可中止。拒绝、中止和保留仍消费本幕问号；只有明确记录才提交 `Question/Revise` 边，记阿那克西曼德已见而不替换赫拉克利特节点或琴弓能力。未来人物不得仅凭“已见”推断玩家全盘采纳无定者学说。

每一步采取准备保存、提交同一行动、再保存确认；事件房间身份与局内状态须一致。旧存档没有本记录时不伪造遇见；未知版本、矛盾行动、损坏槽或保存结果不明时停用本事件并保留来源，不清空后重新邀请。结局页统一使用原生继续。
