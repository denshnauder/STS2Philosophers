# 德谟克利特当前设计

## 三分钟摘要

- **当前结论：** ENC-110用第二幕固定事件“空隙与排列”，让玩家在不变单元与可变组合之间承担一个具体解释；原子与虚空作为对爱利亚论证压力的回应。
- **玩家流程：** 第一幕从琴弓实践明确转向巴门尼德，第二幕保留琴弓并完成战斗后受邀。先选运动或性质，再实际选择本次模型如何改变，看到相应解释与盲区，最后明确接受原子与虚空或保留巴门尼德。
- **核心取舍：** 留空位只先改变模型；最后接受原子论时，才承担真实虚空的主张。改变组合能区分显现与单元，却不能凭感官直接证明微观结构。每次只提交一项所选比较，不允许读档改写已经公开的操作。
- **界面与素材成本：** 一个原生事件、普通按钮和诸子观照背景别名。全部操作明确为文字呈现的思想模型，不需粒子画、拖放、显微镜、动画或新战斗UI。
- **已完成：** 事件、双语、四种模型后果、明确转向／保留、精确保存确认与恢复均已实现。12条完整路径、异常状态、原生房间序列化、Release与PCK检查通过，已安全部署并保留回退点。

## 研究与归属边界

[亚里士多德《形而上学》I.4，985b](https://classics.mit.edu/Aristotle/metaphysics.1.i.html)把原子论归于留基伯与德谟克利特，并以形状、次序和位置说明差异；[SEP德谟克利特](https://plato.stanford.edu/entries/democritus/)与[古代原子论](https://plato.stanford.edu/entries/atomism-ancient/)讨论不变实体、虚空、运动、性质及感官知识的解释问题。个别贡献难以完全分配，本事件保留留基伯的共同归属，不写成德谟克利特独创或赫拉克利特弟子。

游戏对话为创作。感官提供解释的起点，但甜、苦、颜色不能直接作为原子的内在性质；这不等于一切感觉全假，也不把他改成系统怀疑主义者。可见单元只作示意，不把砂粒当古代原子，不引入电子、现代化学元素或伊壁鸠鲁偏斜。

## 完整决策循环

1. **邀请与机会：** 单人第二幕、真实巴门尼德存在／变化节点、已完成`WESTERN_EDGE_001`、仍持琴弓、完成至少一场本幕战斗且第二幕固定机会未处理时出现。原子与虚空属于德谟克利特本次固定用途；不增加入口人物、不改变89人用途。拒绝或中止消费本次Fixed，不能反复邀请。
2. **选择解释负担：** 玩家选择这次正式记录讨论“单元怎样移动”或“同一单元为何呈现不同性质”。未选的问题保持未检验；不制造以后不能研究另一问题的虚假世界代价。
3. **运动操作：** 单元形状与数量保持不变，示意只允许逐个移入空位，不覆盖所有运动方式。选“留空位换位”，只让模型容许位置变化，暂不承诺世界真有虚空；最后据此采纳原子论才承担该主张。选“完全填满”，这套规则没有可供逐个换位的余地，留下模型缺口，不反驳其他模型中的整体运动。结果在按钮中预告，无隐藏正确答案。
4. **性质操作：** 同一批带钩示意片起初钩端朝外，外沿粗。选“只改排列与朝向”，把钩端转向内侧，外沿变平，单元形状不变；选“保持排列，改变观察条件”，只从不同面触看，粗侧与平面感觉不同，但排列未动。前者显示组合解释用途，后者保留感觉而限制由显现直接推断结构。示意片不是肉眼看见的原子，不把改变接触条件当自动证明相对主义。
5. **承担结论：** 四种后果都允许明确接受原子与虚空，或只保留本次现象／模型记录而保留巴门尼德。接受才提交既有`WESTERN_EDGE_005`，推进到德谟克利特；其余终结记录第二幕Fixed拒绝，不提交005、不消费Question。采用模型不是系统认证它唯一正确；保留前说也不获得失败惩罚。
6. **后继与退出：** 原有琴弓继续作为战斗工具，不伪造德谟克利特机械教义，不发数值或额外遗物。玩家返回同一地图。006恩培多克勒与007伊壁鸠鲁存在／变化分支仅为已登记后继，未实现之前不承诺出现，也不混同已交付的德性“共同余地”。

反例：留一个示意空位不能证明宇宙真实虚空；重排能解释差异不等于唯有原子论才解释得了；不能用战斗胜负倒证原子论；完全填满分支不冒充完整反驳所有连续介质理论；感觉改变不等于原子改变；接受不要求先点某个“正确”操作。去掉人物名后仍有“选择解释对象—改变一项模型条件—保留证据和缺口—承担理论边界”的完整循环。
