# 事件幕索引与触发门不一致（集成缺陷）

## 缺陷

`RouteEventMapBoundary.IsActiveEvent(run, local, actIndex)` 以 `run.CurrentActIndex == actIndex` 判定房间当前是否在展示（0 为第一幕）。有 19 个房间的事件把第三参数写成幕号而非索引，导致 `IsActiveRoom` 在其应出现的幕恒为 false：`AfterEventStarted` 直接返回，房间停在「恢复中」锁定选项，玩家无法继续。

受影响房间（事件索引 → 触发门索引）：

- 第一幕：BenthamUtility、FregeSense、FreudUnconscious、HusserlEpoche、KierkegaardFaith、MontesquieuBalance、NietzscheRevaluation、SaussureSign、SmithSympathy（1 → 0）
- 第三幕：AdornoNegative、ComtePositivism、DeleuzeDifference、DerridaDeconstruction、DeweyPublicExperiment、GadamerFusion、HabermasCommunication、MarxAlienation、WittgensteinGame（1 → 2）
- 第二幕：LacanSignifier（2 → 1）

已核对基准：洛克（第一幕，0/0）、休谟与福柯（第二幕，1/1）、培根与牛顿（第三幕，2/2）本来就一致，说明约定是「幕索引」，触发门与图边一致。

## 修复

事件索引一律对齐触发门的 `CurrentActIndex != N`。`RoomIntegrationChecks` 新增守卫：同一房间的事件索引必须等于触发门索引，任一房间写错即失败。

## 验证

ModLogicChecks 全绿（含新守卫扫描全部带完成边房间）；主工程 build 0 error；原生套件 exit 0；内容 PCK 构建通过。
