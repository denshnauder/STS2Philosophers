# 结构主义语言路线阻塞说明

## 现状

图上保留的语言与意义路线是：

- `WESTERN_EDGE_032`：第一幕 Question／Switch，亚里士多德语言 → 索绪尔；**当前禁用**。
- `WESTERN_EDGE_033`：第二幕 Fixed／Adopt，索绪尔 → 列维斯特劳斯，要求 032。
- `WESTERN_EDGE_034`：第二幕 Question／Keep，列维斯特劳斯 → 普罗泰戈拉。
- `WESTERN_EDGE_035`：第三幕 Fixed／Adopt，列维斯特劳斯 → 德里达，要求 034。

## 为什么不可达

- 032 的 `retirement_reason` 明确写着“取消亚里士多德普通邻接；索绪尔独立问题入口尚未接入”，并记录了 ISSUE009、13 西哲路径修订第 4 项及 19 判决 63/64。
- 032 禁用后，033 的 `required_edge_ids` 永远不满足，因此列维斯特劳斯节点不可进入。
- 034 的源节点是列维斯特劳斯，源节点不可达，普罗泰戈拉语言路线无法从该边开始。
- 035 要求 034，且源节点同为列维斯特劳斯，因此德里达节点也不可达。

这不是缺少事件实现，而是入口被设计性撤下；不能用启用 032、伪造 033/034/035 或把索绪尔塞进高尔吉亚问号来绕过。

## 可选方案

### A. 等待索绪尔独立问题入口（推荐）

按 032 的 retirement_reason，后续应先设计“索绪尔独立问题入口”，再恢复 032 或替换为新的合法入口。需要产品确认：

- 入口属于哪一幕、哪个问题面；
- 是否占用现有问号/固定槽位；
- 与高尔吉亚、亚里士多德语言事件及普罗泰戈拉路线的关系；
- 旧存档和既有已部署事件是否受影响。

在入口确认前，033/034/035 只能保持不可达。

### B. 把结构主义路线改挂到其他既有节点

需要替换既有问号/固定窗口或改写图语义，影响范围大于本批补丁；未确认前不采用。

### C. 新增第四幕或新边

超出当前三幕结构与“不得伪造图边”的约束，不采用。
