# 塞涅卡当前设计

## 人物用途与证据

塞涅卡在既定 89 人次序中主要承担「实践」，兼任回响。第三幕芝诺的同意范围已是奠基路线终点，塞涅卡不能再发一条更强的斯多亚结论、遗物或新主说。原版没有第四幕，本人物只能在现有第三幕安全返图时点做一次不占图节点的罗马日常反省；没有芝诺已完成结果时不出现。

[《道德书简》83.1—3](https://romanletters.org/letters/seneca/83/)把每日回看做过的事与次日打算相连；同信83.9—10批评仅靠关于醉酒的芝诺式推论，转而要求看具体情形。这是文本中的自我记录与论证批评，不是「塞涅卡只反对芝诺」的历史结论。[《论愤怒》3.36](https://www.stoicsource.com/seneca/on-anger/3.36/)描述每日盘点说过、做过的事，并允许指出过失后修订下一次做法；不能把这转译成怒气值、睡前得分或对玩家动机的程序诊断。两种英译与拉丁文本版本不同，本设计只取有限的实践问题，不将其中的奴隶、家庭或社会处境搬成游戏强制情节。

## 一次可玩反省

- **出现时点：** 芝诺结局已保存并关闭后，第三幕下一次安全返图；单人、未在 Boss 战中、无其他路线事件占用。一次局内最多一次。不要求第四幕，也不补新的师承图边。
- **玩家操作：** 查看冻结的芝诺实际结果与可用的审思砝码取舍记录；选一件要核对的事——「我把判断说成了什么」或「我何时借助了便利」。事件按已保存事实给出有限回看，随后玩家选择保留原打算或针对反例修订下一次的核对方式。缺资料时明确显示空白，仍可诚实结束。
- **真实取舍：** 每次只能选一个反省焦点；保留与修订导向不同的结尾记录，但均不发战斗收益。付出的不是金币或生命，而是承认本次检查无法证明另一件事。不能同时把回看写成“我已完全自足”和“我从不误判”。
- **失败与恢复：** 查看、返回不写状态；确认前先保存待提交动作，确认后再保存结果。旧档没有塞涅卡记录即未遇见；未知／矛盾状态冻结，不从当前生命、手牌或库存补造过去。重复回调和重载不再发第二事件。
- **后继：** 只保留局内有限反省记录；不改芝诺结局、德性主说、已有图边或游戏奖励。未来人物若要引用，必须另按其 Issue 证明合法时点与独立用途。
- **界面与素材：** 一个标准事件、原生按钮、现有静态背景的 PCK 别名；无独立地图、夜间场景、动画、怒气资源或第四幕。页面控制在 2—4 项，确认页先显示返回。

## 反例与边界

若芝诺只得到 `NoAssent`，它仍是一个真实的结局，但不能反推玩家此前曾有完整公开说法；若没有合格战斗选牌记录，不能写成“从未借助”。两次没选牌也可能只是战术，保留说法也可能是谨慎而非固执。塞涅卡的实践是回看具体行为并修订检查习惯，不是给芝诺的五种同意结局判正误，更不是抽象地说「接受一切」。
