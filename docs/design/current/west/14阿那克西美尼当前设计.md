# 阿那克西美尼当前设计

## 三分钟摘要

- **当前结论：** ENC-104 保留主要用途“实践”，兼任“研究”。以气的凝聚与稀散设计一次战斗中的跨回合转换，不建立独立大教义或把米利都人物顺序当成师徒升级。
- **玩家流程：** 第三幕仍持赫拉克利特琴弓，完成本幕至少一战后，在实际问号被原生抽为 Event 时才可能接受或拒绝阿那克西美尼实践。接受获得辅助遗物“凝散之息”。此后每回合结束时若至少剩余 1 点能量，自动将其中 1 点留待下一回合；下一回合获得 1 点能量并抽 1 张牌。
- **核心取舍：** 本回合少用 1 点能量，换下一回合相同能量和额外一张牌；临近战斗结束时可能完全收不回。玩家可通过用尽能量避免转换。它不改变琴弓所标记牌的去向，不消耗 Fixed 或 Question 机会。
- **界面与素材成本：** 复用原生事件、遗物栏和既有静态图形；不增地图节点、人物肖像或动画。
- **已完成：** 一次性第三幕事件、双语选择、辅助遗物与跨回合状态均已接入；两条事件结果、旧档与拒绝重邀、原生事件房间、Release、RitsuLib 0.6.2／0.6.7 和 PCK 通过检查，0.5.6 已在游戏未运行时部署到 Mac 并保存旧版回退点。
- **未完成：** 尚无整局实机试玩或渲染界面观察；玩家反馈另票处理。无界面夹具不足以独立重演完整抽牌命令，不把状态检查写成整局战斗证明。
- **准确下一步：** 完成 ENC-104 的 GitHub 与 Linear 收尾后，重查 Linear 并按 89 人顺序推进下一项。

## 来源与边界

[SEP 前苏格拉底哲学条目](https://plato.stanford.edu/entries/presocratics/)依据后世证言，说明阿那克西美尼以气及凝聚、稀散解释不同可见形态；关于米利都思想家的明确师承与原话均应谨慎。游戏只借“同一材料经过程改变表现”设计跨回合转化，不把能量与抽牌声称为古人的学说，也不把他设为阿那克西曼德事件的后继奖励。

## 接入、恢复与反例

第三幕单人、完成本幕至少一场战斗、赫拉克利特节点与琴弓仍在时，在实际问号被原生抽为 Event 后仅邀请一次。是否见过或采纳阿那克西曼德均不影响资格；若路线已经切换、琴弓失去、事件已结束或多人局，则不插入。拒绝也永久关闭本局邀请。接受后保留当前路线，只添加一个可共存的辅助遗物；已持该遗物时不重复发放。

事件先持久化玩家选择，再执行发放，并将结束状态再次持久化；恢复时按已保存的选择与遗物持有情况幂等完成，保存结果未知时锁定事件而非重新开邀。遗物记录本场上次凝聚、稀散的回合数，避免重复回调或读档重复领取。第一回合没有先前存量；战斗结束清空未稀散存量。用尽能量无收益；直接击杀敌人后留存没有跨战斗利益。与琴弓的先异类后标记牌机制可叠加，但不修改它的独占主教义判断。
