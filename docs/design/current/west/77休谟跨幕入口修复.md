# 休谟第二幕入口修复（ENC-134）

## 缺陷（Sol P1）

休谟入口用 `HasCompletedCombatAfter`，只看当前幕（第二幕）的历史；洛克记录在第一幕索引 0，第二幕索引 1 找不到它，`last=-1`，触发策略拒绝，正常新局进不了休谟，也就到不了 027 固定。

原生夹具 `AllRouteQuestionNodeChecks` 之前把洛克事件放进第二幕历史，违反洛克自己的幕数限制，因此掩盖了该缺陷。

## 修复

- `HumeInductionPatch` 改用既有 `HasCompletedCombatAfterAcrossActs`（黑格尔等房间同款）：跨幕找前驱，仍保留本幕战斗、前驱身份、真实问号、visited 与业务预算门控。
- 原生夹具改为真实两幕历史：第一幕洛克事件，第二幕战斗；其余拒绝路径（缺洛克、缺本幕战斗、无 026、非法节点、已访问）不变。
- 未搬动洛克、未伪造历史或图边、未改图。

## 证据

- 修前：同一夹具 + 旧 `HasCompletedCombatAfter` → `Real native PullNextEvent selects HumeInduction, got AbyssalBaths`，原生套件 exit 1。
- 修后：同一夹具 + `HasCompletedCombatAfterAcrossActs` → 原生套件 exit 0。
- ModLogicChecks 全绿；主工程 build 0 error；内容 PCK 构建通过。
