# 尼采当前设计（ENC-148）

## 路线选择

候选列出两条互斥分支：

1. 意志与价值：苏格拉底／德性 → 第一幕叔本华 → 第二幕尼采 → 第三幕加缪。
2. 谱系与权力：卢梭／历史 → 第一幕尼采 → 第二幕福柯 → 第三幕阿伦特／巴特勒。

本票交付**分支二**。原因：分支一在图中没有叔本华与加缪节点；叔本华已在 ENC-145 作为康德节点上的第三幕内批事件交付，未建立独立图节点，若强接会把无内容节点塞进第一幕。分支二的卢梭入口与阿伦特第三幕节点均已存在，只需补尼采、福柯节点与三条例边。

## 玩家流程

第一幕在卢梭节点完成至少一场普通战斗后，地图边界插入本事件：

学者展示道德社团的账本：同一件事强者做叫美德，弱者做叫恶。三个选择：

1. **重估一切价值**：采纳 062，进入尼采节点。
2. **揭示谱系**：同样采纳 062，记录谱系标准。
3. **保留卢梭**：放弃本幕固定承接，停留在卢梭节点。

结算页各有一句后果说明，随后「离开档案室」关闭事件。
