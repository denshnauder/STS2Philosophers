## 三分钟摘要

- **人物用途：** 第 23 位，主要「固定」，兼「转线、回响」；本轮拟优先承载「德性与幸福」转向「存在根据」的追问。其余「存在与变化／主体与他者」仍作关系与后续研究背景，不在一个事件内包揽三问题。
- **设计主题：** 《同源而非同形》。两份不同的现场记录可依赖同一组织原则；由共同根据理解差异，不等于消灭差异，也不意味着根据因被使用而耗尽。玩家需要把这一解释要求转成一次实际修复／交付决定。
- **独特动作：** 在有限的修订机会里，玩家决定先核查共同结构还是先解决一处不同的现场问题；随后遇到第三份不符合粗略归纳的记录，必须依据首次操作留下的证据采取具体后续行动。无法同时获得完整概括与现场修复。
- **生产成本：** 一次原生标准事件，2 个主要行动阶段（可拒绝），每页 2–3 个原生按钮，复用静态背景；无新战斗资源、卡、遗物、地图节点、动画。
- **关键阻碍：** 当前 `config/western_graph.json` **没有** `PLOTINUS` 节点和边，`western_routes.json` 也没有角色资格或事件接入。下述合法连接是**提案**，须 Codex 先核查现行路线状态、幕位和遗物资格，再决定是否获准实施。若冲突无法解决，保持 Todo，不能用只读回响或文档验收替代正式玩法。

## 一、历史根据：可以主张什么

1. **不是无差别的“一”。** 《九章集》V.1、V.2 涉及一者、理智、灵魂的关系；理智具有可理解的多样，灵魂在其活动中面对感性差异。不能把一者写成物理蓝图、可见人物、精确数值、万能总公式或所有差异被合并后的平均数。
2. **依赖不等于物理转移。** 普罗提诺的所谓“流溢／产生”涉及本原与由其而来的存在之间的依赖；在解释层次上，被依赖者的活动可以不同于其根据，且不使根据耗损。不能制作“消耗一者能量→生成两个副本”的战斗交易。
3. **回归关乎观看和生活方向。** 《九章集》I.2 区分公民德性与净化的层次；V.1 与相关篇章涉及思考、沉思与返回根据。本事件不会因一次选择宣称玩家达到与一者结合或更高道德等级。避免将公共职责说成毫无价值。
4. **解释传统，不是直接师徒。** 普罗提诺在晚古代解释柏拉图，与游戏内柏拉图早期历史设定存在时间跨度；应使用“后世读解／遗留文本”场景，不让两人历史上会面，也不把它直接接成奥古斯丁的恩典机制。

**史料与研究入口：** [《九章集》V.1、V.2（MacKenna 英译）](https://classics.mit.edu/Plotinus/enneads.5.fifth.html)；[《九章集》I.2](https://classics.mit.edu/Plotinus/enneads.1.first.html)；[SEP：Plotinus（2024）](https://plato.stanford.edu/entries/plotinus/)；[IEP：Plotinus](https://iep.utm.edu/plotinus/)。以上给的是哲学关系，**不是**角色交互、工坊情节或游戏规则的原典出处。

**解释分歧：** 一者的超越性如何被恰当地表达、产生与回归的准确因果语言、净化与公共实践的关系，在学界存在复杂解释。本轮只采用“根据与依赖、理智中的多样、回归不抹平感性经验”这一窄边界，不将一个游戏结局用作体系证明。

## 二、玩家事件《同源而非同形》

**虚构情境：** 一处旧档案馆留有一份公共的通行安排及两处不同路段的旧版本。一份强调支架间距，另一份强调转角留空；两者借用相似的安排关系，却需应付不同的现场条件。第三处路段尚待修复，同行者只给玩家一次完整核对或修订的工时。这里的“共同安排”只是让玩家可操作的**有限类比**，文案不得把档案直接叫做“一者本身”。

### 玩家操作和信息顺序

**邀请页：**
- 查看两处现成记录：共同的结构关系可辨认，但具体安排不同；第三处通路需要确定如何施工。
- `检查共同关系`（A）／`先修现场缺口`（B）／`谢绝介入`（C）。
- A、B 都是行动。拒绝仍消耗本次邀请的机会，关闭后不重现，不奖励德性。

**A：先检查共同关系**
- 玩家先制作一份只覆盖确定相同部分的结构草图；由于工时限制，本轮无法亲自修完第三处现场缺口。
- 新揭示：第三处转角比两份旧记录都窄，直接复制旧布局会发生冲突。
- 第二次行动任选其一：
  - `交付带例外标注的共同草图`：后续使用者有统一参照，但仍需自行完成第三处具体测量；不假装共通原则推出全部细节。
  - `转交现场缺口并暂缓概括`：为实际通行优先交出当前具体限制，统一草图保持未完成。
- 这两个结果分别保存“说明范围较广但现场留白”和“具体问题优先、解释尚未闭合”。

**B：先修现场缺口**
- 玩家依据已知的当地约束，完成一份可供当前工人行动的修订建议；本轮失去逐项比较两份旧记录的完整机会。
- 新揭示：另一处记录后来也曾修订过；相同外观不能证明两处安排一模一样。
- 第二次行动任选其一：
  - `交付本地修订并注明未核实共同依据`：现场拥有可用方案，来源解释仍悬而未决。
  - `保留两份不同记录交由后继核对`：更完整地保留差异，但本轮不完成可普遍复用的施工建议。
- 两者都必须显示玩家**已经做了什么**以及**这一轮不能再做什么**，而非“答对一者＝奖赏／答错＝惩罚”。

**共同结算：**
- 简要并排呈现玩家完成的工作、仍缺乏证据的范围，以及他人/现场的独立限制。
- 不修改战斗数值、不给金钱/卡牌/遗物，也不由程序宣布玩家“领悟最高真实”；本事件的有限得失来自工作机会和交付内容，不能声称具有全局游戏平衡优势。
- 所有分支有清晰离开路径，不强制事后接受一套正确哲学结论。

### 与已有角色的机械区别

- **柏拉图「两项职责」：** 决定谁能独立完成及谁有权承担依赖职责；本事件的行动对象是由多个具体表现追溯解释上的层次，**不分配公共决定权**。
- **塞克斯都「两盏灯下」：** 对争论命题可悬置并继续按地图行动；本事件必须在有限材料中**完成一项具体验证或修订**，没有“暂不表态＝唯一怀疑动作”。
- **笛卡尔：** 怀疑共享原则以重建可确信起点；本事件不寻找我思等不可怀疑基础，也不以消除所有差异取得确定性。
- **芝诺／塞涅卡：** 不对旧判断的同意范围二次结算，不给日常自我盘点加一个“更高级”环节。
- **奥古斯丁：** 不出现创造、罪、意志二分、恩典或救赎奖励；后来的接受与改写另有独立问题和合法前置。
