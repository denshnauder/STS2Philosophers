# 普罗提诺当前设计｜ENC-118

> 以下保留 ENC-118 的设计依据与业务规则，交付状态以 Linear 为准。ENC-199 的 0.5.19 迁移已通过代码、纯逻辑与原生自动检查；部署及实机验收另行核实。新事件仅在第三幕实际地图问号被原生判定为事件时有机会出现，不再使用战后额外房间。既有 89 人顺序、用途和六入口／七问题不变。

## 三分钟摘要

- **人物用途：** 第 23 位，主要「固定」，兼「转线、回响」；本轮拟优先承载「德性与幸福」转向「存在根据」的追问。其余「存在与变化／主体与他者」仍作关系与后续研究背景，不在一个事件内包揽三问题。
- **设计主题：** 《同源而非同形》。两份不同的现场记录可依赖同一组织原则；由共同根据理解差异，不等于消灭差异，也不意味着根据因被使用而耗尽。玩家需要把这一解释要求转成一次实际修复／交付决定。
- **独特动作：** 在有限的修订机会里，玩家决定先核查共同结构还是先解决一处不同的现场问题；随后遇到第三份不符合粗略归纳的记录，必须依据首次操作留下的证据采取具体后续行动。无法同时获得完整概括与现场修复。
- **生产成本：** 一次原生标准事件，2 个主要行动阶段（可拒绝），每页 2–3 个原生按钮，复用静态背景；无新卡、遗物、地图节点、动画。若采用普罗提诺路线，审思砝码在合法路线下获得额外的手动牌序实践。
- **接入：** `WESTERN_EDGE_044` 从已完成的柏拉图 009 进入第三幕普罗提诺 Fixed，伊壁鸠鲁事件关闭后须另完成一场非 Boss 战。未满足条件不开放邀请。

## 一、历史根据：可以主张什么

1. **不是无差别的“一”。** 《九章集》V.1、V.2 涉及一者、理智、灵魂的关系；理智具有可理解的多样，灵魂在其活动中面对感性差异。不能把一者写成物理蓝图、可见人物、精确数值、万能总公式或所有差异被合并后的平均数。
2. **依赖不等于物理转移。** 普罗提诺的所谓“流溢／产生”涉及本原与由其而来的存在之间的依赖；在解释层次上，被依赖者的活动可以不同于其根据，且不使根据耗损。不能制作“消耗一者能量→生成两个副本”的战斗交易。
3. **回归关乎观看和生活方向。** 《九章集》I.2 区分公民德性与净化的层次；V.1 与相关篇章涉及思考、沉思与返回根据。本事件不会因一次选择宣称玩家达到与一者结合或更高道德等级。避免将公共职责说成毫无价值。
4. **解释传统，不是直接师徒。** 普罗提诺在晚古代解释柏拉图，与游戏内柏拉图早期历史设定存在时间跨度；应使用“后世读解／遗留文本”场景，不让两人历史上会面，也不把它直接接成奥古斯丁的恩典机制。

**史料与研究入口：** [《九章集》V.1、V.2（MacKenna 英译）](https://classics.mit.edu/Plotinus/enneads.5.fifth.html)；[《九章集》I.2](https://classics.mit.edu/Plotinus/enneads.1.first.html)；[SEP：Plotinus（2024）](https://plato.stanford.edu/entries/plotinus/)；[IEP：Plotinus](https://iep.utm.edu/plotinus/)。以上给的是哲学关系，**不是**角色交互、工坊情节或游戏规则的原典出处。

**解释分歧：** 一者的超越性如何被恰当地表达、产生与回归的准确因果语言、净化与公共实践的关系，在学界存在复杂解释。本轮只采用“根据与依赖、理智中的多样、回归不抹平感性经验”这一窄边界，不将一个游戏结局用作体系证明。

## 二、玩家事件《同源而非同形》

**虚构情境：** 一处旧档案馆留有一份公共的通行安排及两处不同路段的旧版本。一份强调支架间距，另一份强调转角留空；两者借用相似的安排关系，却需应付不同的现场条件。第三处路段尚待修复，同行者只给玩家一次完整核对或修订的工时。这里的“共同安排”只是让玩家可操作的**有限类比**，文案不得把档案直接叫做“一者本身”。

### 玩家操作和信息顺序

**邀请页：**
- 查看两处现成记录：共同的结构关系可辨认，但具体安排不同；第三处通路需要确定如何施工。
- `接下核查`／`谢绝介入`。接受后才在工作页选 `检查共同关系`（A）或 `先修现场缺口`（B）。
- A、B 都是行动。拒绝仍消耗本次邀请的机会，关闭后不重现，不奖励德性。

**A：先检查共同关系**
- 玩家先制作一份只覆盖确定相同部分的结构草图；由于工时限制，本轮无法亲自修完第三处现场缺口。
- 新揭示：第三处转角比两份旧记录都窄，直接复制旧布局会发生冲突。
- 第二次行动任选其一：
  - `交付带例外标注的共同草图`：后续使用者有统一参照，但仍需自行完成第三处具体测量；不假装共通原则推出全部细节。
  - `转交现场缺口并暂缓概括`：为实际通行优先交出当前具体限制，统一草图保持未完成。
- 这两个结果分别保存“说明范围较广但现场留白”和“具体问题优先、解释尚未闭合”。

**B：先修现场缺口**
- 玩家依据已知的当地约束，完成一份可供当前工人行动的修订建议；本轮失去逐项比较两份旧记录的完整机会。
- 新揭示：另一处记录后来也曾修订过；相同外观不能证明两处安排一模一样。
- 第二次行动任选其一：
  - `交付本地修订并注明未核实共同依据`：现场拥有可用方案，来源解释仍悬而未决。
  - `保留两份不同记录交由后继核对`：更完整地保留差异，但本轮不完成可普遍复用的施工建议。
- 两者都必须显示玩家**已经做了什么**以及**这一轮不能再做什么**，而非“答对一者＝奖赏／答错＝惩罚”。

**共同结算：**
- 简要并排呈现玩家完成的工作、仍缺乏证据的范围，以及他人/现场的独立限制。
- 事件当场不给金钱、卡牌或遗物，也不由程序宣布玩家“领悟最高真实”。交付有限共同草图或保留版本时，采用 044；审思砝码在此合法路线下记录一回合内**手动打出两张不同模型的技能，中间打一张攻击**，恰好三张且无自动出牌，回合结束获得 5 格挡。转交缺口、交付本地修订或谢绝时，消费第三幕 Fixed、保留原遗物行为，不触发这项额外收益。格挡不是哲学正确性的评分。
- 所有分支有清晰离开路径，不强制事后接受一套正确哲学结论。

### 与已有角色的机械区别

- **柏拉图「两项职责」：** 决定谁能独立完成及谁有权承担依赖职责；本事件的行动对象是由多个具体表现追溯解释上的层次，**不分配公共决定权**。
- **塞克斯都「两盏灯下」：** 对争论命题可悬置并继续按地图行动；本事件必须在有限材料中**完成一项具体验证或修订**，没有“暂不表态＝唯一怀疑动作”。
- **笛卡尔：** 怀疑共享原则以重建可确信起点；本事件不寻找我思等不可怀疑基础，也不以消除所有差异取得确定性。
- **芝诺／塞涅卡：** 不对旧判断的同意范围二次结算，不给日常自我盘点加一个“更高级”环节。
- **奥古斯丁：** 不出现创造、罪、意志二分、恩典或救赎奖励；后来的接受与改写另有独立问题和合法前置。

原候选指出图中没有普罗提诺；实施已补足独立节点及 044 边，角色文字本身仍不能冒充合法固定节点。下列条件是本次接入与复核边界：

- 资格是第三幕累计至少两场战斗，且**伊壁鸠鲁事件关闭后另完成一场非 Boss 战斗**；此后只能在实际地图问号被原生抽为事件时有机会遇见。还须同一局已完成柏拉图对应事件、记录合法、审思砝码仍有效、第三幕固定机会未被使用。不能只因柏拉图姓名出现在历史中就满足前置，不在安全返图时额外压入事件。

- 图、幕位互斥、遗物资格及原生返图边界已通过相应自动检查；实际游戏内操作尚待批次部署后的试玩。任一状态矛盾或存档证据不足时拒绝自动接入，保留 In Progress 并写明缺口。
- 若采用其他已存在的合法柏拉图路线，也须重新论证“固定”资格及与 019/020 奥古斯丁制度链的互斥关系；**不能借用或改写 019、020 充当普罗提诺路线。**

`WESTERN_EDGE_009` 成功提交后，图状态确为柏拉图德性节点、`LastFixedAct=2`，而第欧根尼的 `WESTERN_EDGE_010` 会改写当前节点，使这条候选自然互斥。基于普罗提诺对柏拉图文本的后世重释，实施分支增加了独立的 `WESTERN_EDGE_044`（第三幕 Fixed、仅以前述 009 为前置）及新节点；路径检查证明 008→009→044 合法，010 转线后不能补领 044。此处的图边仅给出*可能的路线*，不自行生成事件，也不表示人物已可玩或已交付。

原先 `WesternNodePracticePolicy` 中的柏拉图及普罗提诺牌序只是纯逻辑模型，生产遗物并未调用它；不能把模型测试当成真实战斗收益。现已把上述普罗提诺条件接入审思砝码的生产回调：原生检查以真实牌回调记录三张牌，并验证回合结束时角色格挡从 0 变为 5、重复结束回调不再增加；逻辑检查覆盖严格路线身份以外的牌序与载荷恢复。事件即时收益仍为零，不能由数值大小推断哲学对错。

## 四、状态与相称验收（仅设计规格）

- 状态最少包括：版本／运行身份、是否已邀请、第一次操作 `A/B/Decline`、第二次操作、已确认动作序列、待提交动作、最终交付结果、关闭标记、必要路线边／固定机会事务标记。
- 页面逻辑严格由已持久化动作导出；先保存准备动作、再提交结果并保存。退出、加载和重复回调不应让不同选项同时成立。
- 未见旧档不可伪造选择；未知版本、矛盾路线、错误原生房间身份、未完成柏拉图前置、固定幕机会冲突时冻结新事件且不覆盖存档。
- 纯逻辑测试：邀请／拒绝、A/B 两条各2结局、保存点重放、第三处反例后的分支回显、不同 act 与路线拒绝、错遗物／幕位、旧／坏档、重复 LEAVE、双语长度及全键存在。
- 原生最小验收：真实问号 `PullNextEvent` 与公开遗物钩子选择、原生 `EventRoom` 及旧记录恢复、伊壁鸠鲁后战斗历史门控；Release、PCK 和 RitsuLib 兼容检查；主仓整合版本安全部署并保留回退点。没有渲染试玩就如实注明。
- 美术／文案：可复用已许可静态背景，最多一个短场景意象；不能要求未来单独画“位格升阶”特效。中英本地化必须保持“共同依据、不同表现、已知限制”三个层次，不把 Plotinus 译为柏拉图的直传学生。

## 五、通过设计审查的条件

本候选必须同时满足：
1. 玩家完成了至少一次具体的核对或修订；无脑点最哲学化的选项不会奖励自己。
2. 玩家看得见被舍弃的另一项实际工作机会；差异有事实回显。
3. 共同的结构不能推导每处全部细节，特例不能否定任何共同根据的可能；任何结果都不由游戏确认为普罗提诺哲学的证明。
4. 正式出现资格由**已实现的路线及事件事实**给出，而非从设计文档、名字或来源推断；不破坏后续奥古斯丁既有 019/020 前置。
5. 设计与可玩性仍待实际试验。若“有限工时＋两次选择”仍让人感到是普通事件分支换哲学词，应先在本票内修改互动载体，再投入大量代码。

**核对范围：** 图接入、事件流程及生产战斗收益保留；ENC-199 已验证实际问号入口和前驱后战斗门控，完整纯逻辑、Godot 原生及 PCK 检查通过。部署记录与 Linear 单独核实，尚无本轮实际游戏内手动验收。
