# 利科当前设计（ENC-172）

## 承接位置

- 主要用途：回响。置于第三幕伽达默尔事件结尾，回看本局的解释与主体选择；不新增问号、不占独立节点、不要求第四幕。
- 图：不新增节点或边。回响页挂在 `GADAMER_FUSION` 事件的结果页之后。

## 玩家流程

伽达默尔房间的三选一提交后，结果页多出一个选项「听利科的回响」；进入回响页只读回记录，不再提问，随后关闭房间。回响不改变路线、不写路线字段、不影响存档兼容。

## 状态与保存

回响作为 `GadamerFusionStage.Echo` 与 `GadamerFusionAction.HearEcho` 记录在 `GadamerFusionState` 的确认动作里；旧档没有该阶段时按原状态恢复，不补发。
