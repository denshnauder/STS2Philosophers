# 普罗泰戈拉当前设计

## 三分钟摘要

- **当前结论：** 普罗泰戈拉在第一幕德性 Question 中让另一个行动者真实提出判断；共同事务不是单纯把更优算法交给对方。
- **玩家流程：** 完成苏格拉底德性路线首场普通战斗后，玩家在当场商议中选择保留自己的完整办法并亲自主持，或接受同伴对授权边界的修订并交出主持；双方都能拒绝替对方代言。
- **核心取舍：** 保留自己的完整程序就不能要求他人背书；允许交接就不能继续单方决定全部步骤。不同意也可以诚实完成回应。
- **界面与素材成本：** 一个标准事件、复用背景、固定称谓同伴和预写选项；无补给奖励、自由输入、多人头像或动画。
- **已完成：** 事件、Question 占位、完成边、逐动作保存恢复、双语文案、验证、构建和部署均已完成。
- **未完成：** 排版、节奏和共同实践是否有足够取舍感只作为之后的试玩反馈。
- **准确下一步：** 普罗泰戈拉的新扩展只从 Linear 的人物任务开始；现有事件不阻塞柏拉图后继。
