# 孟德斯鸠当前设计（ENC-135）

## 承接位置

- 主用途：固定。路线「制衡与公正」：柏拉图／制度开局 → 第一幕孟德斯鸠〔伏尔泰内批〕 → 第二幕康德〔制度〕 → 第三幕罗尔斯。
- 图：新增节点 `MONTESQUIEU__FREEDOM_AND_INSTITUTIONS__CORE`、`RAWLS__FREEDOM_AND_INSTITUTIONS__CORE`；新增边 051（柏拉图制度→孟德斯鸠，第一幕固定）、052（孟德斯鸠→康德制度，第二幕固定）、053（康德制度→罗尔斯，第三幕固定）。
- 伏尔泰的内批段与孟德斯鸠共用本事件房间，不新增问号、不占第二幕问号。

## 玩家流程

第一幕在柏拉图制度节点完成至少一场普通战斗后，地图边界插入本事件：

一位官员把立法、行政、司法三份文书塞进同一个抽屉，说这样办事更快。三个选择：

1. **分置三权**：三权各占一个抽屉、各自设防；采纳第一幕固定边，进入孟德斯鸠节点。
2. **以派系相互制衡**：对立派系各守一权，只要无人同时握住两个抽屉，制衡成立；同样采纳固定边。
3. **保留统一安排**：拒绝拆分，保留柏拉图式安排；本幕固定承接被放弃，停留在柏拉图制度节点。

结算页各有一句后果说明，随后「离开议事厅」关闭事件。

结算页另可「请伏尔泰核对此案」，进入内批段：

一名商人的小册子嘲讽行会游行，行会要求焚毁。三个选择：保护小册子（宽容，论证留在公开处）、以公共秩序查禁（秩序，论证转入地下）、维持制衡（拒绝裁决）。结算后回到孟德斯鸠结算页；内批段关闭后不再出现。

## 状态与保存

- `MontesquieuBalanceState`：阶段、待确认动作、已确认动作、标准（分置／制衡／保留）、是否采纳边、是否放弃固定幕、是否关闭，以及嵌套的 `Voltaire` 段与 `Inspecting` 标记；严格版本与重放校验。
- `VoltaireToleranceState`：阶段、结论（保护／查禁／维持制衡）、是否关闭；随宿主记录保存。
- `PhilosophyRunState.MontesquieuBalance` 随存档往返；旧档没有该属性时保持 null，不补发。
- 触发策略 `MontesquieuBalanceTriggerPolicy`：仅第一幕、单人、安全地图边界、柏拉图制度节点、`LastFixedAct == 1`、051 可承接时插入；已保存未关闭实例优先恢复。
