# 奥斯汀当前设计

> 阶段：第71位，ENC-165，主「内批」；已实现增量原生事件与逻辑检查，**未部署、未实机验收**，保持 In Progress。版本冻结 `0.5.24`。

## 领取与取舍

候选见 PR #4 的 `29剩余人物设计70-79.md`「71 奥斯汀｜《说出口就算了吗》」。采纳其核心：言语行为与施为的适切条件不同于说一句“我宣布”就改变所有权；说话者资格、约定程序、参与者理解和执行都可能失效。

本轮把它接在 **亚里士多德语言节点 `ARISTOTLE__LANGUAGE_AND_MEANING__CORE`，奥卡姆第二幕问号解决之后**，排在卡尔纳普内批之后；此时第二固定位已放弃，029/030 尚未完成。该窗口不新增图边、不占新的问号或固定位；卡尔纳普仍在开放时由 `HasOpenQuestion` 阻止奥斯汀抢占，关闭并访问后才轮到奥斯汀。这样两个内批是同一节点的先后可选事件，而不是同时堆叠。

## 玩家流程

1. 交接站：标准口令是“我交付钥匙”，但钥匙仍在锁柜里。玩家只能核对三项条件中的两项：发话者授权、接收者在场、约定程序完成。
2. 第二项核对后出现新事实：有人未经同意代签。第三项不能再核对，必须判断这句话实际能完成什么。
3. 三个终局：
   - 补完必要程序再交付：耗费一次优先通行机会，钥匙才生效；不把重复句子当成效力。
   - 撤回无效声明：花 10 金币找合法交接者；原话不授予任何东西。
   - 把话记录为待履行承诺：不打开锁柜、不授予门禁；以后履行仍需自己的条件。
