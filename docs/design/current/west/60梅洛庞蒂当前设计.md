# 梅洛庞蒂当前设计（ENC-160）

## 承接位置

- 主用途：固定。路线「具身知觉」：笛卡尔 → 第一幕胡塞尔 → 第二幕梅洛庞蒂 → 第三幕波伏瓦。
- 图：节点 `MAURICE_MERLEAU_PONTY__SELF_AND_OTHER__CORE` 与边 074（胡塞尔→梅洛庞蒂，第二幕固定）已在胡塞尔票补入；本票新增边 076（梅洛庞蒂→波伏瓦，第三幕问号 Switch）。
- 076 与萨特线的 061 是第三幕的两条跨周目替代收束，一局只承接一条。

## 玩家流程

第二幕在胡塞尔节点完成至少一场普通战斗后，地图边界插入本事件：

房间测量了伸向杯子的手，数字描述出一套机制。三个选择：

1. **身体作为知觉主体**：采纳 074，进入梅洛庞蒂节点。
2. **保留客观身体**：同样采纳 074，记录客观化标准。
3. **保留胡塞尔**：放弃本幕固定承接，停留在胡塞尔节点。

## 状态与保存

- `MerleauPontyBodyState`：阶段、待确认动作、已确认动作、标准（身体／客观／胡塞尔）、是否采纳边、是否放弃固定幕、是否关闭；严格版本与重放校验。
- 随 `PhilosophyRunState.MerleauPontyBody` 保存；旧档缺属性时为 null，不补发。

- 未做实机渲染与整局试玩；版本保持冻结的 0.5.24。
