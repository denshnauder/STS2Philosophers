# 恩培多克勒当前设计

## 三分钟摘要

- **当前结论：** ENC-107 在第二幕德谟克利特固定选择之后，以一次标准问号事件“四根的配合”比较另一种回应爱利亚挑战的模型。`WESTERN_EDGE_006` 是并行比较的 Keep 边，不转移原子论主线。
- **玩家流程：** 玩家已明确接受德谟克利特的原子与虚空后，在第二幕实际问号被原生抽为 Event 时才可能接受或拒绝比较。接受者先选择要解释“多样事物怎样组合”或“原有组合怎样分开”，再对四种不生灭的根作一次混合或分类示意，最后明确记录有限比较或只保留原子论。拒绝、中止和只保留均耗费本幕问号。

## 来源与解释边界

[SEP《Empedocles》](https://plato.stanford.edu/entries/empedocles/)介绍土、水、气、火四根和爱、争两种作用，认为四根不从无中产生，也不彻底消灭；不同根的结合与分离构成变化的解释。宇宙周期的阶段、生成次数及诗篇关系仍有争议。本事件只展示模型的局部解释力，不强行认定某一周期重建，更不把恩培多克勒写成德谟克利特的学生或后继发明者。两者是回应同一压力的并行比较。

## 完整决策循环

1. **邀请与机会：** 单人第二幕、当前德谟克利特存在／变化节点，已完成 `WESTERN_EDGE_005`，固定选择为本幕完成状态且 Question 未用、实际问号被原生抽为 Event 时邀请。持琴弓与原前驱已由德谟克利特入场保证；本事件不额外改写前驱。拒绝立即预约并耗费本幕问号。
2. **选解释负担：** 接受后选择“同样的根为何能组成不同事物”或“既有组合为何能散开”。这只是本次示意的提问，不把物质重排当成道德选择。
3. **操作示意：** 模型给出土、水、气、火各一份。对组合问题，玩家可把四份混在一起，或仍按类分开；前者展示异类结合，后者保留分离状态。对分离问题，先给四份混合，玩家可按类分开或保留混合；前者展示分离但不创造新根，后者展示结构依赖配合。爱与争均可能改变组合关系，不简化为纯善与纯恶。
4. **承担结论：** 每个结果都允许明确记录恩培多克勒的有限并行比较，提交既有 `WESTERN_EDGE_006`、记已见人物而保持德谟克利特当前节点；或只保留原子论而不提交边。记录不认证模型为唯一真理；保留也不算答错。两者都不发金币、战斗增益或遗物。
5. **失败与恢复：** 邀请先预约问号并保存原生事件房间，按钮动作按准备→提交→再保存。旧档无此事件时保持缺席；未知、残缺或矛盾状态保留并冻结，不清空重邀。已提交相同结果可恢复确认，陈旧按钮与重复回调不能换选或重复写边。
6. **退出与后继：** 事件返回同一地图。`WESTERN_EDGE_007` 的伊壁鸠鲁第三幕固定前置仍是已接受的德谟克利特路线；006 的 Keep 比较不替它改前驱或提供额外资格。

反例：仅把四种色块混合不证明真实四根；分堆不说明所有生命如何形成；爱／争不可等同玩家好坏阵营；第二幕问号不与赫拉克利特留线的阿那克西曼德分支同时发生。正式内容使用文本模型，不承诺可视化物理模拟。
