# 安瑟尔谟当前设计｜ENC-120 候选规格（待合法问号入口审查）

> 阶段：仅设计候选，**未实现、未测试、未部署**。第25位，主「问号」，兼「内批、实践」，问题「知识与怀疑」；保留89人既定顺序和用途，ENC-120 应继续为 Todo。

## 三分钟摘要

- **问题：** 人们能否从一种特殊的概念描述推到现实存在？如果一套推理能同样「证明」理想岛，说明了什么，又没有说明什么？
- **事件：** 《未写完的证明》。玩家先选择自己愿意公开承担的论证范围；有人提出理想岛的反例；玩家用仅余一次答辩机会选择**直接公布、改写范围、保留争议或撤回**。第一次断言与后来的修订不可互相覆盖。
- **核心操作：** 一个论证结构清晰的两回合公开听证；原生事件选择按钮、短小的可见「论证账页」，以**有限答辩席位与是否留下公开记录**作为即时机会成本。它不判「神存在」或「神不存在」为游戏正确答案。
- **关键阻断：** `config/western_graph.json` 当前没有 ANSELM 节点或合法边；「知识与怀疑」现有第一幕012塞克斯都问号、第二幕013笛卡尔固定及014休谟问号均不能被默认覆盖。具体可用幕位、路线和遗物资格必须由 Codex 核对后批准；不能为了补齐89人而凭空添加出场。

## 一、研究依据与争议边界

1. 《宣讲篇》（Proslogion）第二章将「无可设想更伟大者」（that than which nothing greater can be conceived）置于存在于理解中、现实中和可设想更伟大者的论证关系里。它不是「我想到某物，所以它存在」这种普遍结论，也不是用物理尺寸比较最大物件。
2. 第三章与安瑟尔谟给高尼罗的答复涉及不能设想其不存在等更强主张，不能把复杂解释争议全部塞进第一章短句后由游戏宣告证明完成。
3. 高尼罗《为愚人辩护》的「失落的岛」试图以类似结构推出荒谬的理想岛存在；它对论证的哪些形式有效，以及安瑟尔谟的实际回应如何解释，学界有分歧。游戏允许玩家辨认类比的适用范围，**不得**自动宣称「岛屿反例已经彻底推翻安瑟尔谟」或「回应已经彻底证明神」。
4. 「信仰寻求理解」说明这场讨论的原有宗教语境。玩家可以评价推理形式而不必由系统替其选择宗教信仰；不以信仰、怀疑或辩论获胜作为道德得分。

**史料入口：** [Proslogion II–III](https://sourcebooks.web.fordham.edu/source/anselm.asp)；[高尼罗《为愚人辩护》与安瑟尔谟答复](https://sourcebooks.web.fordham.edu/basis/anselm-gaunilo.asp)；[SEP：Saint Anselm](https://plato.stanford.edu/entries/anselm/)；[SEP：Ontological Arguments](https://plato.stanford.edu/entries/ontological-arguments/)。
「听证、账页、一次答辩席位」均为游戏创作，不宣称历史上发生过该具体听证。

## 二、一次原生问号《未写完的证明》

**场景：** 一处中转站的公开书案上留有两条经过争论的论证摘要。发言人准许玩家先把一条主张放入听证记录；一位质疑者随后提出「如果这样推，也能证明最理想的岛存在」的挑战。公开席位时间有限，本轮只能完成一次最终公开发言或一次细致改写，不能同时占用两份发言记录。

### 甲．选择承担的主张（打开论证账页）

玩家能够看到简短标注：
- **理解中存在一个描述**，并不等于已经承认其在现实中存在。
- **「无可设想更伟大者」**与「某类物品中最好的一个」之间，存在待审查的类别差异。
- 本轮首次发言不可在事后悄悄删除；后来的撤回或限制可以追加。

可选择：
1. **「我主张：无可设想更伟大者的论证值得辩护」**（记为 `Scope=UniqueBeing`）。
2. **「我主张：凡能想出的最完善事物都应真实存在」**（记为 `Scope=UniversalMaximum`；这是故意较宽的可检验主张，**不是**安瑟尔谟本人被确证采用的论证）。
3. **「我先只提出问题，不公开结论」**（记为 `Scope=QuestionOnly`）。

仅记录初次主张，不增加金币、卡牌、信仰值或随机奖励；选择3也会进入反例阶段，不能借「暂不回答」获得免于回应的奖励。

### 乙．质疑者提出「理想岛」，玩家指定反例的作用

可见事实：有人把「最理想的岛」代入有关最完善存在的推理，声称由此能推出这座岛必须存在。玩家**必须**先选择怎样对待该质疑（不消耗答辩席位）：
- **「它直接针对我刚才使用的普遍规则」**：若首次选择 UniversalMaximum，账页可明确记录「普遍化承受反例压力」；其他初次主张下不得显示「已经驳倒」的结论。
- **「理想岛与无可设想更伟大者的论证范围不同」**：账页只记录有待论证的范围区分，不能因为选了这句话就判定回应成功。
- **「我尚不能判定类比能推到哪一步」**：保留未解决的反例，不当作已证实或已证伪。

这一步产生 `ObjectionTreatment`，实际界面显示「原主张 / 当前针对的推理环节 / 尚缺的证明」。

### 丙．只剩一个发言席位：选择真实取舍

玩家可在**一次**公开席位内做一项工作：
1. **「保留原主张，公开回应」**：会发布原有主张和刚才的反例处理；如 UniversalMaximum 遭理想岛攻击，必须显式保留「仍受强烈质疑」标记，不得把措辞说得漂亮就升级为证明成功。
2. **「缩小范围并重写论证」**：保存从旧主张到新范围的修订历史；本轮只能交出**尚待下一位审阅的草稿**，放弃立即发布完整回应的机会。
3. **「撤回此前主张，公开保留质疑」**：对先前发言留下有来源的撤回记录，不抹去曾经说过什么；本轮无法拿到「已发表论证」的结局。
4. **「不再占用席位，直接离开」**：没有新的审查成果，先前范围与反例处理仍保存；关闭后不重刷。

最终页面简要并排显示：初次主张、接受到的反例、最后留下的公开记录/未完成草稿/撤回声明。**即使选择了宗教立场相近的陈述，也不能据此在游戏里判定逻辑证明正确**。

### 游戏性审查门槛

这一候选刻意让玩家在「尽快公开并承担异议」与「留下更精确但未公开的修订」之间二选一，以时间席位而非道德分作代价。它是一种**论证结构操作**，而不是把塞克斯都「暂缓判断」事件换个名字。

**必须否决的情况：** 若最终所有结局都仅以文字不同而对玩家后续状态没有任何可感知区别，或存在「缩小论证范围」恒为无成本上位选项。进入编码前，Codex 需验证：至少当前公开记录／草稿状态在本局后续实际可回看或可被合法知识路线后继读取；若项目当前不支持这个最小可感知后果，则先保留候选，不把它包装为合格玩法。

## 三、与现有知识人物不同在哪里

- **塞克斯都：** 并置观察结果、悬置特定判断，同时实际走地图；本事件要求玩家**说明一套具体推理如何面对某个反例**，并在公开结论与修订精度之间分配有限席位。
- **笛卡尔：** 暂撤共同假设以寻求可靠起点；本事件聚焦一条特殊的存在论证及其类比反驳，不借「我思」作救援。
- **高尔吉亚：** 关注说服和听众收到的话；本事件必须显示前提、推理作用范围、反例落点和修改历史，漂亮话不能替代论证。
- **奥古斯丁：** 人内在意志、所爱与实际履约不同于一场关于概念和存在的争论；不因安瑟尔谟的宗教身份自动要求先完成奥古斯丁的制度线。
- **阿奎那（后继人物）：** 阿奎那的论证手段、对安瑟尔谟论证的态度及神学与哲学的区分必须独立审查；不能把玩家在这里的选择称为已证明五路。

## 四、生产接入约束（尚未满足）

- 现有 `config/western_graph.json` 的知识路线节点只包括苏格拉底、塞克斯都、笛卡尔、休谟、康德；无安瑟尔谟节点、可接受的新边或原生人物资格。**不能用既有012/013/014边的编号或完成事实指代本角色。**
- 历史定位处于古代怀疑与近代方法怀疑之间的中世纪哲学语境，不能凭「89人名单排在笛卡尔之前」就直接插入塞克斯都→笛卡尔的单线必经节点。对思想史的真实中介、保留跨时代争论开放结构；世界观可用一份后世读到的旧文本而非强迫历史人物同场。
- 候选生产方案只作**待核查**：在已满足知识线遗物资格且第一幕塞克斯都完成的某个**独立问号机会**出现，须与第二幕已有休谟 Question 及笛卡尔 Fixed 明确互斥或另有合法槽位。未经检查不得抢现有随机问号、跳过前驱或改既有边。
- 与公共阻断 Bug **ENC-194** 保持分离：不得让新事件在敌人死亡而原生奖励尚未完全出现时触发；只能考虑已证实的地图安全边界。

## 五、状态、原生恢复与最小验收

- 状态：版本、局/事件身份、合法触发来源、初次范围 `Scope`、反例处理 `ObjectionTreatment`、最后公开行动 `Disposition`、原主张与修订记录、完成与关闭标记；页面由状态推导，不能反向篡改已提交结论。
- **事务边界：** 首次主张、反例处理、终局答辩分阶段提交；确认前允许原生返回，确认后重复点击/加载不重复占席位、不重新开放未选分支。所有无效/未知载荷必须安全隔离，不推断玩家的信仰或将缺失状态当成选择。
- 纯逻辑测试：三种 Scope × 三种反例处理 × 四种最终行动，尤其“普遍规则受理想岛压力”与“窄范围未被反例自动推翻”；旧档、坏档、重载、重复LEAVE、不满足路线资格、问号机会冲突。文案中英键必须完整且按钮短。
- 原生验收：合法事件池/固定资格→地图安全邀请→原生 EventRoom→完成结论并读档→原目标地图继续；Boss、奖励叠层和多角色互斥必须不受影响。计划兼容 RitsuLib 保存，实际集成、Release/PCK、部署仅在合法入口确认和 ENC-194 修复后开展。
- 素材：一个可复用静态背景，论证账页由已有 EventRoom 正文显示，无拖拽 UI、新牌、新遗物、新地图或自制模拟法庭。

## 审查结论

本候选能描述具有先后关系、可被反例挑战的论证操作；**独立的合法问号入口和公开结论的可感知后果尚未落实**。这两项是明确阻断，不得因文档完成把 ENC-120 改成 Done，也不能把一堆分支文字当成真正的机制差异。
