# 牛顿当前设计

## 定位

- ENC-128 第33位人物，主要用途固定，标题《一条定律，两处试验》。
- 主要用途固定，兼任回响、转线；本轮只实现已授权的第三幕固定内容。
- 实现与自动逻辑／原生检查已完成；游戏界面与完整试玩尚未验证。

## 设计来源与取舍

- 采用候选 PR4 HEAD `cf2cf9aa` 第33节思路：同一关系、两处试验，保留原始读数与误差，本地校准不等于远程证明。
- 将候选的 25 金/补给惩罚改为转移一份校准材料；不引入原生金币、生命、补给消耗，也不新增遗物。
- 区分《原理》中的运动定律与引力；不声称潮汐或落体虚构读数能证明一切未知。

## 实际入口

- 单人第三幕原生真实地图 Unknown，以 Event 形式抽取。
- 苏格拉底知识杯为唯一教义；实际匹配需已闭合可用的塞克斯都，以及重建后的有限判断已闭合笛卡尔，之后为非 Boss 战斗。
- 无皮浪、安瑟尔谟实例；第三幕固定机会尚未使用，没有未闭合的路线问号事件。
- 条件只给资格，不保证触发；原生随机与队列不变。
- 真实来源图节点仍为苏格拉底，经由既有已保存的笛卡尔事件；仅为采用的 Conditional/Rechecked 增加合法牛顿知识节点与 edge049 Fixed3，不虚构笛卡尔/伽利略前驱节点，也不强制同局推进。

## 流程

1. 邀请：接受或拒绝。
2. 选择 Drop 或 Tide。
3. 保留第一处原始误差。
4. 揭示对侧试验的阻力。
5. 选择：
   - Conditional：保留第一处校准。
   - Rechecked：把唯一材料转移到另一处，放弃第一处校准。
   - Local：只保留本地有限结论，不获得牛顿校准加成。

## 效果

- Conditional/Rechecked 保留原知识杯效果，并追加校准加成：每个玩家回合结束时，恰好两张手动牌按 Attack→Skill（校准 Drop）或 Skill→Attack（校准 Tide）顺序打出，获得 6 格挡，每回合一次；自动牌不计，第三张手动牌使加成失效。
- Local/Decline 保留原知识杯与苏格拉底节点，无牛顿加成。
- 所有最终决定消耗 Fixed3；Local/Decline 保留原结局，不作为业务 Question3。
