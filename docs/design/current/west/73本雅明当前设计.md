# 本雅明当前设计（ENC-175）

## 承接位置

- 主要用途：问号（可选历史视角）。按票内 2026-10-30 设计：本雅明置于福柯第二幕事件内的历史视角，与主事件共用问号房间，不新增第三幕问号、不占独立节点。
- 图：不新增节点或边。视角页挂在 `FOUCAULT_POWER` 事件的结果页之后。

## 玩家流程

福柯房间三选一提交后，结果页新增「读本雅明的历史视角」；视角页逆着纹理读同一份档案，不再提问，随后关闭房间。该页不改变路线、不写路线字段、不影响存档兼容。

## 状态与保存

视角作为 `FoucaultPowerStage.Benjamin` 与 `FoucaultPowerAction.BenjaminHistory` 记入 `FoucaultPowerState` 的确认动作；旧档没有该阶段时按原状态恢复，不补发。
