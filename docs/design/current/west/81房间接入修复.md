# 已交付房间的问号分派与注册修复（集成缺口）

## 缺陷

`NativeQuestionNodeEvents` 的原生问号分派链和 `RouteEventMapBoundary.IsRegisteredEvent` 的注册链在 2026-10-30 的一批房间交付中没有同步扩展：弗雷格、罗素、维特根斯坦、索绪尔、列维斯特劳斯、德里达、福柯、德勒兹、伽达默尔、霍克海默、阿多诺、哈贝马斯、弗洛伊德、拉康共 14 个独立房间的 State／Patch／Event／本地化／逻辑检查都在仓库里，但补丁从未被调用、事件也未注册，正常新局无法遇见。

同批的内批人物（本雅明在福柯房间、利科在伽达默尔房间、卡尔纳普／奥斯汀／波普尔等）走宿主房间的分页，不受此缺口影响。

## 修复

- 两条分派链（开放实例恢复、原生新建）都补上这些补丁；`IsRegisteredEvent` 补上对应事件类型，使房间恢复、持久化与冻结路径可用。
- 新增 `RoomIntegrationChecks`：扫描 `src/Philosophy/*State.cs` 中带 `CompletionEdgeId` 且存在同名补丁的房间，要求分派链含 `TrySelectNative`（有开放实例方法的还要含 `TrySelectExistingNative`），注册链含事件类型。此检查在修复前会逐个报出缺失项。

## 证据

- 修前：`RoomIntegrationChecks` 报 `XxxPatch must be reachable from the native question dispatch chain.`
- 修后：ModLogicChecks 全绿（含 79 节点覆盖与 46 个房间接入扫描）；主工程 build 0 error；原生套件 exit 0；内容 PCK 构建通过。
