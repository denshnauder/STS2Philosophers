# 皮浪当前设计

## 证据与位置

第 21 位主要用途「问号」，兼任研究，属于知识与怀疑。皮浪本人无留存著作；[第欧根尼·拉尔修《名哲言行录》IX.61—62、102](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Diogenes_Laertius/Lives_of_the_Eminent_Philosophers/9/Pyrrho*.html)转述关于他是否日常避险的相反证言，明确区分安提柯努斯的危险故事与埃奈西德摩斯的“日常仍有预见”说法。[优西比乌《福音的准备》XIV.18](https://www.tertullian.org/fathers/eusebius_pe_14_book14.htm)又经亚里士多克勒转引提蒙的概述，转述链与论敌立场都不可抹去。这里只展示传述证据的边界，不让皮浪本人说出后世塞克斯都的体系，也不拿一次选择裁定史学争议。

既定知识路线第一幕问号已由塞克斯都保留，第二幕若接受笛卡尔，既定问号属于休谟。因而本事件仅在**第一幕塞克斯都事件已关闭、第二幕笛卡尔邀请被明确谢绝**的支路占用当幕尚空的问号；不与休谟可走的笛卡尔支路竞争。笛卡尔事件关闭后须进入另一实际问号，且由原生抽为 Event 才可能遇见。保持苏格拉底知识节点、诘问杯和原生地图；没有合法问号 Event 时本局不强行出现。

## 玩家问题

战后档案摊上，一页题为“皮浪”的抄录一面说他不避车与悬崖，另一面说他日常并非没有预见。抄录不是皮浪手稿。玩家先决定怎样向同行者描述来源：**注明两种后来证言尚冲突**，或**把其中一种说成皮浪本人的命令**，也可拒绝处理这页材料。前两种说法保留为可见事实，不把“正确答案”转换成数值奖励。

同行者随后问眼前湿滑的短桥怎么走。玩家必须再做一项有限行动：**检查可见桥板并谨慎通行**，或**请熟悉此路的向导先查看再通行**。两种做法耗用不同的时间与他人协助，在事件文本中明确；不按史料争论推出必须冒险、永远不行动或无痛。若最初把二手材料说成直接命令，结果页会保留该越界说法并指出后续行动无法验证它。谢绝分支不虚构过桥行动。

此题与塞克斯都的两盏灯不同：那边并置当前显现与同意，这里处理传述来源、冲突证言和眼前行动的分层。玩家代价是本幕问号机会，收益是完整的史料问题与行动反馈；不发遗物、金币或战斗收益，不改图边、主说和现有结局。

## 保存、制作与反例

使用现有原生标准事件及静态背景别名，双语短页面，无新场景或动画。进入前确认实际问号被原生抽为 Event、单人、第二幕、苏格拉底知识节点、诘问杯仍持有、塞克斯都与被谢绝的笛卡尔事件合法关闭，且第二幕问号未用；原图守卫只在这种分支预留一次问号。选择采用待提交→保存→确认→再保存的现有事务形式；旧档无本记录即未遇见，损坏记录不能重邀。两种来源说法×两种通行动作及谢绝路径均可保存恢复。

反例：若笛卡尔被接受，不能抢休谟问号；若原生游戏只剩 Boss，不能用 Boss 或新图节点凑触发；若塞克斯都未出现，不能把苏格拉底自知无知伪称为皮浪传统；若玩家只听到危险故事，不能把不避险写成经证实的皮浪生平或游戏义务。
