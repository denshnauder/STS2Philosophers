# 西哲当前路线

## 三分钟摘要

- **当前结论：** 六位西哲入口人物与孔子、墨子、老子组成九人池；每局展示三位。苏格拉底只占一个人物位置，再在知识与德性之间二选一，共形成七种入口战斗实践。
- **玩家流程：** 入口实践在原生战斗中改变选择；知识路线可遇到塞克斯都并在第二幕经历笛卡尔，德性路线可依次经历普罗泰戈拉、柏拉图、伊壁鸠鲁，或在第三幕进入第欧根尼与芝诺的互斥终点。
- **核心取舍：** 每种实践必须改变可做之事并承担真实代价；事件不发哲学正确答案奖励，也不让胜负证明思想正确。
- **界面与素材成本：** 入口只复用战斗、卡牌和遗物界面；人物事件使用标准事件和少量静态图，不新增地图节点。
- **已完成：** README 所列七种入口实践、普罗泰戈拉、柏拉图、伊壁鸠鲁、塞克斯都、笛卡尔、第欧根尼与芝诺内容均已完成相关验证、构建和安全部署。
- **未完成：** 89人中其余人物仍按合法用途保持研究、候选或未接入；试玩反馈不会自动改写当前设计。
- **准确下一步：** 按 Linear 的人物 `Todo` 逐一读取本目录对应入口，不从 Drive 旧页或历史 Dxxx 段落恢复任务。
