# 西哲当前路线

## 三分钟摘要

- **当前结论：** 六位西哲入口人物与孔子、墨子、老子组成九人池；每局展示三位。苏格拉底只占一个人物位置，再在知识与德性之间二选一，共形成七种入口战斗实践。
- **玩家流程：** 入口实践在原生战斗中改变选择；第欧根尼与芝诺已有第三幕去留路线。知识线的塞克斯都／笛卡尔及德性线的普罗泰戈拉／柏拉图／伊壁鸠鲁等后继事件已有实现，但普通返图入口存在缺口，修复交付前不能承诺这条完整体验可达。
- **核心取舍：** 每种实践必须改变可做之事并承担真实代价；事件不发哲学正确答案奖励，也不让胜负证明思想正确。
- **界面与素材成本：** 入口只复用战斗、卡牌和遗物界面；人物事件使用标准事件和少量静态图，不新增地图节点。
- **已完成：** 七种入口实践、第欧根尼／芝诺以及其余既有人物事件有相应实现、验证、构建和安全部署记录；部署事实不替代各事件生产入口可达性。
- **未完成：** 巴门尼德、德谟克利特、普罗泰戈拉、柏拉图职责、伊壁鸠鲁、塞克斯都、笛卡尔重建及亚里士多德制度等战后入口的共享修复尚待验证与安全部署。其余89人用途仍分研究、候选和未接入，马基雅维利草稿未交付。
- **准确下一步：** 先在已有授权范围安全收尾公共入口阻断；人物按 `western_research.json` 的 `people` 顺序和真实依赖继续，同人内再看优先级与创建时间，不从旧页找工作或跳到后序人物。

## 当前交付边界（2026年10月17日）

旧段落中“相关验证、构建、部署完成”保留其历史事实，但不能据此沿用“普通战后一定遇到”的结论：这些后继补丁监听 `EnterRoomInternal(MapRoom)`，普通战后却只打开地图、当前房间仍为已完成的战斗房间。当前共享修复与马基雅维利均未成为已验证部署；修复的代码存在也不能提前写成已解决。第欧根尼使用第三幕幕初入口，芝诺已监听真实地图打开，两者不因这项共同问题而被一概判定无效。最终完成状态须核对原人物 Issue 的合法接入、内容、验证和安全部署证据。

## 入口遗物反馈边界

ENC-192保留未琢之石既有完整循环：手动出牌的牌种统计→唯一最多且至少2次形成惯例→下一回合首张正费用同牌种减费→实际结算后存活敌人各加1力量。不同实例与强化版本合计，自动出牌不计；未抽到、费用已为0或未使用时不付力量代价；无新唯一最多时旧惯例延续。这是效率与给敌人增益的取舍，不以战斗胜负证明卢梭的历史主张。当前牌种和一次性预算用既有遗物悬浮与原生卡牌提示呈现，无额外场景、图标或动画。旧版公共出牌身份误判的修复和原生集成证据见DEVELOPMENT，不把纯逻辑通过当作实机反馈已被替代。
