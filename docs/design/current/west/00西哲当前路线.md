# 西哲当前路线

## 三分钟摘要

- **当前结论：** 六位西哲入口人物与孔子、墨子、老子组成九人池；每局展示三位。苏格拉底只占一个人物位置，再在知识与德性之间二选一，共形成七种入口战斗实践。
- **玩家流程：** 入口实践在原生战斗中改变选择；第欧根尼与芝诺已有第三幕去留路线。知识线的塞克斯都／笛卡尔及德性线的普罗泰戈拉／柏拉图／伊壁鸠鲁等既有后继，在符合路线、幕、遗物与机会条件时，从战斗奖励结束后的真实返图入口邀请。
- **核心取舍：** 每种实践必须改变可做之事并承担真实代价；事件不发哲学正确答案奖励，也不让胜负证明思想正确。
- **界面与素材成本：** 入口只复用战斗、卡牌和遗物界面；人物事件使用标准事件和少量静态图，不新增地图节点。
- **已完成：** 七种入口实践、第欧根尼／芝诺以及其余既有人物事件有实现记录；九个既有事件的真实返图、精确原生房间保存及恢复保护已随0.5.4验证并安全部署。0.5.5 加入阿那克西曼德第二幕问号；0.5.6 加入阿那克西美尼第三幕凝散实践，均完成相称检查和 Mac 部署。
- **未完成：** 本轮没有渲染界面或整局实机回放。其余89人用途仍分研究、候选和未接入，马基雅维利草稿未交付；共享修复不能代替逐人物验收或批量关闭原票。
- **准确下一步：** 按 `western_research.json` 的 `people` 顺序和真实依赖继续；主要用途研究按研究成果验收，其他玩家内容仍须实现验证部署。阿那克西美尼当前批次须完成 Git 与 Linear 收尾后再核对下一位。

## 入口遗物反馈边界

ENC-192保留未琢之石既有完整循环：手动出牌的牌种统计→唯一最多且至少2次形成惯例→下一回合首张正费用同牌种减费→实际结算后存活敌人各加1力量。不同实例与强化版本合计，自动出牌不计；未抽到、费用已为0或未使用时不付力量代价；无新唯一最多时旧惯例延续。这是效率与给敌人增益的取舍，不以战斗胜负证明卢梭的历史主张。当前牌种和一次性预算用既有遗物悬浮与原生卡牌提示呈现，无额外场景、图标或动画。旧版公共出牌身份误判的修复和原生集成证据见DEVELOPMENT，不把纯逻辑通过当作实机反馈已被替代。
