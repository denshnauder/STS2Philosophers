# 巴门尼德当前设计

## 三分钟摘要

- **当前结论：** ENC-106 使用第一幕赫拉克利特路线的一次标准问号事件“不可说的来处”，让玩家先固定自己在谈什么，再承担生成论证的边界。不是把“重复打同名牌”当成存在不变。
- **玩家流程：** 获得琴弓并完成战斗返回地图后，可接受或拒绝。接受后先选谈论整体的“有”，或谈论眼前一只改铸的杯；两种所指进入不同质问。玩家可承担不诉诸非有的道路并转向巴门尼德，或保留变化判断并承担尚未完成的论证，也可中止。
- **核心取舍：** 谈材料与形状可以保留经验描述，却不能据此声称回答了存在本身从何生成；转向巴门尼德则撤回生成的真理断言，失去用普通物件改形直接反驳他的出口。没有金币、战斗增益或答对奖励。
- **界面与素材成本：** 原生事件按钮和短页；复用诸子观照静态背景，无新场景、物件画、动画、NPC或战斗UI。杯与铜是论证例子，不假装游戏内完成了铸造模拟。
- **已完成：** 事件、双语、严格行动重放、明确转向与问号预约已实现；10条完整路径及两次保存边界检查通过，Release零警告零错误、PCK加载与纹理校验通过。没有赫拉克利特与巴门尼德直接师承或面对面对话的历史断言。
- **交付状态与未完成：** 用户退出游戏后，已安全部署同一批已验证产物，三文件哈希一致且保留旧部署回退点，现在可在游戏内遇到。原有“三次同名牌加格挡”仍是未接入练习，不作为人物正式表达；尚未人工实机体验。
- **准确下一步：** 返回Linear领取下一个依赖已满足的授权任务；本事件后续体验问题另票处理，不预先扩写未授权后继。

## 研究与解释边界

[残篇译文](https://web.stanford.edu/~jsabol/sophia/parmenides.html)保存 B7—B8 对“非有”与生成来源的追问；[SEP](https://plato.stanford.edu/entries/parmenides/)说明一元论、逻辑、模态及现象地位的解释存在争议。游戏取其论证压力，不把巴门尼德简化为“用眼看错了”或“不许移动”。杯的改形不是物理反驳，也不把材料守恒当作他的完整主张。玩家能坚持变化，但必须明确自己拒绝或尚未证明的是哪一步。

## 玩家操作、后果与反例

1. 第一幕，单人、当前赫拉克利特节点、当前仍持琴弓、已完成至少一场战斗且本幕问号未用时，在地图已建立后邀请一次。先预约问号再持久保存，拒绝也不刷新。
2. 首先固定所指：“谈有本身”进入整体生成质问；“谈这只杯”进入杯与铜的区分。不能在下一页偷偷把整体现有换成材料或器形。
3. 整体分支可以承认不生不灭的推论，或明确保留变化、拒绝从不可谈非有推出一切生成不可能。杯分支先面对“有铜不等于已有这只杯”；选择相对否定，只能到“不是杯是否等于绝对非有”的边界页，不能直接领取“驳倒巴门尼德”。
4. 正式转向必须有独立明确选择，才通过既有预约问号完成 `WESTERN_EDGE_001`。保留／中止／拒绝不提交该边，不假装改宗。琴弓继续作为既有战斗工具，不叠加新主能力、不发奖励；路径变化记录在局内历史。未实现的后继不提前许诺出场。
5. 中止保留已做过的所指选择，结果标为未完成；不能借退出重选另一所指或刷问号。每个终点共享一次原生继续，回到原来的地图。

反例：改铸杯不能证明宇宙从无生成；改称铜不能自动消除对生成的质问；选巴门尼德不获得奖励，也不把战斗胜利当作存在论证据；保留赫拉克利特不是低级失败；不能通过返回与读档抹掉先前所指。逻辑检查证明状态和记录一致，不证明思想转译、平衡或实际体验已经成立。

## 实现与恢复

名称：不可说的来处；模型 `ParmenidesInquiry`／`PARMENIDES_INQUIRY`；状态与策略用同名前缀；本地化 `PARMENIDES_INQUIRY.*`；背景资源 `parmenides_inquiry.png` 只做既有图的PCK别名。保留全部已公开模型身份。

核对 RitsuLib 0.6.2、现有共享适配器和原生 `EventRoom`／`SaveRun`，复用现有局内保存槽与地图叠层，不新建存档框架。业务记录保存实例、阶段、确认行动序列、待提交行动与关闭事实，严格重放行动验证阶段。旧档缺少新字段视为尚未遇到；未知／矛盾实例停用，不清空重邀。准备保存→同步提交状态及路线→再次保存；重复回调和读档只能续同一行动，转向已提交时只接受相同目标与边。保存失败保留待提交状态，不给额外效果。
