# 阿奎那当前设计｜ENC-121

## 范围与来源

本轮兑现既定主用途“固定”，只取“自由与制度”问题面。阿奎那在《神学大全》I-II q.90 a.1–4区分法律所需的理性、共同善、正当制定者和公布；q.96 a.4–6讨论不公正法律、统治者与紧急个案。翻译、注释和中世纪重构是本事件的背景，不把阿奎那写成与亚里士多德同时在场的师徒，也不把玩家操作当成神学或法学判决。[q.90 原文译本](https://www.newadvent.org/summa/2090.htm)、[q.96 原文译本](https://www.newadvent.org/summa/2096.htm)。

[设计候选 PR #4](https://github.com/denshnauder/STS2Philosophers/pull/4) 当前 HEAD `cf2cf9aa7c51be6c7baec9d3175ef4c1e09d6644` 的第26人章节提供“矛盾告示—核对—未公布例外—收束”的场景和第三幕制度固定连接。采纳其历史边界、第三幕制度而非语言029的区分，和不使用未验证金币／HP交易的限制。调整最终玩家代价：不声称文本选择本身改变通行、金币或地图；采用后必须占用第三幕 Fixed，后续战斗还要以**第一张手动牌**兑现自己选定的公开规则，另一种牌失去该场机会。拒绝则明确放弃本幕 Fixed。本选择不证明一种法律天然正当。

新增 `THOMAS_AQUINAS__FREEDOM_AND_INSTITUTIONS__CORE` 及 `WESTERN_EDGE_045`，只从已实际提交的亚里士多德制度016进入第三幕 Fixed。要求现行制度节点、016 已完成、亚里士多德事件已关闭、仍持柏拉图城邦印章、`LastFixedAct=2`、第三幕 Fixed 尚空且017未完成。只在第三幕已完成并领取奖励的非 Boss 普通战后安全返图邀请；已保存事件只能恢复同一实例。029/030语言线及退休031保持原样，第二幕语言阿奎那不由本票冒用。017若以后得到生产入口，完成它的局优先保留需要017的霍布斯018资格；本候选不抢该第三幕 Fixed。采用045或明确拒绝都会让本局失去其他第三幕 Fixed 机会。

## 一次完整决策

原生事件《两份渡桥告示》先让玩家接受或谢绝核对。接受后在“谁有权修订”和“修订是否公开可见”之间选一项先查；不把未查的另一项自动判为已证。随后桥板当场断裂，而代理人声称的例外既未张贴也未获核验。玩家可：

1. 请求有权限者公布修订和申诉渠道，记录自己放弃了不受公布规则约束的便捷通行；采用045并选“公开修订”实践。每场战斗**第一张手动牌若为技能**，结算后获得5格挡；若先打攻击／能力，则本场此项不发。它只表示这一局已承担的防护操作，不代表法律已获无条件认可。
2. 先查验现场断板，只有立即危险来不及请示时先让旅人避开，只为这一具体情形公开狭窄的临时例外；情况存疑或容得等待则应请示有权者，不授予永久自行解释权。采用045并选“紧急例外”实践。每场战斗**第一张手动牌若为攻击**，结算后获得1能量；若先打其他牌，则本场此项不发。它表示先行动的机会成本，不把所有例外自动称为正当。
3. 暂不替未公布的修订背书，沿用亚里士多德制度主线；本局放弃第三幕 Fixed，没有阿奎那战斗收益。

首次核查项、揭示事实、最终行动、图边／拒绝、关闭以及遗物首张手动牌回执分别保存；重复按钮、重复卡回调或读档不重复发收益。损坏／未知载荷保持原样且不补发。事件只用原生页面、现有城邦印章和静态背景，不新增地图节点、卡牌、动画或美术。失败的持久化使事件留在恢复态，不让玩家在未确认提交时移动。原生奖励屏障关闭前不得插入事件。

## 反例与交付边界

若只持城邦印章却未完成016、改走020奥古斯丁、已完成017、第三幕 Fixed 已使用、来源是Boss或奖励未结束，都不能邀请。两张告示的矛盾不证明任何人的信仰或人格；仅查公布不能推出制定权，现场断板也不能批准永久任意例外。还须以原生检查证明战斗收益真在生产遗物回调发生，而不是只在纯逻辑模型中算出。玩家渲染界面与整局体验仍需异步反馈。
