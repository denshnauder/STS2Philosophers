# 亚当斯密当前设计（ENC-139）

## 承接位置

- 主用途：固定。路线「同感与公共行动」：柏拉图／制度开局 → 第一幕亚当斯密 → 第二幕密尔 → 第三幕阿伦特。
- 图：新增节点 `ADAM_SMITH__FREEDOM_AND_INSTITUTIONS__CORE`、`HANNAH_ARENDT__FREEDOM_AND_INSTITUTIONS__CORE`；新增边 054（柏拉图制度→斯密，第一幕固定）、055（斯密→密尔，第二幕固定）、056（密尔→阿伦特，第三幕固定）。
- 与「制衡与公正」共用柏拉图制度开局；两行是跨周目替代分支，一局只取一条第一幕固定承接。

## 分支选择

`WesternFirstActBranch` 在同一节点有多条可承接的第一幕固定边时，按运行种子稳定选择其中一条；同一存档重载结果不变。孟德斯鸠与斯密两个房间都用它决定本局是否轮到自己。这是对路线文档「不同行是跨周目替代方案，不在一局叠加」的实现。

## 玩家流程

第一幕在柏拉图制度节点完成至少一场普通战斗后，若本局抽中斯密分支，地图边界插入本事件：

集市上陌生人破产，围观者有的同情、有的只重新算价。三个选择：

1. **以同感为秩序基础**：采纳第一幕固定边，进入斯密节点。
2. **只按交换与自利**：同样采纳固定边，记录交换标准。
3. **保留柏拉图式安排**：放弃本幕固定承接，停留在柏拉图制度节点。

结算页各有一句后果说明，随后「离开集市」关闭事件。

## 状态与保存

- `SmithSympathyState`：阶段、待确认动作、已确认动作、标准（同感／交换／保留）、是否采纳边、是否放弃固定幕、是否关闭；严格版本与重放校验。
- 随 `PhilosophyRunState.SmithSympathy` 保存；旧档没有该属性时为 null，不补发。
