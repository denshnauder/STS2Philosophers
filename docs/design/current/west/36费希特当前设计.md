# 费希特当前设计

## 定位

- 第 37 位西哲人物，ENC-142，主要用途内批，次要固定／转线，位于“自律与历史”路线（AUTONOMY_AND_HISTORY）。
- 标题《谁设定了这条规则？》：把康德的平等规则从“被交下来的形式”改写为行动者自我设定、同时接受非我检查的规则。
- 默认主线：第一幕笛卡尔 → 第二幕康德〔主体／自律〕（`KantApperception`，边 095）→ 第二幕实际问号遇费希特内批 → 第三幕黑格尔〔历史〕。
- 旧第三幕路线（022 进入康德自由节点，再以 037 修订）保留给旧档与旧版本，不作为新默认主线的必经条件。

## 研究边界

- 只写已核实论点：自我设定自身、非我的检查、自我立法与任意的区别；不把费希特写成“只要我想就是规则”，也不把“检查”写成道德分数。
- 不读 NPC 内心；不新增金币、生命或补给成本；不新增节点实践。
- 费希特对康德是内部推进，不是简单取代；保留康德是合法选择。

## 玩家情境

城门账本写着康德的平等规则，但必须遵守它的办事员从未参与制定。夜班提出：规则只是被交下来的，还是由行动者自己设定的？玩家选择：

1. **改写为自我设定**：完成本幕内批，保留康德节点与实践，记录规则须由行动者重新制定。
2. **要求公开检查**：完成本幕内批，保留康德节点与实践，把自我制定与承受后果者的检查绑定。
3. **保留康德形式规则**：谢绝内批，用掉本幕问号。

两种改写都不切换节点、不授予新实践、不应用 037 的图边；不提供“既改写又不留下记录”的免费选项。

## 幕数与路线限制

- 默认主线在第二幕固定康德主体／自律之后，事件只在**实际地图问号被原生抽为 Event** 时出现；不额外生成节点，不在战后或普通行进途中补弹。
- 触发要求：第二幕、`LastFixedAct >= 2`、当前节点为 `IMMANUEL_KANT__SELF_AND_OTHER__CORE`、康德主体房已采纳其固定边（095 或同幕到达边）、本幕问号未用。
- 事件实例 `FICHTE_SELF_POSITING:{seed}:2`；旧第三幕实例仍为 `:{seed}:3`，按旧身份恢复，不套用新幕次。
- 提前转线（第一幕问号康德）走第二幕黑格尔，不触发本内批；谢绝康德固定房也不触发。
- 038（黑格尔历史）在默认主线由第三幕固定承接，不以费希特出现为前置；旧 022／038 路径只服务旧档。
- 坏档或未知状态冻结，不重造。

## 保存与测试

- 原生事件房间 prepare／save／commit／save 屏障；待确认动作先持久化，提交后再持久化。
- 纯逻辑检查覆盖：第二幕康德前置、两种改写均消耗本幕问号但保留康德、谢绝只消耗本幕问号、旧第三幕 022 路径、坏档重放拒绝、触发幕数与问号资格。
- 原生边界检查覆盖注册、锁定入口、陈旧回调与待恢复冻结；不渲染 UI、不跑真实存档。
- 版本保持 0.5.24；未部署、未实机验收。
