# 第欧根尼当前设计

## 三分钟摘要

- **当前结论：** 第欧根尼是德性路线第三幕互斥终点的第一部分，处理真实上游事实、公开说法与自足实践；不是柏拉图的直接后继或芝诺钥匙。
- **玩家流程：** 玩家回看已经发生的行动与公开历史，随后选择 Stay 完成第欧根尼结局，或明确放弃该完整回应并经犬儒传统与克拉特斯的中介转向芝诺。
- **核心取舍：** Stay 立即闭合当前实践并失去本局芝诺；Switch 保留战斗能力但放弃第欧根尼完整结局，把唯一后续终点交给稍后出现的芝诺。
- **界面与素材成本：** 标准事件、原生按钮与既有保存槽；不新增地图节点、桶屋、群众、行走或挑衅动画。
- **已完成：** 正式入口、事实适配、去留事件、保存恢复、与芝诺的延迟调度、验证、构建和部署均已完成。
- **未完成：** 更广的第二幕披露、主动撤离和额外公开关系玩法不属于当前交付。
- **准确下一步：** 第欧根尼人物任务从本入口和真实已保存事实继续，不从旧纸面公开说明候选恢复生产。
