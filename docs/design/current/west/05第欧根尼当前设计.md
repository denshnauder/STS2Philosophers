# 第欧根尼当前设计

## 三分钟摘要

- **当前结论：** 第欧根尼是德性路线第三幕互斥终点的第一部分，处理真实上游事实、公开说法与自足实践；不是柏拉图的直接后继或芝诺钥匙。
- **玩家流程：** 玩家回看已经发生的行动与公开历史，随后选择 Stay 完成第欧根尼结局，或明确放弃该完整回应并经犬儒传统与克拉特斯的中介转向芝诺。
- **核心取舍：** Stay 立即闭合当前实践并失去本局芝诺；Switch 保留战斗能力但放弃第欧根尼完整结局，把唯一后续终点交给稍后出现的芝诺。
- **界面与素材成本：** 标准事件、原生按钮与既有保存槽；不新增地图节点、桶屋、群众、行走或挑衅动画。
- **已完成：** 正式入口、事实适配、去留事件、保存恢复、与芝诺的延迟调度、验证、构建和部署均已完成。
- **未完成：** ENC-114 的开局取舍回看已实现、待随人物批次部署；更广的第二幕披露、主动撤离和额外公开关系玩法不属于本次交付。
- **准确下一步：** 第欧根尼人物任务从本入口和真实已保存事实继续，不从旧纸面公开说明候选恢复生产。

支撑材料：[人物设计证据](../../DiogenesVirtueDesign.md)、[自足与操练研究](../../DiogenesSelfSufficiencyResearch.md)及第欧根尼专题审查文件。

愿意试玩时可直接使用[芝诺入口中的一次试玩脚本](06芝诺当前设计.md)，同一份覆盖去留、保存加载、芝诺出现与反馈；不要求现在试玩，也不作为开发交付闸门。

## ENC-114 实践回看的交付边界

现有第三幕去留已经给玩家一个真实且不可兼得的路线后果，但它不记录玩家是否在战斗中尝试过一种可修订的自足方式。`NoMaterial` 是诚实的安全降级，不能把它称为已发生的舍弃、直言或操练；原有去留交付也不能单独充当本次「实践」人物验收。

本次可用的具体材料是德性入口的「审思砝码」：每场战斗首回合，玩家确实可选择一张攻击／技能牌留在手中，等待后减费。原生选牌本来允许选零张；提示明确玩家也可不选、用原有手牌应对。这个替代不是新赠的能力，而是放弃本场可能取得的保留及折扣。玩家在下一场可以重新选择帮助，所以用不用工具都不是德性分数；不能把为了更好牌序而不选的战术动机读成自足。

首、二幕每次有合格牌且成功完成选牌时，仅记录本局幕号、房间及零／一张选择；至少两次选择零张是重复的可核对行动，不是对原因的认证。第欧根尼在第三幕既有去留事件提供只读回看：重复放下、仅一次、都借助或无可用记录分别写明；之后玩家仍可 Stay／Switch。只有回看当下才由玩家解释行为，不能倒称此前玩家已公开宣言。停留仍失去本局芝诺，转向仍放弃第欧根尼完整终点；不因少选牌发额外奖励或惩罚。这里没有有社会风险的公开直言；那一候选仍未生产。

实现复用现有遗物选择和第三幕事件，不占用新的地图节点、问号或后继时点。没有合格牌、选择失败、旧档没有记录、尚未进行两次取舍时都诚实降级；仍可正常完成去留。进入第欧根尼时冻结本局已记录的摘要，防止页面与存档读回互相改写。旧档不从当前手牌、库存或遗物状态补造既往事实；损坏记录阻断写入，而不是清空后宣称没有行动。测试需要覆盖两次真实机会、混合选择、重复回调、旧档和双语页面。
