# 东哲当前路线

## 三分钟摘要

- **当前结论：** 六条既有两幕路线全部保留，第三幕可以继续发展，也可以在第二幕形成合法终点。
- **玩家流程：** 开局诸子观照在先古之民之后直接出现，选择孔子、墨子或老子的观点遗物；第二幕持真实路线遗物时，进入实际地图问号且原生抽为 Event 才有资格遇到对应后继诸子观照。木铎到绳墨路线还可在第三幕满足至少一战及遗物条件后，于另一实际问号 Event 遇到韩非；满足路线不保证出现。
- **核心取舍：** 后继改变的是玩家承担规则和关系的方式，不是简单获得更强版本；没有合法关系时静默回到正常地图。
- **界面与素材成本：** 使用标准事件、现有诸子观照素材与既有遗物；不为未设计路线预建人物场景。
- **已完成：** 第一幕六件根遗物、第二幕六位后继与十二件遗物，以及木铎→绳墨→韩非第三幕事件已有历史部署；ENC-199 的后继问号入口已通过原生选择与保存恢复检查，部署证据以既有 DEVELOPMENT 与 Linear 为准，未经本次实机验证。
- **未完成：** 其余五线第三幕没有获准的完整交付，不因此视为路线残缺。
- **准确下一步：** 只在 Linear 出现对应 `Todo` 后设计下一条完整第三幕循环。

详细路线、韩非事件、恢复与研究边界见 [东哲路线总览](../../00东哲路线总览.md)。玩家当前能玩到的内容见仓库根目录 `README.md`。
