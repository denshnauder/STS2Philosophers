# 当前设计索引

## 三分钟摘要

- **当前结论：** 当前设计按“共用边界、东哲路线、西哲路线、人物入口”组织；一个人物只在本目录拥有一个当前入口。
- **玩家流程：** 开局九人池展示三位思想家；东哲进入两件路线遗物，西哲进入七种问题实践。合法后继只由当前实际路线事实触发。
- **核心取舍：** 不用奖励强弱代替思想差异，不为填满幕数伪造师承，不把玩家试玩当开发完成闸门。
- **界面与素材成本：** 优先复用原生战斗、卡牌、遗物、奖励与标准事件；新增场景、动画或大量静态素材必须单独证明必要性。
- **已完成：** README 所列入口实践与人物事件均已完成相关自动验证、构建和安全部署；试玩问题走独立反馈 Issue。
- **未完成：** 89人并不等于89个已实现节点；未获得合法载体和 Linear 任务的人物继续保持研究或候选状态。
- **准确下一步：** 任务顺序只看 Linear；本索引只负责把已授权 Issue 路由到正确设计入口。
