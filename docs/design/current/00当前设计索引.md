# 当前设计索引

## 三分钟摘要

- **当前结论：** 当前设计按“共用边界、东哲路线、西哲路线、人物入口”组织；一个人物只在本目录拥有一个当前入口。
- **玩家流程：** 开局九人池展示三位思想家；东哲进入两件路线遗物，西哲进入七种问题实践。合法后继只由当前实际路线事实触发。
- **核心取舍：** 不用奖励强弱代替思想差异，不为填满幕数伪造师承，不把玩家试玩当开发完成闸门。
- **界面与素材成本：** 优先复用原生战斗、卡牌、遗物、奖励与标准事件；新增场景、动画或大量静态素材必须单独证明必要性。
- **已完成：** 七种入口实践及既有人物内容有实现、构建和安全部署记录；0.5.4 已修复九个既有事件的普通战后返图与保存恢复。0.5.5 新增阿那克西曼德第二幕问号，0.5.6 加入阿那克西美尼第三幕凝散实践，0.5.7 加入恩培多克勒第二幕并行比较问号，均完成相称检查及 Mac 安全部署。
- **未完成：** 本次未进行渲染界面或整局实机回放；89人其余用途及研究定义不代表人物交付完成，马基雅维利草稿未纳入部署。研究人物按原定研究成果验收，泰勒斯旧验收冲突已由用户解除；详见人物用途基线。
- **准确下一步：** Linear 决定授权和真实依赖，人物按 `config/western_research.json` 的 `people` 数组推进；必要公共阻断 Bug 和现有工作的安全收尾按仓库规则处理，不按优先级跳人物。

## 事实分层

| 内容 | 唯一入口 |
| --- | --- |
| 任务授权、真实依赖、优先级和状态 | Linear |
| 西哲人物既定顺序与用途快照 | `config/western_research.json` 的 `people` 数组 |
| 玩家当前能玩到的内容 | `README.md` |

本目录是普通 Git 文档目录，不依赖 Obsidian、Vault 或同步插件。Google Drive 保存研究资料、附件与必要历史存档；当前设计不写回 Drive 或旧本地 Vault。Linear 的 Todo 即授权，不增加 AutoRun 标签门槛；人物领取仍须满足既定顺序与真实依赖。研究、文档、构建或部署记录均不能单独证明人物完成，详见 [西哲人物用途基线](shared/01西哲人物用途基线.md)与仓库根目录 `AGENTS.md`。
