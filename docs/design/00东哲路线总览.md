# 东哲路线总览

## 三分钟摘要

- **当前结论：** 六条既有两幕路线都保留。第三幕允许继续发展，也允许在第二幕形成合法终点；不为凑齐人物伪造师承。
- **本期玩家流程：** 持有绳墨的玩家在第三幕完成首场战斗后遇到韩非。玩家可以坚持荀子的礼义教化，处理一场需要因情境判断的职责争议；也可以先公开一条名实标准，再看具体个案并决定是否承担一致执行的代价。
- **核心取舍：** 荀子路线保留师法、积习与情境判断，但秩序依赖判断者和长期教化；韩非路线取得不依赖个人德性的公开标准，却必须接受标准会压平救急情境、削弱信任的代价。两者都不是道德评分。
- **界面与素材成本：** 一个原生标准事件、现有诸子观照背景、文字选项和既有保存槽；不新增地图节点、人物立绘、动画或遗物图。
- **已完成：** 第一幕六件根遗物、第二幕六位后继与十二件遗物；统一后续幕遗物门控已经上线。
- **本期目标：** 交付木铎 → 绳墨 → 韩非的完整第三幕事件，保存拒绝、坚持、转向和关闭状态，避免重复进入或重复结算。
- **准确下一步：** 本期完成后，按独立可玩路线批次选择其余五线之一，不建立空人物票。

## 韩非：法前之衡

### 出现时点与资格

- 单人局第三幕，玩家当时仍持有 `XUNZI_SHENG_MO`，并已完成本幕至少一场战斗。
- 资格由统一的 `LaterActRelicEligibilityCatalog` 注册和运行时遗物查询决定；没有绳墨就不进入候选。
- 本局已经创建过该事件时只恢复尚未关闭的实例；结果关闭后不再出现。第三幕没有合法候选时静默跳过。

### 玩家流程

1. 韩非提出一场职责争议：在运送时限前，需要决定秩序究竟依赖受教者的判断，还是依赖预先公开、无须信任个人品德的标准。
2. **坚持荀子：** 玩家先看到两名执行者的完整情境，再选择“把救急纳入职责解释”或“仍守住原职责边界”。两种选择都承认判断者必须为解释负责，也都保留绳墨与荀子终点。
3. **接受韩非的制度试验：** 玩家在不知道执行者身份与遭遇前，先公开“按承诺数量核名实”或“按最终公共存量核结果”。
4. 规则公开后才揭示反例：有人偏离承诺去救援，有人按数完成却拒绝救急；或有人保住公共存量却以强制征用转嫁代价，有人分出存量救急而未达标。
5. 玩家可以执行已公开标准并转向韩非，也可以在看见个案后撤回规则、承担公信受损并回到荀子的情境判断。系统保存先前已经公开过什么，不把撤回写成没有发生。

### 收益、代价与后继变化

- 本事件不发遗物、金币、治疗或隐藏数值奖励，也不改绳墨数值。
- 坚持荀子保留现有战斗实践和后续荀学身份，代价是放弃本局韩非路线，并明确承认秩序依赖教化与具体判断。
- 转向韩非保存所选公开标准与执行结果，关闭荀子第三幕终点；代价是在已知反例中仍接受规则对情境的压平和信任损耗。
- 公开后撤回保存“曾立法后撤回”的历史，回到荀子终点；它不是免费返回，也不伪造已经立过的规则不存在。

### 失败、恢复与反例

- 每次不可逆选择先写 `PendingAction` 并保存，再提交结果并再次保存；退出或读档时只重放同一个待提交动作。
- `Closed` 只在结果页离开时写入。重复点击、重复回调和已关闭实例不再改变路线。
- 若事件模型不可用、状态损坏、多人局、幕位不符或当前遗物已失去，生产入口不创建新实例。
- 反例边界：韩非不是“更强绳墨”；荀子不是“法家前置”；一致执行不等于现代法治；救急者与守额者都不被系统判成善人或坏人；路线结果不能由之后战斗胜负倒推为思想正确。

## 研究边界

- [SEP：Xunzi](https://plato.stanford.edu/entries/xunzi/) 将礼义、师法、外在规范与自我修养作为荀学核心，也提醒后世常用韩非、李斯受业叙事把荀子简单归入法家是误读。
- [SEP：Legalism in Chinese Philosophy](https://plato.stanford.edu/entries/chinese-legalism/) 区分法、术、势及韩非对统治者与官僚风险的悲观看法；这里的“法”不是现代限制统治权的法治。
- [Chinese Text Project：《荀子·礼论》](https://ctext.org/xunzi/li-lun/ens) 与[《韩非子》](https://ctext.org/hanfeizi)只作原典入口；事件对白均为游戏创作，不冒充人物原话。
