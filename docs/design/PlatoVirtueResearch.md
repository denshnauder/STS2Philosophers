# 柏拉图灵魂秩序

## D105证据范围
服务既定德性后继用途（第二幕Fixed/Adopt），不更改柏拉图自由/制度入口或现有关系。依据[柏拉图《理想国》Jowett英译正文](https://www.gutenberg.org/files/1497/1497-h/1497-h.htm)，网页前部译者导言与正文分开；以下不采导言裁决。它是对话论证，不是历史苏格拉底的逐字录音。

## 原典定位
- 419a–421c：诉诸整座城邦幸福，不只求一群体最满足。
- 441e–442d：理性照顾各部分及整体，意气作盟友，欲望受安排。
- 443c–444e：正义指内在秩序；健康/疾病是灵魂类比。
- 518b–d：教育转向已有学习能力，不似给盲眼装视力。
- 518e–519a：敏锐能力也能服务坏目标，能干不直接证明善。

## 转译边界与反例
以上支持一个研究问题：“安排有条理，是否足以判断它服务整体？”这是游戏推论，不能让胜利、最大伤害、血量或程序规则定义灵魂健康。
理性、意气、欲望不是攻击/技能/能力三种牌，也不是三个轮换增益；同一游戏行动可服务不同目的，行为分类不能替玩家作内心诊断。
内在秩序不等于从不修订事前计划；死守已不合用的安排不自动获得理性标签。对整体的照料须有具体内容，不能以“遵守任意规则”代替。
课程限制奖励只是可能载体，不等于真实教育/知识善或完整幸福。高效专注也可能只是扩大一个局部偏好；不为课程命名“理性/贪欲”后按胜负发品德分。
城邦/灵魂类比有规范与权力问题，不能自动给等级统治背书。本次当前德性用途不包办柏拉图全部作品或自由/制度入口。
