# 柏拉图卡牌载体比较

D116｜设计候选，未批准主能力、未实现、未进游戏验收。先看正式呈现与生产风险，再看取舍和思想。守灯原型保持冻结。

## 共同出现边界

沿用既定第二幕Fixed/Adopt窗口与EDGE009前置；该窗口当前仍是规划中的载体，不宣称新选牌界面已接入。接受只保留一个当前主说，拒绝保留原说。不开新地图房间、不新增敌人、设施或旅人。复用已有事件文字、原生牌面与战斗手牌；最多一枚静态遗物图标是本阶段的成本目标，不是用户批准的预算或已有资产。

仓库存在plato_civic_seal.svg，但它属于当前生产根遗物，不能直接覆盖或冒充新候选美术。现有代码中未找到可直接复用的自定义选牌封装；原生Survivor使用手牌弃牌选择，只说明上游有该交互，不能证明牌组选择、主动按钮与存档恢复已解决。

## A：开局出场安排

候选命名：开篇安排 / PlatoOpeningOrder / PLATO_OPENING_ORDER；拟本地化键PLATO_OPENING_ORDER.title、.description；拟资源plato_opening_order。均未注册，公开ModelId不变。

- **操作/界面**：接受时选择两张拥有的牌，在每场正常开局抽牌的两个位置安排它们；手牌总数不增加，正常支付费用。再次安排必须先给出真实且不可套利的代价，不能把未设计的“付代价改序”当成完整规则。
- **素材**：原生牌面、事件页与选择界面；不需新角色/背景/目标动画。选择、位置提示及牌实例持续绑定仍需开发验证。
- **具体作用**：同为1费的StrikeSilent与DefendSilent，当前原生基值分别伤害6、格挡5。先拿到前者便于收尾，后者便于应对攻击；稳定抽到某牌可能减少其他牌的出现机会，但不自动产生本场付费或永久损失。
- **反例**：每场都想先拿到最强组合时，候选只是降低抽牌波动；如果选择最弱牌就能移出后续抽牌，实际还可能是变相压缩牌组。不能用“秩序”一词把普通启动器判成柏拉图教育。
- **判断**：呈现目标较省素材，但目前只有牌序优化，目的如何统领能力与教育转向没有成立；不批准、不写框架。

## B：封存范本并替换一种用途

候选命名：拟范练习 / PlatoExemplarPractice / PLATO_EXEMPLAR_PRACTICE；拟键PLATO_EXEMPLAR_PRACTICE.title、.description；拟资源plato_exemplar_practice。未注册。

- **操作/界面**：接受时选择一张自有牌作为范本并封存原实例；每战至多一次，选当前手牌的一张牌替换为范本基础副本。本场只替换一个位置，不多抽牌、不多给能量；原手牌永久实例不删除，范本不能同时普通抽到。离开主说时须归还原封存实例。
- **素材**：复用原生牌面、选牌窗口；无额外房间/角色/目标。战斗中主动入口、封存状态提示与替换可读性尚未落实，不能写成已有UI。低美术目标不代表低实现成本。
- **范围**：先只讨论未升级、无附魔的原生牌，不能在设计里默认复制升级/附魔/存档身份。真正封存、存档读回、撤销和转向归还风险很高，现有苏格拉底有限诊断不证明安全。
- **真实不同用途例**：将StrikeSilent替换成Survivor，正常费用同为1，攻击6的机会变为格挡8，并在有其他手牌时必须再弃一张。损失的不只是伤害数值，还包括另一张手牌的使用机会；若手牌没有其他牌，该代价为零，须如实显示。反向替换会失去防护与弃牌功能，不能说是同一个升级。
- **其他反例**：封存原本不想抽到的弱牌就可长期压缩牌组；将某强牌重复拟范可能成为通用复制器。玩家选择的样本不等于柏拉图的理念或善，不能把牌相似性当成原典含义，也不能以“范本”命名掩盖思想缺口。
- **判断**：动作比只改格挡数值更有具体机会成本，但当前仍是复制/转用途策略，加上高风险实例恢复；不批准、不铺封存系统。

## 当前判决与下一步

两候选均未通过完整设计审查，不能因为素材少就替代守灯进入生产。已有课程奖励过滤与跨战预支也不恢复为新批准候选。

下一阶段先用现有真实卡的不同用途检验“选定目的后，是否会在新处境改变手段”这一游戏问题；必须提供不依赖封存/复制的新决策循环，以及其区别于通用战术优化的反例。如果做不到，登记思想转译缺口并换问题面；不先建共享主动能力系统或生成图标。历史意义只在已有研究依据内讨论，不把上述假设新增为柏拉图原话。

数值依据为2026年9月15日本机sts2.dll原生起手牌核对，见仓库native_starting_facts.json与已保存源码；本文只引用牌自身基值，不模拟整局、完整手牌或敌人行为。Survivor弃牌条件来自OnPlay的实际手牌选择调用。未重复构建，生产体验与README不变。
