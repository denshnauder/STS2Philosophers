# 苏格拉底当前人物设计

G盘59为维护真源，本页为可恢复摘要。

## D96当前人物方案

### 已定与候选

用户已定七问题、六入口、89人用途、苏格拉底双分支与单局一种主说；本文收束的是当前人物设计候选。首轮邀请/二选一防双领已有生产入口，新试授与撤离仍只在纸面可操作。旧诘问杯/审思砝码未迁移，不把33/32项检查、字段或笔记数量当完整路线。

苏格拉底共同方法：让玩家真正提出说法，检查它所声称的对象与理由，在不够时能改写、撤回或保留问题。知识面是选牌承诺的根据，德性面是危险行动的目的与自评；进入路线不承诺一套知识/勇敢定义，未答不等于承认无知。

### 两种完整循环

| 维度 | 知识：试授与反问 | 德性：坚持与撤离 |
| --- | --- | --- |
| 首先遇到的问题 | 想收一张牌，却只有有限用途材料；材料支持的是当前对象还是更广承诺？ | 已进入危险，继续的原理由是否还值得；行动、目的和勇敢判断是否同一回事？ |
| 独特动作 | 三选一奖励锁一份副本，一幕一次试授；下一正常流程战斗后可收入/放弃 | 普通地图战斗稳定玩家回合开始、首次实质手动动作前，一幕一次确认撤离 |
| 收益 | 看过实际用途后多一次反悔权 | 有代价地停止当前危险、保住继续旅程的可能 |
| 代价 | 本幕机会、试授构筑变化；放弃丢本份奖励，不能换另外两张/退机会 | 本幕机会及整场胜利奖励；既有生命损耗/持久消耗不退，已获持久变化不回滚 |
| 真实材料 | 未抽/抽到未用/实际使用分开；准确命中前后目标生命、给出的格挡与整回合总抵消分开 | 实际窗口资格、动作、当时目的、旧标准与本次自评分开；资格不等于内心考虑 |
| 表达机会 | 原句可空，回应可跳过；新句不由程序认证为限定。收入/放弃不表示接受/撤回句子 | 标准/目的/自评可不提；同范围必要条件和撤离勇敢同时明确认可才共同指出关系问题 |
| 失败及恢复 | 死亡无回看/补偿；准确副本身份不明停止自动删补，不按模板代替；只允许一张待定 | 死亡/精英/Boss/事件战斗不能撤离；过期请求不消费；节点一次处理、合法后继、非胜利结束 |
| 核心反例 | 9生命目标连击后剩1，后来基础攻击获胜不变成连击独自击倒；新对象不自动反驳旧局部句 | 保留“不退必要”却优先别的目的不自动逻辑矛盾；无退出资格下继续不称主动拒绝退出 |

这些都是游戏设计，不是历史苏格拉底发明的规则。知识是对承诺根据继续发问，不能以成功/解释长度判知识；德性必要条件是《拉凯斯》取材后的更强游戏命题，取消“不退”必要不能推出所有形式无关。原典区别与推理修订见63/66。

### 长期停留究竟承担什么

第二幕不换人，保留当前方法与同样的一幕机会，不自动升级数值/叠旧收益。知识继续在不同构筑需求与实际场景中承担有限承诺；德性继续在不同危险/奖励和具体目的中承担退出取舍。生命、牌组与已经付出的机会造成新的处境，变化不靠重复填同一题。第三幕可选择以同一方法结束发展：关闭后续主说转向，但不禁止玩家继续修订句子、实际使用本幕能力或承认问题开放。

“本幕保留”和“最终停留”不同：前者不必拒绝本幕尚未用的合法问号，后者关闭未来发展。最终停留不奖励答对/困惑，不抹旧事实或消除能力代价。是否值得长期停留仍要实际体验；同一能力重复三幕不自行证明这一点。不存在必须答出最终知识/幸福定义才准结束的条件。

配置中的required_edge_ids仍是现有游戏流程资格，不是因果/思想史证明。本次不修改图；尚未形成完整新实践的后继不开放接受。可自愿保留当前人物；没有完成问号不能据此说历史关系消失，也不为填位伪造边。

能力切换只在旧事务完整处理后发生。知识待定副本未处理时，不能一面带走试授反悔权、一面领取新主要实践；实际恢复与幕位需在接入前明确证明，不靠补开额外槽凑流程。德性确认/退出未完成不切主说。历史说法留下作为说法，不变成第二套生效能力；修订句子不会暗中换问题。

### 设计判决及继续条件

当前人物的核心问题、独特动作、实际成本、反例、失败恢复和后继边界已在上述候选中明确，可以进行下一人物的独立研究与具体设计。它不代表苏格拉底已发布、可玩性已通过或全部西哲路线完成。新的主要能力生产实现仍需真实身份/非胜利退出安全证据；纸面体验独立待验证，新反馈优先修改本方案。

下一有意义阶段优先为既定普罗泰戈拉问号做完整具体情境：只解决“自己的理由能否成为共同教育”的问题，不把他当待击败反派，不先写战斗礼包或继承资格代码。必须先核对《普罗泰戈拉》及既有研究，区分戏剧角色、历史材料与游戏创作；设计一个真正有代价的公共实践取舍，再做相称原型。

其他独立等待：socratescardprobe实际样本、最终保存/读档/变形、自有非胜利事务、ISSUE005人工验收、ISSUE010 TLS恢复。未变时不重复审计构建/推送。后续用户暂停/取消/范围调整优先；有额度与可执行研究设计继续。
