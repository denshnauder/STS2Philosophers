# 西哲设计与呈现审查

D116｜按2026年9月17日用户“按照新标准调整工作”执行。维护真源为G盘，本页是后续逐人物设计的入口，不是发布清单。

每个候选先回答以下具体问题，再决定是否值得做原型：
1. **出现与操作**：在哪一幕、哪个既有节点或战斗时点出现？玩家实际点击、选择或放弃什么？是否占用额外房间、战斗或奖励？
2. **呈现与制作**：复用哪一个事件页、选牌窗口、战斗界面？新增角色、背景、目标、图标与动画各是多少？已有文件、需要验证的能力、尚缺素材分别写明。零新场景不能自动推断零交互开发。
3. **人物与取舍**：一个具体问题面；一个有意义的玩家动作；利益、真实机会成本、失败与恢复、后继变化。至少给两个同权限但不同处境的例子，指出代价可能为零或策略支配的反例。
4. **转译与差异**：原始资料、争议和游戏改写分开；去掉人物名字，动作是否仍能区分本人物与普通遗物或其他路线？若只剩抽牌、格挡、加数值，重新选择动作，不靠改文案通过。
5. **继续条件**：分别判断思想、玩法、正式呈现与实现风险。纸面自动通过、部署、推送、游戏验收分别记录；任一项未成立时不写“完整可玩”。

执行顺序为：具体呈现与成本 → 完整决策循环 → 反例与人物差异 → 相称的最小原型 → 必要自动检查 → 正式安全验证与人工体验。每个有意义步骤先更新活动问题、接续与人物页，阶段末同步日志、仓库与S盘阅读副本；内容未变不复制。研究与小型反例可以独立继续，不为待验证样本反复构建。

柏拉图守灯冻结为设计实验，保留既有原型与归属，不扩正式场景、不接生产。七问题、六入口、89人用途及苏格拉底双分支是既定规划；美术约束不能用来改变这些规划，也不能用来复活已否决设计。
