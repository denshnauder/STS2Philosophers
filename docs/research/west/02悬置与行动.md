# 塞克斯都的悬置与行动

> 迁移来源：Google Drive 只读研究归档（2026年10月16日核对）。本页保存研究与解释边界，不授权任务，也不代表玩法已经实现。当前人物设计见 [唯一入口](../../design/current/west/07塞克斯都当前设计.md)。

## 原始材料与版本

读取Mary Mills Patrick书内后半部分的《皮浪学说概要》第一卷英译，定位PYRRHONIC SKETCHES / SEXTUS EMPIRICUS / BOOK I。来源：[Project Gutenberg原书](https://www.gutenberg.org/cache/epub/17556/pg17556-images.html)。前半部是Patrick的研究与评价，不能把她对怀疑主义消极性的评判写成塞克斯都自述。此次只作定向摘读，不解决古代怀疑研究的全部解释争议。

## 摘读依据

- I.1至4：继续探究不同于宣布真理已找到或不可能找到；作者还限制自身陈述的断言强度。
- I.8至10：对置的关键是理由在可信性上不相胜，不是把两种收益数值设为相等；悬置不同于认定两方都错。
- I.19至24：承认当下显现和按生活所需行动，不等于裁定事物本性；行动判准与判定真假的判准需要区分。
- I.25至30：不扰与对不可避免感受的适度承受相联系，不能直接译为免伤、永远无痛或按按钮必得奖励。

以上均为短摘要，不是游戏对白或逐字引文。I.1至3对学院派的分类先视为塞克斯都本人的论战性表述，不据此断言所有学院派都教条地否认知识。对日常信念的容许范围仍有解释争议，本阶段不代作定论。

## 2026年10月11日研究边界复核（ENC-83）

**本轮核心冲突：当同一命题的两边理由都依赖尚未独立确认的判准，而行动又不能无限等待时，玩家是否必须先宣布一边已经为真；还是可以暂缓同意，同时明确依眼前显现、既有技艺或当前习俗继续一项有限行动？** 悬置发生在对主张的同意层，不等于停止移动、空过回合或拒绝一切日常做法。

### 历史事实、解释争议与游戏创作

- **史料事实：** 本页依据的是塞克斯都保存的后期皮浪主义文本，不是皮浪本人逐字发言。皮浪本人没有留下可直接据此复原的著作；游戏称“塞克斯都／皮浪主义传统”时必须保持这一层差别。
- **史料事实：** 塞克斯都区分继续探究、教条断言与悬置，并说明怀疑者仍依显现、生活需要、习俗规则与技艺行动。这里的“不加断言”针对事物本性等教条裁定，不支持把人物写成没有感受、语言、习惯或任何实践判断。
- **解释争议：** 怀疑者可保留何种普通信念、“依现象生活”是否完全无信念，以及不扰与悬置的关系，仍有解释分歧。游戏只能公开采用窄边界，不能用一个按钮裁定争议。
- **历史关系：** 古代悬置不是笛卡尔方法怀疑的早期版本。项目若以后连接笛卡尔，必须显示塞克斯都文本再发现、蒙田与宗教争论等中介，并说明笛卡尔把怀疑用于寻找可重建的确定基础，目标不同。
- **游戏创作：** 色片、照明、门槽、地图路线、具体食物及所有选项和资源后果均是项目处境，不是古代事件或原文规则；蜜等感受差异只提供改写依据，不直接搬作历史剧情。

### 相邻动作不能混同

| 动作 | 本轮边界 | 不能偷换成 |
| --- | --- | --- |
| 悬置 | 对当前争论命题暂不表示肯定或否定，理由比较继续开放；仍可行动 | 两边都错、永远不可知、什么都不说 |
| 撤回 | 玩家先前明确提交过主张，现在因反例或边界收回；有真实前史 | 从未同意时的悬置、换一个按钮后的重置 |
| 承认无知 | 承认自己目前没有足够知识；未必已经形成两边理由的对置 | 自动接受皮浪主义、领取谦逊奖励 |
| 犹豫／拖延 | 行动决定尚未作出，可能只是信息不足、害怕损失或操作等待 | 悬置本身；悬置可以迅速行动，果断行动也不等于已断言 |
| 笛卡尔方法怀疑 | 为检验并重建知识基础而有计划地撤下可疑依据，目标指向不同 | 持续悬置的自然下一等级或同一主说换名 |
| 依显现／习俗／技艺行动 | 在不裁定终极本性的前提下，按当前所见、生活需要、通行规则或已学实践采取有限行动 | 宣布习俗永远正确、行动结果证明理论为真、人物没有任何主张 |
| 不扰 | 在文本中作为与悬置相关但仍有解释争议的生活效果；不可避免的感受并未消失 | 免伤、无痛、平静条、点击悬置后的必得奖励 |

“少出牌／拖延一回合→领奖”、固定第三回合礼包与同额主动延期继续属于历史否决方案；它们只制造时点与资源交换，没有让玩家面对同一命题的理由对置，不得恢复为候选。

## 与既定规划的关系

18/19已要求苏格拉底知识问号到塞克斯都为后世征用与同题转向，非直传；之后笛卡尔需公开文本复兴、蒙田和宗教争论中介，且目的不同。这次摘读只核对悬置/行动边界，不证明那条近代传播链，也不提高图中LocalPlanning证据等级。

## 本项目设计推论

以下为设计判断，不是原文的游戏规则：淘汰把固定第三回合礼包或同额主动延期直接命名为塞克斯都主机制。晚作资源选择本身没有呈现对某项断言的对置；更不能从苏格拉底C3的有限实践擅自推断玩家已经相信普遍真理。后继挑战必须另外提出可争论的主张，并允许玩家既继续行动又不予裁断。

## 2026年10月12日近代方法转向桥（ENC-87）

### 可安全陈述的传播背景

- 古代皮浪主义文本在拉丁中世纪并非完全消失，但塞克斯都著作没有形成广泛、直接的哲学影响；近代不能写成塞克斯都本人把一套方法一路传给笛卡尔。
- 1562年亨利·埃蒂安出版《皮浪主义纲要》首个印刷出版的拉丁译本；1569年重刊时又收入让蒂安·埃尔韦所译《反学者》。此前已有拉丁译稿与手稿，不能把“首印”写成“首次翻译”；这类印刷、翻译与评注使塞克斯都在十六世纪欧洲重新成为更易取得的文本。日期与出版事实可以写入研究附注，不要求把译者做成游戏人物。
- 蒙田《雷蒙·塞邦赞》中确实大量使用塞克斯都式材料，但他也结合西塞罗、双向论辩、人文主义日常判断和宗教语境，改变了怀疑论的用途。学界对蒙田的怀疑论性质、信仰用途及其对笛卡尔的具体影响仍有解释分歧；安全写法是“蒙田代表文本复兴后的一次重要改造与近代问题背景”，不是“蒙田把塞克斯都教给笛卡尔”。
- 宗教改革、反宗教改革与判准争论是近代怀疑重新变得尖锐的背景之一，但不能把整段思想史压成单一教派工具或一条确定因果链。游戏只需说明古代材料进入了新的知识与宗教争论语境。

### 概念断点

| 环节 | 怀疑在做什么 | 不能写成 |
| --- | --- | --- |
| 塞克斯都／后期皮浪主义 | 对争论命题并置理由、可能悬置同意，同时依显现、生活需要、习俗和技艺行动 | 为了找到一条必然真基础而暂时清空全部知识 |
| 十六世纪复兴与蒙田 | 古代材料经印刷、翻译、评注和《随笔》进入人文主义、宗教与日常判断语境；用途发生改造 | 一位中转导师把原封不动的学说传给笛卡尔 |
| 笛卡尔《沉思集》 | 不逐项审判无穷意见，而攻击它们共享的原则；暂缓对可疑意见的同意，以寻找稳固起点并重建科学知识 | 持续悬置就是终点，或塞克斯都玩法数值升级 |

笛卡尔的重建在《沉思集》中经过我思、上帝、清楚分明观念、外部世界与身心区分等论证；这些论证是否成功仍有重大争议。游戏可以采用“怀疑的目的在重建”这一文本事实，不能用胜负宣布整个体系已被证明，也不能把Cogito、外部世界和身心问题压成一个按钮。

### 玩家最低只需知道三件事

1. **文本重新进入争论。** 古代怀疑不是人物间直传；十六世纪的翻译、印刷与重读把塞克斯都带入新的时代问题。
2. **蒙田是改造背景，不是必做节点。** 《随笔》让古代材料参与人文主义、日常判断与宗教争论，但不等于笛卡尔的完整来源或导师线。
3. **笛卡尔改变了任务。** 他暂时撤下可疑基础，是为了寻找能承受怀疑的起点并重建知识；这与把悬置本身作为持续实践不同。

三条可压在一次标准过渡说明中，不新增亨利·埃蒂安、埃尔韦或蒙田人物节点，不需要新肖像、场景或动画；任何正式对白仍须重新做短文案与可读性审查。
